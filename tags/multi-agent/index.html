  • 多 agent 不是更聪明，是更贵：它到底买到了什么 yage.ai 2026-10-21
    文章探讨了多 agent 系统并非自动提升智能，而是一笔用数倍 token 预算去换取特定工程指标的交易。多 agent 的价值取决于任务的特性，例如，子任务的独立性可以换取更短的端到端时间；信息复杂可以换取更广的搜索覆盖和查漏补缺；长程任务可以换取搜索多样性；上下文隔离可以换取干净的审查窗口。文章指出，如果任务卡在单步核心推理太难或步骤过于紧密，多 agent 可能会因协调故障而导致重复劳动。最终建议是先看清任务瓶颈，根据瓶颈选择单 agent + 高档位推理，或在特定条件下才考虑引入多 agent。

  • Fugu：一个学会当经理的 AI，但它藏的比经理多 yage.ai 2026-06-23
    Fugu 是一个通过进化策略和强化学习训练出来的多智能体协调器，它学会了如何分配角色、分工和验收流程，将多智能体编排从开发者手写的流程转变为模型权重的能力。它将协调策略内化到模型权重中，使得协调能力不再依赖于硬编码的 if-else 规则，而是通过训练涌现出来。Fugu 的核心特点是其协调过程对用户不可见，但其背后的协调动作被藏得比真实组织中的经理还彻底，这是一种商业选择，旨在保护学来的协调策略和定价策略。尽管在某些基准测试上表现优于提示编排器，但其透明度问题和缺乏独立验证仍是其面临的挑战。
