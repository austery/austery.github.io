  • 做 Postgres 起家的 Supabase，为什么非要自己卖 Docker 容器？ yage.ai 2026-11-02
    Supabase 宣布进入 Compute 私有内测，旨在为用户提供在数据库项目上直接运行 AI Agent、后台任务和自定义接口的能力，包括通过 Dockerfile 部署任意语言的 API 服务和 WebSocket 长连接服务。Supabase 官方推出容器部署是为了在客户自建外部业务层服务器前，将预算留在自家平台内。Compute 容器支持完整的 Linux 环境和任意语言运行时，解决了无服务函数在单次运行时间限制和环境受限的问题。通过在同机房内网运行容器，可以实现高频读写数据库和数据分析智能体（如使用 DuckDB）的低延迟查询，将查询延迟从近五秒降低到2.9毫秒，并实现内存快照，从而简化查询流程并隔离生产主库风险。
