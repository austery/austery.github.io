  • 用 Claude Code 的 Hook + Skill，实现每次提交后自从 commit 提交变更 | 宝玉的分享 🎙️ baoyu.io 2/18/2026
    🌐 tech-engineering 🏷️ software-development
    📄 本文介绍了一种使用 Claude Code 的 Hook 和 Skill 机制，实现代码变更自动提交的方法。通过在任务结束时触发一个自定义的 `Stop` Hook，脚本会检查工作区是否有未提交的变更。若有，则阻止 Claude Code 结束任务，并调用一个 `/commit` Skill。该 Skill 能够智能分析变更内容，按文章、代码或配置等主题进行分组，并自动生成规范的中文 Commit Message。这一方案旨在提高开发者工作效率，确保 Git 历史记录的清晰和完整性，避免遗漏任何修改。
