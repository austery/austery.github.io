9月FOMC会议纪要的重点标注， 透露了9月加息决议的更多细节， 最重要的是关于加息是基于“风险管理”考虑，还是基于“情景展望”考虑的争论： 如果是“风险管理”角度，那么加息不会太多，大概率不超过3次，这是目前许多(Many)官员的观点； 如果是处于“情景展望”考虑，那么加息幅度上不设限，必要的话，加息可以更高，这是一些/多位(A number of)官员的观点。 从读美联储会议纪要的经验来看，Many代表的人数要明显多于A number of。 （但A number of代表的人数有些飘忽不定，类似之前争议很多的"various"，尽管如此，依然是Many＞A number of）
