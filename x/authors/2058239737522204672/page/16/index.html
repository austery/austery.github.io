08/14 很多人纳闷为什么 $AVGO 突然下跌 6%， $AMD 上涨 7%。大多数人只看到了“订单争抢”，结合最近我在硅谷看到的风向，我认为背后有 6 条新的产业机会值得关注 1/ 小作文说了什么？市场过度解读 据传言，Google 可能在 TPU v10 项目上与 AMD 合作。但注意，这只是可能。 市场把这条消息翻译成了“AMD 要替代博通，帮 Google 设计 TPU” 2/ 我看到了什么 我认为这条 AMD × Google TPU 传闻，真正值得关注的不是 AMD 能不能抢 Broadcom 的单，而是它暴露出了一个更大的技术拐点： AI 芯片正在从“谁的 GPU 算力最高”，进入“谁能把 CPU + XPU + HBM + I/O + 网络 + 光，拼成一个最优系统”的 Agentic阶段。 3/ 背后被忽略的六条主线 1. CPU 会重新变得重要，而不是被 GPU 吃掉 2. 真正的新赛道可能叫：Merchant Chiplet。ASIC 行业可能从卖整颗芯片，变成卖 chiplet + IP + integration。 3. 竞争从 GPU vs ASIC变成 Composable XPU，这点会改变 Broadcom、Marvell、AMD 三家的边界 4. HBM 下一步不是单纯涨价或者价格见顶，而是Custom HBM。目前所有厂商基本买类似的 HBM，正在转向memory/compute co-design 5. 最终会把 CPO / Optical I/O 提前：AMD × Google 这种异构 TPU 越成功，反而越利好光。因为 compute density 上升以后：数据搬运问题会越来越严重。 6. 提升了 $AMD 的范围主线，同样 $NVDA 也会走类似路线，这点要重点看和 $MRVL 的 nv fusion 以前 AMD 只能说： “我的 EPYC CPU 比 Intel 好。” 现在它可能变成： “Google，你设计 TPU core，我把 Zen CPU、I/O、封装、HBM 和 TPU 拼成一颗东西 4/ 我的观点和操作 AI 半导体的下一阶段可能不是“ASIC 替代 GPU”，而是“ASIC 本身也被拆掉”：CPU、XPU、HBM、I/O 和光全部 chiplet 化，然后按 workload 拼装 真正最值钱的公司未必只是“拥有最好 compute core”的公司，而可能是掌握“怎么把所有东西连接起来”的公司 $AVGO 我重新开仓，等到 9 月财报
