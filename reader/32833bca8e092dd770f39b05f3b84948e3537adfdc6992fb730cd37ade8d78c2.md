DeepSeek Harness 是一个自带网页和桌面界面的开源编程和智能体软件，简称
DSH。近期，DeepSeek
官方微信公众号透露它的日活已经达到 154 万，第三方插件有约 3.5
万个。官方同时宣布将筹建插件市场、提升插件兼容与安全，以成为智能体时代的操作系统。经常用
Claude Code、Cursor 或 OpenAI 的编程工具 Codex
写代码的人可能会好奇：Claude Code 和 Cursor 官方市场各自只有约 500
个插件，这 70 倍差距是怎么算出来的？

更实在的问题是，花时间折腾 DSH
和社区插件，到底能做成哪些主力软件做不到的事？8 月 13 日它刚开源时，主打连软件内部组件都能由插件随时拆换，我们当时觉得这套拆机设计对日常写代码太重了。过了三个月再看，社区做出的一批热门插件确实干成了几件别家干不了的活。

## 差出 70
倍的插件数是怎么算出来的

答案其实藏在 DSH 的默认统计里。这 154 万日活用户每次跟 DeepSeek
官方服务说话时，软件会自动带上当前激活的插件名单。哪怕只是自己电脑里从没公开过的本地自用插件，只要开着就计入总数。界面上还放了几个创建插件的按钮：接个外部工具、设个定时提醒，或随口让
AI 做个桌面挂件，系统就用内置模板在本地生成一个独立的插件包。

社区维护的可安装目录在剔除无法安装的半成品之后，最终收录了
9,714 个公开插件。其中近六成的插件在开源社区最多只有 1
人点赞收藏，而主题美化和桌面宠物等外观挂件占了四分之一以上。获得 100
人以上点赞的只有 271 个，最流行的几个插件获得了几千到上万的点赞。

但如果你去看隔壁两家的官方市场，Claude Code 官方市场和
Cursor
官方市场都各自只收录了大约 500
个经过人工审核的功能套装。把本地小挂件也算进去的总数，和这些审核过的套装一比较，就出现了
70 倍的账面落差。

其实只要降低写扩展的门槛，任何一家都会迅速膨胀。Claude Code
不久前才开放内部脚本扩展功能，允许开发者给软件本身写小段定制脚本。过了
39 天，社区已经冒出了 7,848
个脚本，近一半同样无人点赞。现在比插件总数已经没有意义，关键是那批最火的插件到底解决了什么真问题。

官方公布的 3.5
万插件名单筛掉半成品后，真正可安装的公开插件为 9,714 个，超百人点赞的仅
271 个，而 Claude Code 与 Cursor 官方市场各自只收录约 500
个审核套装。

## 怎么打破账号围墙、省下日常对话开销

写码的人常办两三家订阅套餐，但各个软件彼此不通。你在 Claude Code
里消费不了 ChatGPT 的额度，在 Codex 上登不进 Claude 的账号，Cursor
也只看自家的订阅。这几个软件都把登录和模型菜单牢牢攥在自己手里，不让第三方插件插手。

DSH
的自带模型连接模块也是个普通插件，所以第三方可以往它的默认菜单里塞新渠道。装上跨平台订阅插件，在设置页就能登自己的
ChatGPT、Claude、Grok 或 GitHub Copilot 账号（Claude
甚至能直接复用电脑上的登录状态）。登完之后，这几家的包月模型就出现在 DSH
默认的下拉菜单里了，底栏还随时显示各家剩余额度。

不过这种跨平台蹭额度的便利靠的是伪装身份。Anthropic
的包月接口只认自家的 Claude Code
客户端，这款插件为了蒙混过关，会在每次发出的请求头里伪造 Claude Code
的最新版本号，还在系统指令最开头强行塞入一句自称是 Anthropic
官方命令行的假身份。这种做法直接违反了 Anthropic
的官方合规条款，因为官方明文禁止任何第三方软件借用个人包月凭证转发请求。在该插件的报错反馈区里，已经有用户因为
DSH 里其他插件带出了陌生的工具名或指令特征，让 Anthropic
服务器当场识破伪装并拦截报错，拒绝扣减包月额度并要求额外充值按量付费余额，重度使用还有直接封号的风险。

日常干简单活想省钱，不少人会切换到便宜的纯文本模型（比如不支持看图的
DeepSeek
主力对话模型），但遇到报错截图就抓瞎了。在别家工具里就算加装同款识图外挂，也得先把截图存成本地文件，再把存放位置发给
AI 去读。而在 DSH 里装上四千多赞的看图插件
ModLens，它会直接在菜单里给这类纯文本模型多加一个带看图标记的选项。你选上它，往输入框直接贴截图，聊天窗照常显示缩略图，发送时插件会在后台提取图里文字和画面布局喂给模型。

长对话聊几天也贵，每次发新消息软件都得把前面攒了的一大段旧记录重发一遍给大模型。长对话折叠插件让
AI
把聊完的旧话题收成几行摘要，后面就带摘要接着聊，想看细节随时再展开，省下大笔重复开销。在
Claude Code 和 Codex
里，插件改不了发给模型的历史记录，想同样省下这笔钱，只能在软件外另开中转程序绕路处理；而在
DSH 里直接装上这款折叠插件就能生效。

## 怎么直接改远端代码，还能把界面和遥控方式按需重做

如果代码放在云端或者公司的远程电脑上，不在手头的笔记本里，Claude Code
和 Codex 就很难直接下手。就算用上 Claude Code
的内部脚本，这两款软件自带的改文件和运行功能依然只认本地硬盘。想访问远程电脑就得额外加装第三方工具，AI
用不惯这些外接工具，可能会犯错。DSH 则让 AI
照常使用自带的改文件和运行功能，由插件在后台悄悄把实际操作转到远端。比如装上云存储插件 Mirage，AI
就可以直接读写云端文件，就像在改本地文件一样。如果装上远程服务器的插件
Honeybee，那么聊天记录留在本地笔记本上，修改代码和运行命令则会自动发送到远程电脑上去。

别家软件往往得在外部加装工具或另开中转程序，DSH
则让插件直接在软件内部接管模型菜单、历史记录处理和远端文件读写。

除了省钱和连远端，软件长什么样也能跟着重做。虽然 Claude Code 和 Codex
如今都有了官方桌面版，Claude Code
的内部脚本也能在侧边栏画按钮、输入框和简单矢量图等预设界面组件，但它只允许插件在固定区域里拼装十来种预设小组件，图片总大小不能超过
2 MB，更不允许拆掉软件原有的外壳；Codex
的插件则完全改不了界面布局。Cursor
虽然能在侧边栏开自由网页窗口，但插件和 AI
隔在两个房间里：插件读不到旁边的实时聊天内容，你点一下窗口里的按钮或图片，也没法直接叫
AI 接着改。

DSH
的网页版和桌面版共用同一套插件机制，可以在聊天框旁边直接开图形界面，并且和聊天状态实时联动。比如多模态设计画布插件在对话旁边摆出网页原型、幻灯片和视频时间轴。你可以手动拖拽排版，也可以点击画布上的标题或图片让
AI 只改这一个组件，改完可以导出 PDF
或演示文稿。甚至有人拿它干写代码以外的活，比如书童小说工作台干脆把代码布局都撤了，换成书架、大纲和改稿对比台，成了本地长篇小说软件。

反过来，嫌图形窗口占地方的人装个极简终端插件，不用改动官方代码，就能把整个界面换回类似
Claude Code 的纯键盘黑框。出门在外也能随时用手机遥控：网页看板插件用多列卡片管理后台定时任务，拿手机扫个码就能在路上查看进度和发指令；消息连接插件还把飞书、微信、钉钉、Slack
等 9 种聊天机器人直接接了进来。

## 拆机自由的背面，是智能体操作系统最难付的那笔账

拆机自由也有暗面，代价在官方公布数据的同一天就露了出来。一位重度用户的反思帖提到，每加一个插件，后台通常都要在发给
AI 的指令里多塞一段使用规则。装了超过 15
个插件后，成堆规则挤满指令还互相打架，害得 AI
反复兜圈陷入死循环，最后只能删插件自救。

同一天曝光的桌面版升级故障帖更让人捏把汗。一位
Windows
用户在应用内升级桌面测试版后，不仅碰上第三方插件不兼容导致软件打不开，还发现升级程序悄悄重写了配置文件，把原本配好的
34 个插件抹得只剩 2 个内置基础包，折腾了 5 小时才手动抢修回来。

Claude Code、Cursor 和 Codex
像是给你一套精装房，承重墙都封好了，省心但改不了户型；DSH
则是管线全露在明面上的毛坯底座，连承重墙都许你拆了重砌。DeepSeek
这次宣布筹建官方插件市场、补齐兼容与安全机制，说明团队已经撞上了这道真门槛：口头上喊智能体时代的操作系统很容易，难在把底盘彻底敞开之后，还能保证升级不丢配置、插件彼此不打架，甚至还得裁决那些靠伪装官方客户端去蹭别家包月额度的热门插件能不能进官方商店。我们自己平时用
DSH，也不会往里塞满 20
个花哨挂件，只装一两个补齐主力软件短板的插件，反倒最省心。
