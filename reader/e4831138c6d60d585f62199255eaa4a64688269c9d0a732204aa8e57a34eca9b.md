今天早上醒來，發現 GPT 完全不一樣了。

表面上看，他們正在模仿 Meta 的做法，將 GPT 放在最顯眼的位置；打開最左邊的側邊欄，可以看到 ChatGPT 和 GPTs，底部有三個標籤頁，中間是 GPTs。基本上，GPT 是 ChatGPT 的專屬私人代理。表面上看，他們似乎在模仿 Meta，但實際上，他們抄襲的是 WorkOS——他們抄襲的是騰訊的 WorkOS。

還有，我最喜歡的 Codex——我每天都會打開 ChatGPT，但我現在甚至都不跟它聊天了。我以前每次都會打開 ChatGPT，然後點擊進入 Codex，掃描我的臉，並使用 Codex 的工具，但現在它已經被降級到與其他許多應用程式一起出現的地方了。我本來打算在 Sam Altman 的推特上留言，說應該把 Codex 移到第一梯隊，就像 Claude Code 一樣。事實上，如果你打開 Claude 應用，你所有的 Claude Code 程式碼庫和會話都在最左邊，所以你可以直接點擊並開啟 Codex。現在你必須先點擊才能打開它，而且它被擠到了一個更小的空間裡；起初我對此感到非常沮喪。

### 介面背後的 WorkOS 機制與產品理念

後來，我想起了我為什麼說他們在抄襲 WorkOS；實際上，ChatGPT 之前有過 ChatGPT Work，而 Claude 也有 Claude Work，對吧？本質上，它是指能夠在後台協調許多工具，執行一定程度的編程，並處理各種辦公任務。

如果你現在打開 ChatGPT，它看起來像一個聊天介面，但在後台，它仍然是舊的 ChatGPT Work 設置，採用一種針對程式設計師和非程式設計師都優化的方式來為你完成工作。例如，今天我讓它更新我的網頁，它真的更新了，而且真的去我的 GitHub 提交了更改，它給我的報告都是在這個聊天介面中顯示的，所以它肯定是 ChatGPT Work 系統。

我認為，該怎麼說呢，尤其是在 Anthropic 進入市場之後，你真的可以看出 OpenAI（或 Sam Altman）和他們之間的理念差異。結合他在與大衛的那一集中提到的內容，他認為 Codex 應該是理想的使用方式，但他認為這種介面並不是大多數人習慣的。因此，你可以想像 OpenAI 希望將 ChatGPT 變成一個應用程序，讓每個人都能有效地調動其背後的運算能力，既作為後端，又作為基於工具的介面。

### 商業模式分析：訂閱制與 API 的天花板

我認為這種做法很勇敢，但我不認為目前的商業模式是合理的。因為我已經說過，在 ChatGPT 上投放廣告是不可行的。

如果我們看看 Anthropic（我在之前的影片中對其進行了深入分析），它的大部分收入（約 70-80%）來自 API，而我們知道 API 比訂閱更有利可圖。打個比方，訂閱模式就像《魔獸世界》的月費，而 API 就像在遊戲中出售皮膚；後者的商業模式規模要大得多。如果從兩家公司的商業潛力，或兩種遊戲類型的商業潛力來看，個人消費無上限的遊戲類型具有更大的潛力。

無論你如何把 ChatGPT 打造成個人代理，或者如何把個人工作代理打造成個人工作代理，實際上賺錢仍然非常困難，你仍然無法突破訂閱模式的瓶頸。所以，我認為你應該直接出售 API。有了這麼好的模型，你應該想盡一切可能去佔領企業市場，想盡一切可能成為下一個像 Office 一樣擁有無限發展潛力的公司，而不是浪費時間在這種通用的個人代理上。

從商業角度來看，我認為從消費者角度來看，我當然希望看到個人代理模式得到更廣泛的應用，讓每個人都能更好地使用它，並獲得更愉快的體驗。這是我作為投資者或股東的觀點。

### 廣告模式與代理邏輯的根本衝突

如果 OpenAI 錯誤地認為廣告是讓普通 C 端用戶獲利的一種方式，那麼他們就犯了一個大錯。我之前分析過 ChatGPT 的廣告，它不可能成功，因為廣告的商業模式和代理商的商業模式完全矛盾——它們彼此衝突。

三毛和其他人想表達的是，廣告可以為普及教育提供資金。如果我投放廣告，而這些廣告能夠從終端用戶產生收入，那麼我就可以免費向更多用戶提供我的產品。這種模型豈不是會產生飛輪效應嗎？

但廣告究竟是什麼？廣告的本質是劫持你的注意力；就是不擇手段地去影響你的決定。但經紀人的目的是為了節省你的注意力。它們在產業鏈中發揮作用，縮短了整個採購和交易流程。你只需把它交給代理人，代理人就會為你處理。在這種情況下，經紀人既不看廣告，也不會受廣告影響，否則就會失去信譽。因此，這兩種商業模式相互衝突。

此時此刻，再說任何話都無濟於事；這種理念最終是不可持續的。我希望 OpenAI 已經認真考慮過背後的商業模式。身為人工智慧用戶——或者說是這項技術的「普及派」成員——我真心希望更多的人能夠更有效地獲取和使用人工智慧。但同時，身為 OpenAI 的股東，我希望他們能認真思考底層模型，避免做出可能損害其商業價值的混亂事情。

### OpenAI 的組織心態與三件核心要務

哦，還有一點：說實話，OpenAI 內部有很多不同的人。我覺得他們公司裡既有一些工作態度像新創公司一樣優秀的人，也有一些工作態度像 Meta 公司一樣平庸的人。在 Meta 工作的人，是為了升職加薪和提升自身影響力而努力。至於那些有創業精神的人，你可以簡單地理解他們努力把工作做好。

我認為在大公司裡，那些善於講述自己故事、贏得他人支持的人往往會佔上風。如果這些人佔上風，他們會花很多時間去做一些看起來很了不起但最終毫無意義的事情。例如，沒錯，我們過去就看到 OpenAI 砍掉了許多項目。

事實上，OpenAI 的總裁 Greg 參加了一位 OpenAI 投資者主持的播客節目，兩位主持人向他指出，OpenAI 在過去一年中真正取得的成就係從一家大型公司轉型為一家新創公司，這非常罕見。我覺得他們兩個真的明白了；他們說得太對了。

OpenAI 目前缺乏像大型企業那樣運作的資格；它不是一家穩定的公司，沒有上市，也沒有特別清晰的商業模式。它沒有資格去追求虛榮心強的專案或僅僅為了作秀的事情。它仍然是一家隨時可能倒閉的公司，因此應該將時間和精力投入最重要的事情上。

其實真正最重要的事只有三件：
1. 第一種是最好的模型，即基礎模型；不要談論成本或其他遊戲，你只需要能夠生產出表現最好的模型。如果你無法生產出性能最佳的模型，你就沒有生存的機會。
2. 第二點是你的 API 使用情況。
3. 第三點是程式碼庫。

在我看來，這三件事是 OpenAI 最應該關注的；其他一切都只是噪音。
