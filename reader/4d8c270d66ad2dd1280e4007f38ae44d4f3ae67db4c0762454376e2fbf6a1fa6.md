这次扣子桌面端上线，增加了云盘、深度截图等新功能，也终于让 Agent 碰到“本地电脑”。

除读写本地文件更方便外，也能自动识别本地 Codex CLI、Claude Code 接入为 Agent，多 Agent 协作史诗级增强。

模型方面，昨天 GLM 5.3 API 刚出，扣子就接上了，甚至有 Seedance 2.5、MiniMax H3 等顶级视频模型。

好模型 + 好 Agent = 好产出

下面展开讲案例和操作，建议先收藏再看。

# 新书营销宣传

最近我和姚老师发了新书《AI领导力》。

用扣子桌面端，一口气完成了所有书籍宣传物料的生产：

Agent 读本地书稿大纲 → 生成宣传网站 → 生成宣讲 PPT → 生成宣传播客。

所有产出文件都自动存在扣子云盘中，电脑、手机、网页实时同步，任意端都能查看、调整。

感觉 Agent 终于进入我的电脑工作现场，再也不用手动上传下载，Agent 始终能拿到最新的文件版本工作。

先给大家看看网站，让扣子桌面端读本地书稿大纲，仅调了 3 轮，就做好了。

> https://m9xh7f7fzm.coze.site/

开发网站过程中，顺带体验了扣子桌面端新功能 “深度截图”。

启用方法：桌面端「设置 → 桌面端设置」→ 开启深度截图，然后在“设置->快捷键”中启用快捷键。

如果你是 Mac电脑，以后按左、右 Option 键，就能将当前窗口截图和可读取文本加到输入框。

注意，这里的截图不止是图片，连界面结构文本信息都会一起放进对话输入框。

更多有效上下文信息，对网页调试非常有用。

除了网站，也需要 PPT 用于对外宣讲。

发现扣子内置了 PPT Skill，在对话框中输入“/ppt” ，让 Agent 基于本地和网上资料生成一个PPT。

没等几分钟就做好了，我仔细读了下，完全贴合书中要点，比如3M模型，1+N、干中学等等。

有趣的是，PPT虽然图片生成，但依然可以修改，双击任意一页，可以擦除不需要的元素，也能涂抹修改文字。

这是把 Seedream 模型的图片编辑功能用到位了！

最后，顺手用扣子内置播客 Skill，生成了这本书的宣传播客，听了下，人声自然，解读也很到位。

您的浏览器不支持音频播放

默认生成播客，都会带“扣子”口播，直接用怕不好，所以让 Agent 剪掉。

扣子桌面端安装后，会在电脑上添加一个扣子云盘，操作体验跟本地硬盘几乎没区别。

所有云端 Agent 对话产出的文件，都会存在扣子云盘。

这个设计就很巧妙，你可以任意拖拽本地文件到扣子云盘，云端 Agent 能读取，手机上也完全同步的。

云盘上的所有新增、修改、重命名、删除，都会同步到本地，本地改动也会同步回云盘，双向同步。

感觉可以把办公常用文件都放云盘，再也不用反复上传下载，让“上下文”离 Agent 更近一点。

另外，垃圾箱默认保留30天，哪怕误删能找回来。

# 自媒体场景

除了写书、研究 AI 工具和GEO，我还会做 AI 自媒体，这块扣子也能帮上忙。

建议新建个Agent，操作路径：新建Agent->选择职业模版->自媒体运营达人

扣子官方内置了大量自媒体需要的技能（Skill），甚至连违禁词查询都有。

用的时候，需要去官方合作平台申请一个免费 API：

> https://redfox.hk/

比如让它查询公众号、抖音最新的热门内容。

另外，我给这个 Agent 加了些自己的本地 Skill。

做了这些后，一句话就能让这个 Agent 实现找热点、写文章，然后发到我的博客草稿箱。

我会经常读一些 AI 论文，没想到扣子也内置了 “科研助理” Agent模版。

跟上面类似，可以帮我实现论文查找解读、学习，一键发布的操作。

# 最后说说多 Agent

扣子支持多种 Agent 创建方式：

本地 Claude Code、Codex CLI、OpenClaw 转成 Agent。

云电脑 + Harness 框架，创建云端 Agent

选职业模版创建 Agent

模型支持所有国内顶级模型，比如DeepSeek V4 Pro、GLM-5.3、Kimi K3等。

另外，所有桌面端创建的本地、云端Agent，都是和移动端、网页端打通的。

这意味着，哪怕我不在电脑旁，手机上也可以遥控电脑上的 Agent 帮我做各种事情。

如果你创建多Agent，新建项目时，可选择拉哪些 Agent 一起加入。

适合让多 Agent 协作搞定复杂任务，下面只是演示，让几个 Agent 解读同一本书。

后续计划创建多个专业 Agent，如前端工程师、构架师、产品经理等，分别用最适合的模型，装上最专业 Skill。

组建这样一个虚拟员工团队，想必会相当好用。

# 写在后面

说实话，这次体验扣子桌面端，有几个地方让我意外。

不是盲目加功能，而是 "这个设计终于想明白了" 的感觉。

云盘双向同步、深度截图带结构文本、本地 Agent 接入。

单拿出来不稀奇，但组合在一起，好像是为了解决同一个问题：让 Agent 离你的工作“上下文”更近一点。

文件要上传下载、截图要详细描述、本地脚本执行不了。

扣子桌面端，想帮你把这些摩擦成本一点点抹掉。
