### 常驻代理 Dots：跨平台长程执行与交互范式重构

在上午的主题演讲中，首个登场的重磅炸弹就是 **Dots**（常驻长程代理: 具备独立计算环境、常驻云端且可跨多端主动协作的 AI 智能体）。这是一种始终在线的长程智能体，能够横跨 ChatGPT、Codex 运行，既可以在云端专属虚拟机中操作，也可以直接调用用户的本地电脑、手机，甚至深入集成进 Slack。无论通过文字指令还是实时语音通话，它都能全天候为你完成复杂任务。我非常早就拿到了测试资格，由于 OpenAI 团队几乎每小时都在高频迭代完善，因此目前很难给出一份盖棺定论的完整评测。但最核心的问题在于：在 GrokBot 极度流行、Muse 势头强劲、Instinct 仍活跃在短信场景的当下，Dots 究竟处于整个代理生态的什么位置？

从产品架构来看，**Dots** 就是你的个人代理。当我向团队询问用户能够拥有一个还是多个 Dots 时，团队确认目前每个用户仅分配一个专属 Dot。如果订购了 Pro、Business 或 Enterprise 等关键套餐，你现在就能在 ChatGPT 和 Codex 客户端中看到它。比如我的 Dot 叫作 Bae，形象是一个戴着眼镜、长着大眼睛的粉色小团子。Bae 拥有专属的云端计算机，里面预装了浏览器以及开发者常用的各种生产力工具；作为用户，你既可以让它独立运行，也可以随时接管该虚拟机的操作。此外，用户还能授权它访问本地计算机，形成真正的混合代理执行环境。在交互方式上，OpenAI 大力推进多渠道联动体验：除了桌面与移动端应用外，你甚至可以直接给 Dot 打电话。这并非普通的语音模式，而是真正的语音呼叫，它会响起铃声并接听，虽然在录音转写、实时语音与电话呼叫之间的逻辑串联仍有打磨空间，但整体交互模式非常新颖。而在企业场景中，你还可以直接将 Dot 安装到 Slack 中协同工作。

目前 Dots 最令用户困惑的地方在于其信息架构以及与其他界面的边界定义。OpenAI 将其定位为用户的数字分身与主权代理，类似于你的任务“主线程”。这个总管 Dot 负责承接所有日常工作，具备极强的主动性，不仅可以提醒日常事务、自主推进任务，还能按需派生并调度独立的 Codex 任务线程和对话线程。在实操效果方面，Dots 展现出的执行质量非常过硬：我让它帮我网购，它准确挑中了心仪的鞋子；我让它编写代码，它交付的代码质量非常出色；甚至在日常生活中它展现出了恰到好处的主动性——当我在规划孩子周末游泳课与其他安排是否冲突时，它今早主动提示我：“嘿，需要我为你查看 11 月的课程备选吗？这里有几个选项。”尽管在用户体验和概念区隔（如 Dot 线程、Chat 线程与 Codex 线程的边界）上仍有粗糙之处，但其核心骨架非常扎实。就个人习惯而言，我目前在日常工作中依然偏爱使用 GrokBot 针对具体垂直场景雇佣离散微代理，且 Muse 的消费级体验与拟人化形象也更具亲和力，但 Dots 凭借强大的底层模型与长程记忆，一旦结合主动触发能力，必将成为撬动工作流的核心中枢。

### 原生协作 Spaces 与 Sites：打破企业数据与内部工具孤岛

在本次发布中，我认为被外界严重低估的一个重大突破是 **ChatGPT Spaces**（原生 AI 协同空间: 支持人类与多智能体共同编辑文档、演示文稿及动态页面的统一工作区）。企业长期以来都在渴求一个真正原生集成 AI、具备完善权限管控与数据治理能力的协同平台。当年我在构建 ChatPRD 时就意识到，人类与 AI 智能体迫切需要在同一份活文档上协同作业，而 OpenAI 现已将这种能力做成了底层标准。通过 Spaces，你可以自由创建页面、文档与幻灯片，随时在文本中 @mention 你的 Dot 或 ChatGPT 来直接更新内容。以往 AI 工具虽然善于从零生成幻灯片，但在后续的多人在线编辑与精细调整上一直存在巨大短板，Spaces 的出现彻底补齐了这一痛点。

最令我惊喜的细节是，我的 Dot 在 Spaces 中为我创建了一个名为“个人便签本”（Personal Scratch Pad）的协作空间。我个人处理待办事项的习惯比较随性，从不强求自己使用高度结构化的 Notion 表格，而是偏好意识流式的列表与勾选项。几周前我还专门编写了一个名为 Claire's Notebook 的工具，以便让 Codex、Grok、Muse 和我一起协作管理任务；而现在，Dots 在 Spaces 中完美实现了这一模式。无论是日常备忘、演讲筹备大纲，还是《How I AI》的录制排期，我都能与智能体在同一个活文档内无缝打磨。这种直指企业协同痛点的布局，可以说是向动作迟缓的 Google 正面开炮——拥有深厚技术积累的传统巨头正眼睁睁看着 AI 原生办公的机遇被夺走。

与 Spaces 紧密联动的另一项重大更新在于 **Sites**（OpenAI 应用构建与托管服务: 允许用户基于对话与提示词直接生成并公开发布交互式 Web 产品的内置工具）。Sites 现已深度整合进 Spaces 的权限体系中，更关键的是它支持**打包集成外部连接器与插件**。举例来说，若你想基于企业 Snowflake 仓库快速搭建定制分析看板，以往通过个人 ChatGPT 绑定的插件数据无法在分发后保留合规权限。而现在，你在 Sites 中绑定的插件会遵循企业级鉴权：同事访问该看板时必须通过自身账号认证，仅在具备相应数据权限时方可查阅报表，否则自动受控拦截。当前企业界充斥着大量依靠快速生成（vibe-coded）出来的内部工具、原型与临时报表，企业最头疼的问题就是“如何安全有效地管理这些资产”。Sites 结合插件连接器给出了强有力的工程解法，正面迎战 Claude Artifacts 等竞争对手。

### 模型矩阵迭代：高性价比主力 Sol 与具备视觉能力的 Decisions API

作为一名骨子里秉持工程师精神的开发者，底层模型与平台基础设施才是我最为关注的硬核领域。正如 Sam Altman 开场所言，社区最普遍的诉求始终是“模型更便宜、速度更快”。这次 OpenAI 正式推出了 **GPT-6.1 Sol**，其在保持接近顶尖 Astra 级智能水平的同时，兼具了 Sol 序列极高推理吞吐与极低调用成本。具体而言，其定价仅为**输入每百万 Token 2 美元、输出每百万 Token 10 美元**，远低于 Astra 的输入 10 美元与输出 50 美元。自 Sol 诞生以来它就是我日常工程编码的绝对主力劳模；除非需要极限推理能力并愿意承担高昂账单，否则极具成本效益的 Sol 绝对是绝大多数团队的性价比首选。

比常规模型迭代更激动人心的，是全新的 **Decisions API**（决策专用 API: 针对预定义选择项进行极低延迟高置信度分类决策的模型接口）。这被视为 OpenAI 对标 Jev（即引入约束机制的 Luna 智能）的关键产品，但它拥有一个降维打击的绝对优势：**原生集成了视觉理解能力**（Computer Vision）。为了验证其威力，我用一个实际痛点进行了测试：在录制时长约 40 分钟的技术播客后制作视频封面时，通常需要从长视频中抽帧并寻找嘉宾面部表情自然、不显尴尬的抓拍画面。以往若使用传统模型按 2 秒或 5 秒切片过滤，耗时冗长且准确率低下，而 Jev 缺乏视觉模态根本无法处理。我利用 Decisions API 对 100 帧画面进行自动化筛选，**用时不到 10 秒**就精准挑出了我和嘉宾均笑容灿烂、毫无死角的完美镜头。此外我还重现了经典的热狗识别（Hot Dog / Not Hot Dog）分类测试，该 API 在不到一秒内便以 100% 的置信度完成判定。这种将毫秒级决策速度、极低成本与视觉分析相结合的基语组件，正是当前现代 AI 架构中所欠缺的关键一环。

### Astra Ultrafast 体验：8倍极速推理与实时生成式交互

在全场所有发布中，最让我真正触碰到未来脉搏、但也最为昂贵的技术，非 **GPT-6 Astra Ultrafast** 莫属。在 Codex 和底层 API 的调用档位中，除了标准模式与 2 倍提速的 Fast 模式外，全新的 **Ultrafast 模式实现了高达 8 倍的推理提速**；虽然其调用成本也飙升至标准版的 6 倍，但其赋予的近乎实时（near real-time）的顶级边沿智能彻底改变了交互范式。我没有选择用它去清理陈年代码仓库或进行超深度长程推理架构设计，而是选择探索当开发者将极速前沿模型注入产品栈时，究竟能创造出怎样前所未有的实时应用。

我用 Astra Ultrafast 构建了两款演示原型：第一款名为“另一支画笔”（The Other Pencil），是一个人类与 AI 实时协作的矢量画布。当我在画布上勾勒波浪线条时，Astra 几乎贴着我的笔触在后台飞速渲染出匹配的 SVG 矢量图；当我画出一个带笑脸的圆圈时，它转瞬间配合补全了一只可爱的小鸡，随后又随着交互生成了精巧的瓢虫。第二款名为“小星舰”（Little Starship）的 3D 游戏更是展现了实时代码渲染的魅力。游戏中包含 Pip、Momo 和 Sprout 三个角色，当我输入自然语言指令“给朋友们建一个浴室”时，Astra Ultrafast 在数秒内直接在 3D 场景中实时构建出带泡泡的浴缸和橡胶小鸭；当我输入“去热带岛屿度假”，整个游戏场景瞬间实时变换为椰子树、沙滩与碧海；输入“消除重力来场漂浮派对”，全局物理引擎参数瞬间被改写。昨晚我的孩子们沉浸其中玩了整整 20 分钟——尽管这短短半小时的实时体验消耗了我约 97 美元的 Token 成本，但这种在几秒内凭借前沿超高智能实时生成完整游戏资产与逻辑的交互体验，展现了极速前沿 AI 产品的无限想象力。
