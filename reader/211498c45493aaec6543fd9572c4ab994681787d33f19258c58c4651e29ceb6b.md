### 字节的短剧闭环：左手好莱坞，右手纽交所

>> 字节啊左手造了一个好莱坞，右手造了一个纽交所。你看啊，这个你拍剧，我卖算力对吧；然后呢你要推广，我就卖流量；然后用户来了，我再塞广告。基本上是字节把这个短剧的链条闭环了。我觉得字节最牛逼的一个地方是什么？它同时拥有了全中国最牛逼的两个应用：一个是杀时间的，一个是省时间的。杀时间的就是红果，省时间的就是豆包。

>> 省完时间又去杀时间是吧？还自己循环，太可怕了。

>> 我开头就讲嘛，我说我在豆包上面省的时间，最后都贡献给红果了，哈哈哈。诶聊一下红果短剧啊，最近特别特别火对吧。我们讲了这么久AI，都说AI帮我们节省多少时间提效，这次讲一个反面案例，就是我把AI帮我提升效率的时间都花在了红果上面，哈哈哈对吧。确实是一个最近现象级的案例啊。据说你们不知道吧，就红果现在月活已经超越豆包，仅次于抖音，4点多个亿啊，4点多个亿的月活呀。然后呢，据说这个10月份在台湾的App Store已经跑到第一名了，这是一个非常夸张的一个增长啊。我觉得这个已经是大到我们频道必须要来跟大家拆解一下哈。那我这两天研究了一下，我觉得这个生意真的是太神奇太神奇了啊。我是感觉啊，这个字节啊，左手握了一个好莱坞，右手握了一个纽交所，哈哈哈左手倒右手，直接把这个生意给干出来了。

>> 真的非常神奇啊。你看啊，这个很多人不知道啊，这个红果其实最早是跟这个番茄小说一个团队的，所以很多上面红果的短剧啊，其实是这个小说的IP拿来改编的。

>> 嗯就是我……如果说从广告收入、从收入来讲的话，不是一个纯增量，有可能是在存量里面切出了一块，然后带来了一定的增量。但如果说从业务端，纯增量，纯增量，而且增长巨快对吧。刚才也说了，月活4个亿，然后日活听说已经到2亿了。日活2亿啊同学们，太吓人了，真的太吓人了。我当时在那个……就是看到一个标题，就说用户时长全国第四。

### 创作成本、抽卡损耗与投流套利模式

>> 对，所以我这里其实有一个很朴素的问题。就是我们刚才说它有两个东西都在字节嘛：第一个是制造，还有一个是分发，这两个都在字节。制造靠Seedance模型，那我们知道大模型这个东西是很坑的，就是它不稳定。其实我们要做一个视频出来的话，它肯定得抽卡。然后现在我看到最高的水准也就是抽三张用一张吧，差不多就30%成功率，那这其实很低的。那我每天做个几分钟的剧，可能随便的成本就是可能大几百；然后呢结果才搞个几万的播放，才收了几十块。那我天天这样做，一个月下来我也受不了，就是普通创作者根本受不了。那肯定得有一些什么顶流的东西，能够让我说接着一直去用这个模型啊，对吧？

>> 诶这个其实是个问题啊。它其实跟做自媒体一样啊，你做10个也不可能有一个人成啊；你做短剧也一样是这样啊，这个是所有媒体平台它都是这样的。

>> 对。

>> 但是你看哈，他会给你看头部的数据，就是现在开始说头部赚得多好。你看说这个《持械入宋》嘛，6人的核心团队，1000集，累计120亿播放，改编自番茄小说对吧。然后说赚的应该有8位数的钱啊，据说哈据说。然后还有一个是个例哈，有一个人对吧，半年10部剧，16亿的播放，7位数的分账收入。首先就是大家以为说我做了一部短剧，我就要去投流，其实不是的。这个平台的初始阶段，有专门的投流公司来投这些短剧的。他为什么投这些短剧呢？是因为他可以从流量里面去套利嘛，对吧？因为我投出了一部爆款以后，就会有字节的非常多的老广告客户或者新的广告客户进来，我把你转化成红果的投放客户，那这笔投放的预算再跟创作者、再跟IP、再跟投流商、再跟字节再去分钱啊。也就是说这个生意就是羊毛出在驴身上，然后猫去叫卖，狗来抬价，然后猪付钱，是这样的一个生意，你明白我意思啊。首先这个仅限于红果哈。那单一部创作剧的成本来讲，有低到几千块的，也有几万块钱一部的啊，不等啊不等。那大概是三分之一是在算力上面，三分之一是在剧本上面——但现在剧本据说啊，几千块钱、一两千块钱的也有，3000块钱以下大把据说哈——然后剩下三分之一就是人员其他的，大概是这样一个成本比例哈。

>> 对。那我看到的是很多人在吐血那个Seedance生成。因为现在叫什么，就是那个杰文斯悖论的问题：它单价好像变低了，单个的质量好像都不错啊，但是为了让它质量更好，因为现在就是闲哥说的，大家要比做得好了，那这个时候其实它的用量是比以前要大了很多，就是他得有更多次去调用。

>> 成本嘛对。

>> 就单次成本现在可能是有越来越在降低的一个东西，但是他调用的次数越来越多。然后呢，他最后变成说，你看换算起来就是：一秒钟可能我用Seedance 2.0是一块钱，然后用Seedance 2.5得是一块五，大概是这么个成本。但是这样的一个成本呢，我原来用2.0的时候，我可能不会抽那么多次，我差不多那个质量抽几次就够了；然后现在就要抽很多次，去保持它的整个一致性啊，然后一些细节确实做得很漂亮啊。结果他最后发现，原来可能一集原来只花个十七块钱、20块钱，现在都得干到100块钱了，就是差不多一集有个5倍的成本往上走。最后那个比例我也听说像你刚才提到那个比例，原来算力的比例可能就是30%，但现在可能更高了，现在可能高到五十六十这样子。

>> 你要么用老模型用很多次，要么用新模型一把过但很贵对吧？

>> 对，包括贵了之后，可能他现在还要精益求精了，新模型也得用多次，他是这样子的。为了让他的一致性更好，细节更好，因为大家都水平都上来了，不是那么简单。因为大家都写个说，我们用的工具是一样的，这个时候比拼的就不是简单的说我的IP呀、脚本分镜啊，因为连脚本分镜IP都是用的一样的工具做的。

>> 这你就要问闲哥。闲哥说我们以前拍电影的摄像机也都是一样啊，但是杜琪峰跟王家卫是有区别的嘛。

>> 对哈哈哈。

>> 所以人家好莱坞还有分那么细嘛对吧，有最佳摄影奖对不对，最佳音乐奖嘛。所以基本上我听说就是，现在做一部这种AI红果短剧，100集啊咱一个标准来说的话，大概要5万到10万，差不多这个量级。但以前你知道做一个真人短剧，那个成本是多少钱吗？我朋友他们有做的啊，基本上做一部的话，大概要到十几万到五十万差不多这样一个情况。50万人民币啊，当然已经比原来做一部电影或者说做一部电视剧要便宜太多太多太多了对吧。以前一部电影……

>> 你的意思是说短剧比它便宜十倍嘛对吧？

>> 对，本身就比它便宜10倍。便宜10倍我觉得带来的不是说原有成本的节约，而是让很多普通人能承担得起，明白我意思吗？就说原来的很多创作者就只是观望者，或者说叫做票友，没有机会真正登台；但现在你让我说花5万块钱做一部剧，我们六七个人对吧，然后凭兴趣爱好，这钱也出了，就跟出去出国旅游一趟差不多。但这个获得精神享受，再加上跟别人说“我现在会用AI了”，都有这种情绪价值——“我现在也是刘导了”。

>> 对，而且我留了这部作品对不对？而且万一我这部作品火了呢？上亿观看了呢？那这完全完全不一样。所以我就问你，在这种情况之下，创作者的动力还有创作者的基数就完全不一样了。我觉得就不是10倍的概念了，可能到百倍了，这个级别了啊。

>> 闲哥你这个说的很对，我认同这个，就是在供给端出现的一个增量对吧？

>> 对。也就是说很多你看这个《持械入宋》啊，很多是宝妈对吧，滴滴司机，然后据说还有很多是什么保安呐，也在做这个AI短剧。因为我发现我投个几千块钱，我也能做个几集的小短剧对吧，自娱自乐一下。而且上来你不用做100集啊，你先做两集，那可能也就是500块钱对吧；两集之后你发现自己做不了这事就不做了，但两集三集要是身边人反馈都特别好，或者你发上来之后有人看，你肯定愿意把这事做完啊。

### 端到端工业流 vs 散装模型：谷歌与国内竞品对比

>> 不过咱们帮着人家免费吹了这么半天牛，但是我一直在想下一个问题：现在来讲的话红果也开始有海外出海版了，国内大厂腾讯、快手我觉得都会跟上；但是到底全球来讲的话，有没有能够跟像Seedance或者即梦这种真正的做AI短剧专用工具？这种会不会所有大厂都开始把它作为下一个赛道？这点我其实想听听你们两位有什么看法。
