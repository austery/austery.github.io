### 減肥的「黃金比例」與肌肉監測

>> 減肥的「黃金比例」是多少？一般醫學研究表明，3:1 的比例是一個基準，這意味著減掉的體重中 75% 來自脂肪，而剩餘的 25% 來自非脂肪組織。然而，其他研究告訴我們，如果你想獲得更好、更高品質的減肥效果，這個比例甚至可以達到 6:1。那麼，您如何看待這個比例呢？或者，對於您在普通診所遇到的減重患者，他們如何保持這種更好、更高品質的減重狀態？

>> 首先，你必須知道它是否真的是 6 比 1。減肥是一個長期的過程，所以我們每隔一到兩個月進行一次 InBody 掃描。這使我們能夠評估您的肌肉量下降的原因，並提供即時的建議。

>> 你好。大家好，我是李醫生。在我們的減肥診所，我們經常看到這種情況：兩個人來減肥，他們花費的時間和減掉的體重差不多，但一個人的內臟脂肪明顯減少了，脂肪肝也得到了改善，而另一個人在減肥後感覺更加疲憊，甚至缺乏進行日常活動的力氣。這真奇怪；即使減掉的體重相同，這兩個人的狀態也完全不同，這種情況在減肥診所裡很常見。事實上，有些人減肥過程中沒有適當的監測，或是沒有回來進行後續評估，當減重遇到瓶頸期時，他們不知道該如何應對。

>> 沒錯，那麼，對於同樣減掉的體重，為什麼一個人感到滿意和快樂，而另一個人的健康狀況卻沒有改善呢？今天，我們將詳細解讀這份許多人從未見過的治療流程圖，以幫助大家理解它。今天，我們邀請了維康胃腸病診所主任錢軒醫生，與我們探討如何實現更高品質的減肥，從而徹底改善您的健康狀況。歡迎錢博士。

>> 大家好。

### 減重速度過快的健康風險與極端節食案例

>> 我想請問錢醫生，您在診所裡是否曾經遇到像我們剛才提到的這兩種截然不同的情況？有沒有哪些病例給您留下了深刻的印象，或是您想和我們的聽眾分享一下？

>> 我們診所經常會遇到這樣的病例，一些四五十歲的男性——正值壯年——進行公司體檢，結果發現他們的肝酶高、甘油三酯高，超音波檢查顯示他們患有脂肪肝。遇到這種情況，體檢中心給他們報告後，他們會非常恐慌。

好的，遇到這種情況，我們首先要教育他們注意飲食習慣，例如不要禁食太久。當胃處於非常空的狀態時，如果你攝取大量食物，或者有些人暴飲暴食，他們的胃酸分泌就會激增，這很容易導致胃食道逆流問題。此外，服用某些藥物時，有時會影響膽囊的運動和收縮，導致膽汁淤積在膽囊中而無法排出。由於膽汁在體內不斷翻騰，形成膽結石的風險就會增加。

減肥時，無論採用節食、運動或藥物，都不建議過快做出調整；避免減肥速度過快。如果出現任何副作用，您可以考慮維持基本劑量。

我曾經遇過一個案例，當事人已經快 40 歲了。雖然他們沒有患上「三高」症候群或嚴重的脂肪肝，無需醫生囑咐減肥，但他們想要改善體型和體重，所以決定服用藥物來抑制食慾，少吃點，看看能否更快地減肥。起初他們減肥效果很好，但後來，由於減肥速度過快，他們的整體精神狀態變得非常差。病情甚至發展到出現嚴重的胃腸道症狀，如噁心和嘔吐，他們一天只能吃一頓飯，即使喝水也會感到噁心想吐。

他們吃得越來越少；也許他們沒吃早餐，午餐只喝了點豆漿，吃了個茶葉蛋，然後一直撐到晚餐才吃上一頓家常菜，或者吃一塊雞肉，僅此而已。長期以來，他們的飲食實際上嚴重缺乏營養，這對他們的健康沒有任何益處。

正如營養師所說，我們不希望他們繼續禁食這麼長時間，也不希望他們達到如此嚴重的飲食限制狀態。我們希望他們能先恢復均衡的營養狀態，然後再考慮重新參加減肥計畫或恢復服藥，這樣會更好。

每個人的健康狀況都不同，需要注意的事項也各不相同。Chury 網站提供許多與健康相關的測試，從各種健康角度幫助您更了解自己的身體。點擊右上角的按鈕或下方的資訊欄即可立即開始測試。

從我們剛才討論的案例中，無論是共同經歷還是診所就診，我們都可以看出，減肥真正重要的不僅僅是體重計上減掉了多少公斤。關鍵在於確保你的身體在整個過程中保持健康舒適，並確保減肥效果得以維持。因此，我們彙總了關於減肥，甚至是關於「高品質減肥」的一些最常見的問題，以揭穿謠言並提供答案。

### 減重速率建議與心理、代謝影響

>> 首先：如果你完全沒有食慾，體重迅速下降，這是否意味著你中了頭彩？

>> 我們的肥胖醫學會建議每週減重約 0.5 至 1 公斤，或約佔體重的 0.5% 至 1%。因為如果你每週減重超過一公斤，正如我們剛才提到的，你最終可能會失去不應該失去的肌肉量。

臨床上，我們甚至發現，減肥過快的人容易掉髮，或出現胃脹、飽脹或胃酸倒流等症狀，對於育齡婦女來說，甚至可能導致月經不順。

正如營養師所提到的，對於那些一天只吃一頓飯，而且無法吃其他任何東西的人來說，我們在臨床上遇到過一些患者，他們在減肥過程中變得非常抑鬱。對於一些因壓力而肥胖的人來說，一旦他們的碳水化合物攝取量減少，他們曾經從食用這些碳水化合物中獲得的快樂就會消失，這些碳水化合物的「感覺良好」功能也會消失。這種匱乏感可能會突然導致我們前面提到的補償性進食，你會想要暴飲暴食，而這實際上會對你的健康產生非常負面的影響。

不要盲目追求「我要以最快的速度衝過終點線」的目標。你很容易在進行到一半時遇到瓶頸，真的不值得付出努力。

此外，如果你不小心減掉了肌肉，你的基礎代謝率也會降低。一旦減肥過程結束，體重就更容易反彈，而且所有的體重都會儲存在你的脂肪層中。

### 運動維持肌肉與打破久坐

>> 第二個問題：我們來看看減重過程中需要多少運動量才能維持肌肉。

>> 目前，關於所需的具體運動量，實際上還沒有任何確切的數據。原則上，我們的肥胖醫學會建議進行負重訓練或阻力訓練——只要你進行的動作能夠產生對抗外力的阻力。

例如，我總是告訴我的病人，如果你要去地鐵站或火車站，不要搭乘手扶梯；改走樓梯。因為用腿支撐上半身向上運動其實是一種負重運動，而負重運動其實很簡單，你可以自己做。

另外，我想提醒大家，雖然舉重訓練非常好，但也別忽視你們的基本日常活動水平，特別是你們是否已經擺脫了久坐的生活方式。因為如果你非常努力地進行肌力訓練，但每天坐著的時間超過八小時，實際上會抵消你的努力成果，產生一種叫做「運動阻力」的現象。

事實上，從慢走改為快走可以增加我們的代謝當量（METs），也就是每次運動燃燒的卡路里數量，這也有助於我們擺脫久坐不動的生活方式。

### 自我評估與肌肉力量檢測

>> 我們來看第三個問題：如果你家裡沒有 InBody 儀器，你怎麼知道自己是否真的減肥成功了？

>> 我並不建議在沒有任何科學監測的情況下自行調整體重。如果你在診所或醫院，他們通常會提供這些機器。但如果您覺得去診所或醫院太麻煩，連鎖健身房也提供這些服務。我甚至有些病人會親自去健身房測量，當他們回來複診時，會給我整整一個月的數據，這樣我們就可以追蹤他們的變化。

如果附近實在找不到合適的測量工具，你也可以量一下腰圍。關鍵在於在固定部位進行測量，以追蹤腰圍的變化。

另一點是，如果你想測量肌肉力量，你可以進行握力測試，但這仍然需要回到有設備的地方，這有點困難。至於肌肉力量，我們其實可以在日常生活中自行評估。例如，走路或爬樓梯時，我是否覺得越來越疲憊？通常情況下，我爬到三樓應該毫無問題，但在減肥期間，如果我爬完一層樓就突然氣喘吁籲，或者我的小腿和大腿感到酸痛無力，這些都可能是肌肉力量下降的跡象。

### 蛋白質攝取與預防停藥復胖

>> 現在，我們來看第四個問題。每個人都害怕停藥或減肥結束後體重反彈。你覺得我們應該提前準備些什麼？

>> 研究表明，體重反彈幾乎不可避免，因此你需要做的準備就是盡力保持肌肉量。另一個關鍵點是，我們仍然需要在飲食中攝取足夠的蛋白質，一般建議每天每公斤體重攝取約 1.2 至 1.6 克蛋白質。便利商店裡的一塊雞胸肉可能含有 20 到 30 克蛋白質，因此您可以根據目前的體重計算您所需的蛋白質含量。透過進行阻力訓練並補充足夠的蛋白質，可以降低肌肉流失的可能性。肌肉量得以保留，就更容易確保減肥過程中減掉的是脂肪。

此外，如果有些人需要服用藥物，一些研究表明藥物也可以用來維持較低的體重。

>> 所以，正如你所說，減肥過程中蛋白質的攝取非常重要，但我們也不應該忽略運動的重要性。如果你只攝取蛋白質而不進行鍛煉，實際上很難維持甚至增加肌肉，因此後續的肌肉刺激仍然非常關鍵。我經常遇到這樣的人：“醫生，我害怕肌肉流失”，所以他們瘋狂進食，甚至每公斤體重攝取近 2 克肌肉。但除了會造成消化不適外，你的肌肉也未必更容易維持，你甚至可能無法增肌，反而會更快增加脂肪。所以，我認為調整整個生活方式才是更關鍵的因素，而不是只依賴單一習慣來改善整體健康。

>> 這是正確的。至於注射，我認為如果你正在服用藥物，你必須和你的醫生討論一下你停止服用藥物的方案。在停止或減少藥物用量的同時，我們如何幫助您維持減肥效果？否則，辛苦減肥之後，停止服藥又反彈，會造成很大的精神和實際壓力。

>> 確切地。景醫生，既然我們提到了減少藥物用量，我想請教您：在您的臨床實踐中，您是否觀察到逐漸減少注射劑量有助於防止體重反彈？

>> 是的，停藥後大約兩到十週，體重曲線往往會恢復到治療前的狀態。所以，關鍵不在於減少藥物的速度，而是在過程中你的大腦食慾調節是否仍然受到抑制，從而使你失去對某些食物的渴望。我們希望幫助您養成這些新的飲食習慣，當然，如果您還能建立起運動習慣，那就更好了。

如果您擔心反彈，我們建議採用逐步減量的方式逐步調整劑量。研究表明，之後維持較低劑量也是有效的。

>> 我也想分享一下我們診所的做法。事實上，除了討論藥物治療之外，我們更重視在此期間幫助您養成健康的飲食習慣。透過自然觸發足夠的飽足訊號，停藥後您無需依靠意志力來對抗所謂的「食物誘惑」。因此，我認為養成這些飲食習慣是繼續減肥之旅中最關鍵的部分。

### 黃金減重比例與診所診療流程

>> 一些觀眾想知道什麼是「黃金」減肥比例。一般醫學研究通常以 3:1 的比例作為參考，這意味著減掉的體重中 75% 來自脂肪，而剩餘的 25% 來自非脂肪組織。然而，其他研究表明，為了獲得更好、更高品質的減肥效果，你可以達到高達 6:1 的比例。您如何看待這個比例？或者，當你在診所遇到減重患者時，你如何幫助他們維持這種高品質的減重狀態？

>> 首先，你必須知道它是否真的是 6 比 1。減肥是一個長期的過程，所以我們每隔一到兩個月進行一次 InBody 掃描。這使我們能夠評估肌肉量下降的原因，並立即提供建議。關鍵在於不要自行調整；如果你的劑量經常波動，那其實並不理想。

>> 是的，正是如此。當然，我們希望同時實現增肌減脂，但至少要實現高品質的減肥，並將肌肉與脂肪的減少比例保持在健康狀態。

正如您之前提到的，如果患者想要使用藥物或減肥，他們應該尋求專業人士的幫助。在您的診所，您如何為他們制定計劃，或者您使用什麼樣的減肥流程圖來安排合適的流程？

>> 通常，我們會先檢查他們的 BMI 和腰圍，然後再進行 InBody 掃描。由於我們是國家健康保險覆蓋的診所，如果患者符合成人健康檢查的條件，我們將為其進行健康檢查。它包括血壓、腰圍、血糖、三酸甘油酯、膽固醇以及肝腎功能檢查，從而可以更全面地評估一個人的整體健康狀況。

接下來，我們將提供一些飲食和運動建議。如果患者在治療過程中想要使用藥物，我們通常建議他們至少進行一次腹部超音波檢查和一次甲狀腺超音波檢查。

在這個階段，大多數人可以透過飲食和運動，或者藉助藥物的幫助，達到理想的身材比例，甚至實現高品質的減肥。

>> 我也同意醫生的說法；在我們的診所，我們也經常為客戶提供非常詳細的評估和檢查。除了檢測部分，除了常見的「三高」指標外，我們還會檢查他們的胰島素抗性情況，或者是否存在任何潛在的內分泌或激素問題，例如甲狀腺功能減退症、與女性激素相關的多囊性卵巢綜合徵，甚至是壓力激素。所以，我認為在減重期間，透過檢測和定期追蹤進行幹預是絕對必要的。

由於每個人的目標都不同，因此在進行 InBody 掃描時，我們總是告訴客戶，男性和女性的體脂百分比目標並不相同。對於男性而言，理想情況下體脂百分比應低於 25%，或更好的是低於 22%，以降低「三高」症的風險。為了確保健康，女性的睪固酮水平不應超過 27% 或 28%。因此，你需要詳細了解自己的身體狀況，才能準確地設定目標。

>> 肥胖醫學協會建議，如果您按照減重流程圖進行到最後，但在六個月內仍未達到目標，則可以考慮進一步的手術介入。這些手術通常具有一定的不可逆性。我們可以使用內視鏡縫合並縮小胃部，以減少食物的空間；或者也可以進行手術，直接切除部分胃並進行旁路手術。這些是較新的內視鏡或外科手術程序，代表流程圖的最後階段，適用於罕見病例。
