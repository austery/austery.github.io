### 算力稀缺与推理时代的Token爆炸

在过去的一年里，整个AI行业目睹了**算力稀缺**的急剧恶化。作为大模型算力基石的 **NVIDIA H100** GPU 价格打破了硬件价格随时间下降的常规规律，较去年底的低点上涨了约 40%。与此同时，随着**推理模型**（Reasoning Model: 具备多步思考和深度推理能力的 AI 模型）的兴起，**测试时算力**（Test-time Compute: 模型在推理阶段用于思考和搜索的计算资源）变得至关重要。思考 Token 的引入导致代币消耗量呈指数级暴增——推理模型消耗的 Token 数量是非推理模型的 8 倍，且预计在未来一年内还将再翻 5 倍。这种 Token 吞吐量的激增极大地加剧了算力限制。

这种算力瓶颈已经开始冲击行业生态。由于推理算力的严重受限，某些前沿 API 的访问权甚至开始被限流或关闭。例如，**谷歌**（Google）最近因推理算力限制，封顶了 **Meta** 对 Gemini 的调用额度；而 **OpenAI** 则开始销售“Token 期货”以保障未来的代币算力容量。这种商业行为的背后，是服务商对算力不足的真实担忧，他们必须在推理阶段优先保障第一方自有产品。在算力受限且急需提升模型性能的当下，优化数据质量成为了无可避开的关键路径。

### 数据质量：突破算力限制的乘数效应

数据质量是一个被行业严重低估的**算力乘数**（Compute Multiplier: 通过优化数据质量而非增加算力来成倍提高模型学习效率的机制），因为它能够让学习曲线显著变陡。在模型性能与训练开销（或数据、时间、资金）的关系图谱中，通过提升数据质量，我们可以将平缓的灰色学习曲线弯曲成高效的蓝色曲线。这意味着在相同的算力预算下，你能够获得远超平庸数据训练出的性能；或者在极低的算力成本下，达到相同的模型效果，实现十倍算力的节约。

在技术底层，这一过程的本质是最大化每个 Token 和每个批次（Batch）的**边际信息增益**（Marginal Information Gain: 每个新样本能教给模型的未解知识量），即最大化每个展示给模型的数据点的信息信号。世界上并不存在适用于所有任务的“万金油数据集”，数据集的优化必须紧密围绕下游的特定任务展开——例如，要训练出色的法律模型，法律数据的权重必须远高于医疗数据。同时，数据必须具备高度的**多样性**，以消除模型因训练数据过于单一而产生的脆弱性与过拟合。面对来源各异的异构数据，如何将其进行科学的混合与排序，是释放模型最大潜力的关键。**Datology AI** 并不像传统数据商那样去开采新的 Token，而是将自己定位为“数据炼油厂”（Oil Refinery），通过 Clean（清洗）、Curate（筛选）、Create（生成）和 Compose（组合）这“4C 法则”对公开、私有和授权数据进行深度提纯。

### 数据炼制管线：从清洗到合成的四阶段方法

我们将数据炼制过程标准化为四个关键阶段：
1. **Clean（清洗）**：这是最基础的门槛。除了使用启发式过滤器（如 Gopher）过滤掉字数极少或乱码的无效文档外，最核心的任务是**基准污染去重**（Benchmark Decontamination: 剔除数据集中与下游评估测试集重合的样本）。我们使用超低 N-gram 匹配算法对所有训练数据进行清洗，防止模型通过记忆测试题获得“伪高分”，从而客观解释模型的真实能力。
2. **Curate（筛选）**：清洗后的数据仍是未经雕琢的粗盐。我们通过分类器、主题分类学和**语义去重**（Redundancy Reduction: 检测并移除语义高度相似的冗余信息）进行数据筛选。即便两个文档字面不同，如果传达的内容一致，也会被去重。随后，利用上采样和下采样调整数据配比，实现任务分布匹配。
3. **Create（生成）**：高质量数据筛选后通常规模有限，此时需要引入**合成数据**。我们采用一种被称为“文档改写”（Rephrasing）的精细数据增强方法，将原始的高质量文档转化为问答对、真假判断等数百种格式。由于这些信息完全基于真实的输入文档，能有效规避**模型崩溃**（Model Collapse: 递归使用 AI 生成的数据训练导致模型输出逐渐退化并丧失多样性的现象），同时极大地扩展了数据的多样性与规模。
4. **Compose（组合）**：在拥有多个清洗和扩充过的数据集后，如何将它们在多个训练阶段中进行合理地排序与组合至关重要。目前多阶段训练已是主流，通过构建**连续课程学习**（Continuous Curricula: 根据模型学习进度，动态调整训练数据难度与种类的渐进式训练策略），可以使模型在不同阶段吸收最适合的知识，最大化训练效率。

### 弯曲缩放定律：多模态大模型的优化实证

我们在 Meta 工作期间发表的 NeurIPS 最佳论文《**Beyond Scaling Laws**》奠定了 Datology AI 的理论基石。该论文证明：通过正确选择数据，我们可以扭转传统的**缩放定律**（Scaling Laws: 随着计算资源、数据量和模型参数增加，模型性能呈幂律提高的经验规律），改变其指数曲线。因为高质量数据让模型避免了在冗余或无效的 Token 上浪费算力。

我们在**视觉语言模型**（Vision-Language Models: 能够同时理解图像和文本的多模态大模型）上进行了实证研究。通过对仅含 250 亿 Token 的 Mammoth 数据集（用于训练视觉与文本模型之间的融合适配层）进行数据精炼，在保持所有其他训练参数不变的情况下，模型的性能指标实现了 14% 的绝对值提升。更惊人的是，在不进行任何后期训练（Post-training）的情况下，我们仅用 1/145 的训练算力就基本达到了 **Qwen 3.5 4B** 的性能表现。

此外，合理的数据清洗还能显著优化模型的推理效率。推理阶段的消耗正在急剧上升，而经过 Datology 精炼的数据训练的模型，不仅回答更加简洁，且在每次生成正确答案时所需的**推理算力成本**降低了 35 倍，成功在推理侧打破了算力边界。

### 跨语言迁移：数据蒸馏破除互联网语言偏见

在纯文本模型领域，由于互联网语料存在极强的西方及英语偏见，现有多模态模型在非西方语境下的表现普遍不佳。这限制了 AI 技术的公平性与全球普惠。

我们通过数据精炼展示了如何低成本攻克多语言难关。在多语言 MMLU 评估中，我们仅投入了 8% 的多语言 Token（大多数非英语语种的数据量上限仅为 60 亿 Token），便以 1/8 的算力预算超越了著名的 **Qwen 3**，打破了非英大模型必须依赖海量语料灌输的偏见。更重要的是，我们验证了**跨语言迁移**（Cross-lingual Transfer: 大模型将在一种语言上学到的知识或能力，应用或迁移到另一种语言中的能力）现象。仅仅对英文数据进行高质量筛选，就能显著提升西语等非英语语种的模型表现。这种跨语种能力迁移的强弱与该语种同英语的词汇和语法相似度高度正相关。

此外，基于精心筛选的数据，即使是参数量庞大的 **LLaMA** 架构模型，在训练 1 万亿 Token 时也能展现出极高且可预测的**缩放稳定性**。这使得研究团队可以先在极小的计算规模下对模型进行测试验证，有效降低了后续进行数万亿 Token 规模“终极训练”（Hero Run）的算力打水漂风险。

### 行业微调与全尺寸模型：高性价比的预训练实战

在商业落地上，**Thomson Reuters**（汤森路透）利用 Datology AI 对 1000 亿 Token 数据进行了**混合训练**（Mid-training: 在预训练后期，使用通用与特定领域数据混合进行的继续预训练）。仅消耗不到 1% 的预训练算力，其法律推理能力即提升了 5 个百分点，且毫无**灾难性遗忘**（Catastrophic Forgetting: 神经网络在学习新任务后，突然且彻底失去之前学到的任务知识的现象）。更关键的是，在其原有的后期对齐微调框架下，该混合训练模型所带来的微调性能增益几乎翻了三倍。这表明预训练阶段的高质量领域数据输入，能显著放大后期微调的效果，证明了预训练、混合训练与微调必须进行全盘的协同设计。

另一个典型案例是 **RCI** 的 Trendy Large 模型。该团队在去年中之前没有任何大模型训练经验，但在 Datology 提炼的 17 万亿无闭源模型污染（即未使用 Claude 生成）的公开数据加持下，仅用低于 2000 万美元的总体预算（包含人力、R&D、多轮实验及算力），就成功训练出了能够与 GLM5、Kimi 甚至 Claude 匹敌的前沿大模型。这彻底打破了“只有数亿美元投入才能做出前沿大模型”的行业神话。

总结而言，数据质量是目前被严重低估的算力乘数。在 Token 和算力日益受限的未来，提升每个 Token 的信息密度，并在多维度上进行科学的数据评分和海量规模（PB 级）提炼，才是破局的根本之道。
