8 月 13 日晚，DeepSeek 发布了 DeepSeek Harness，简称 DSH（有朋友cuimao等戏称单身汉）

不到两小时，DSH 的 GitHub Star 破万。

12 小时后超 5 万，两天后接近 9 万，成为 GitHub 史上涨星最快的项目之一。

Harness 的原义是马具、缰绳，今天逛辽宁朝阳博物馆，刚好看到个图。😂😂😂

简单说：Harness 是让模型能当 Agent 干活的那套外壳。

DSH 的设计理念比较特别，核心是“一切皆插件”。

模型、工具、技能、会话、沙箱、UI，全都可以像搭积木一样替换和重组。

基于这个理念，所以 DSH 内测邀请了一堆大佬开发插件。

DSH 上线当天，开源仓库的 ⁠dsh-plugin 话题，立马出现上千插件仓库。

贡献者里一堆二次元头像，比如当天 Star 第一和第三，作者都是 B 站 UP 主。

现在，二次元头像已经成了 AI 技术圈的“大佬”特征之一，哈哈哈。

下面讲讲如何安装 DSH，再介绍推荐一些热门插件。

## 如何安装 DSH

DeepSeek Harness 的运行时基于 Node.js，一共有三种安装方式，支持 Windows、Mac、Linux。

详细安装教程：

> https://www.runoob.com/deepseek-harness/deepseek-harness-install.html

以 Mac 为例，打开电脑默认终端（或Warp、Ghostty、cmux、kaku等第三方终端），输入下面命令，然后回车。

```
<code class="language-bash">npx @deepseek-ai/dsh web</code>
```

安装后会自动打开浏览器，没有的话在浏览器输入

> http://localhost:3080

最后，输入 DeepSeek API Key 就能开始用，没 API 可以到下面网址充钱，创建 API：

> https://platform.deepseek.com/

不过，装上之后，多数人的反应可能是：这玩意儿怎么这么难用？哈哈哈

因为 DSH 出厂是毛坯，图片识别、@文件引用等这些基础功能都没有，全靠插件补。

下面介绍几个热门插件和可能需要补的基础插件。

## Colleague-skill（同事 skill）

当天 Star 第一插件，作者是 B 站 UP 主 @只是路过的titanwings。

本名周天奕，24 岁，在上海人工智能实验室工作。

项目的起点是他看到一条新闻：国外某大厂裁员，要求员工离职前自己提交一份 Skill。

他由此想到：同事离职了，他的经验怎么留下来？

如何“将冰冷的离别化为温暖的 Skill”（From 仓库介绍）。

因为文档只能记显性知识，一个人真正的工作方式，他的决策习惯、代码规范、遇到问题时的处理逻辑，这些东西不会写入文档。

colleague-skill 的思路是直接从原材料里“蒸馏”，把飞书消息、钉钉记录、Slack 聊天、微信记录、邮件、PDF 喂进去，加上你对这个人的主观描述，生成一个真正能接替他工作的 AI Skill。

周天奕说，他只花了 4 个小时搭出了第一版。

生成的 Skill 有两个维度：Work Skill 负责工作能力，记录技术规范、决策逻辑、处理问题的方式。Persona 负责人格，记录沟通风格和说话习惯。

两个维度可以单独调用，也可以组合。

社区很快发现边界远不止"同事"。

有人蒸馏了前任，有人蒸馏了偶像，有人给自己留了一个数字分身。

项目因此从"同事交接工具"进化成了 dot-skill，任何人都能被蒸馏成一个 .skill。

社区里已经有人做出了"户晨风.skill"和"罗翔.skill"。

目前 GitHub 超过 2.1 万 Star，社区产出了 215+ 个 Skills，165 位贡献者。

周天奕还为这个项目发了一篇 arXiv 论文：《COLLEAGUE.SKILL: Automated AI Skill Generation via Expert Knowledge Distillation》。

安装到 DSH ，终端输入：

```
<code class="language-bash">mkdir -p ~/.dsh/skills
git clone https://github.com/titanwings/colleague-skill \
  ~/.dsh/skills/dot-skill</code>
```

装好后输入 /dot-skill 启动，输入数据来源就能“蒸馏”出同事或名人 Skill，甚至只靠描述也行，例如：

项目地址：github.com/titanwings/colleague-skill

论文地址：arxiv.org/abs/2605.31264

作者 B 站：space.bilibili.com/23106195

用这个Skill“蒸馏”出的纳瓦尔Skill：https://github.com/joeseesun/celebrity-naval

## OpenBiliClaw

当天 Star 第三插件，作者也是 B 站 UP 主，ID是 @littlewish，本名 whiteguo233，BIP 大赛参赛选手。

他想解决另一个问题：凭什么让平台算法决定你看什么？

B 站、小红书、抖音的推荐系统都是根据你“看过什么”来推“你还会看什么”，容易进入信息茧房。

平台会用你的历史行为预测你的未来偏好，OpenBiliClaw 是把这个顺序反过来。

先帮你建立你的心理画像，再带着画像去主动搜内容。

通过你在各平台的使用行为、反馈和对话，构建五层用户模型。

画像建好之后，Agent 跨平台主动去 B 站、小红书、抖音、YouTube、X、知乎、Reddit、微博等找内容，每条推荐都附带理由，防止因封面或标题错过真正想看的东西。

整个项目本地运行，数据不上传，MIT 协议开源。

安装到 DSH ，终端输入：

```
<code class="language-bash"># 1. 安装 OpenBiliClaw 后端
curl -fsSL \
  https://raw.githubusercontent.com/whiteguo233/OpenBiliClaw/main/scripts/install.sh \
  -o /tmp/openbiliclaw-install.sh
</code>
```

bash /tmp/openbiliclaw-install.sh

# 2. 如果安装器没有成功启动后端，补齐依赖并启动

if ! curl -fsS http://127.0.0.1:8420/api/health >/dev/null 2>&1; then
cd "$HOME/OpenBiliClaw"

python3 scripts/agent_bootstrap.py 
--project-dir "$HOME/OpenBiliClaw" 
--mode local 
--host 0.0.0.0 
--port 8420 
--skip-ollama-setup 
--skip-init
fi

# 3. 安装真正的 DSH 客户端插件

dsh plugin --profile web add --ignore-scripts 
'@openbiliclaw/dsh-plugin@github:whiteguo233/dsh-openbiliclaw#5cde8b54a628777ae1c7fa153ea90a61d0b91136'

# 4. 永久启用插件

patch_file="$HOME/.dsh/profiles/web/cordis.patch.yml"

if ! grep -q "id: openbiliclaw" "$patch_file" 2>/dev/null; then
tee -a "$patch_file" >/dev/null <<EOF

insert:

id: openbiliclaw
name: '@openbiliclaw/dsh-plugin'
config:
workdir: '$HOME/OpenBiliClaw'
EOF
fi

# 5. 验证后端

curl -fsS http://127.0.0.1:8420/api/health

# 6. 验证 DSH 已识别插件配置

dsh --profile web --dump-config |
grep -A6 -B2 openbiliclaw

## 基础 DSH 插件推荐

除了安装热门插件，建议安装下面的基础插件。

modlens：给DeepSeek这个文本模型装上眼睛，粘贴截图读图，前端调试、图表理解必备 dsh plugin --profile web add @liustack/modlens@latest

dsh-at-file：输入框输入 @ 引用工作区文件，高频刚需 dsh plugin --profile web add github:dsh-external/dsh-at-file

dsh-paste-input：让 DSH 支持 Ctrl+V 粘贴文件、拖文件进对话框 dsh plugin --profile web add dsh-paste-input

dsh-cc-tui：Claude Code 风格终端界面，上下文进度条 dsh plugin --profile web add dsh-cc-tui

dsh-web-ui：Web UI 全家桶，任务看板、Git 图谱、实时 token 统计、移动端远程。 dsh plugin --profile web add dsh-web-ui

dsh-memory-evolve：跨会话长期记忆 dsh plugin --profile web add dsh-memory-evolve

对小白用户来说，没必要没苦硬吃，强烈建议安装界面版 DSH。

客户端下载地址：

> https://www.dshdesktop.cn/

## 写在后面

DSH 现在还是开发者预览版，出厂毛坯，官方甚至暂时不接受外部 PR。

但正因为架构足够开放，社区两天内就涌进了近三千个插件仓库，这速度比任何一个团队单打独斗都快。

一个框架的生命力，很大程度上取决于它能不能让有能力的人愿意在上面搭东西。

DSH 目前看起来做到了这一点。

另外一个有趣的观察：以前大家开玩笑用头发多少判断技术水平，现在基本看头像是不是二次元画风！

DSH 插件榜前排，几乎清一色二次元动漫角色头像，偶尔出现其他，反而显得格格不入。

B 站是国内最大的二次元社区，也藏着一批超级能打的 AI 产品创作者。

大家基操也很一致：GitHub 发项目，然后在 B 站讲清楚自己做了什么、解决了什么问题，第一批真实用户就从这里来。

colleague-skill 两周涨到 1.4 万 Star，OpenBiliClaw 从大赛参赛项目做进热榜前三，背后都是类似逻辑。

GitHub 决定项目能不能被找到，B 站决定有没有人真的去看、去用、去传。

对开发者来说，能写代码只是一半，能把自己做的东西讲出去，才是完整的。

纳瓦尔说的 Build & Sell，放在今天国内开源生态里，B 站正在成为 Sell 这一半最重要的场域之一。

DSH 刚开源没几天，这个生态才刚开始长。
