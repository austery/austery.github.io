## 网站生成

最近 DeepSeek Harness 开源，火爆全网，短短几天诞生了数千个插件。

让豆包监控 Github 仓库，定时抓取新增插件，制作一个持续更新的网站，提示词如下：

> 持续整理监控这里的新增项目，制作成一个网站介绍这些插件：https://github.com/topics/dsh-plugin

扫码发现 5000 多个插件，但第一版生成只列了100多个插件，我提出了质疑。

豆包给的第二版，增加到 1000 多个插件，开发用的云电脑，支持在线预览和分享。

有个功能容易被忽略，就是预览窗口右侧的“编辑”，点击会进入编辑模式，可以标记页面元素，调整页面设计。

另外，点击“刷子”图标会出现侧拉层，有大量网页设计风格可选，能有效降低网页 “AI味”。

其他网站生成方法同理，如论文学习网初始提示词：

> 监控这个网站，生成一个论文阅读站，名字叫乔木论文推荐读，同步日榜、周榜和月榜，但内容都要用中文，列出论文亮点，用 1-10 分打分是否值得阅读。 https://huggingface.co/papers/

建议用豆包云电脑，好处是能一直运行，实现监控 Huggingface 论文更新同步。

## 交互课件生成

儿子9月开学就要上初中，找了一份人教版初一数学教材，整个 PDF 丢给豆包，输入提示词：

> “把 PDF 变成一个支持互动学习的 HTML 课件，方便学习初一数学上册。”

用类似方法，能把任意 PDF 教材，变成方便学习的 HTML 课件、配套测试题和闪卡。

最棒的是，很多公式都能可视化，孩子学起来更直观。

## 飞书文档和 PPT 生成

豆包和飞书团队合并，打破部门墙后，功能整合果然大大加速。

比如你在豆包客户端中，可以把任意内容写入豆包文档（其实就是飞书文档），非常适合协作沟通。

下面是我让豆包生成的关于短视频如何吸引人注意力的调研报告。

> https://feishu.doubao.com/docx/THFZdhBw9oUQi8xigaHcf4BfnCh

如果有了豆包文档（飞书文档），一句话就能转成PPT：“把这篇文章变成精美的PPT”。

第一版觉得封面不好看，继续提要求：

“首页生成的封面太丑了，还有其他页面如果可以生成好看的配图，也可以加入到 ppt 中”

这时，豆包客户端会调用 Seedream 生图能力，生成 PPT 背景。

最让人安心的地方，PPT 中的每个文字都能编辑修改，还能共享给别人一起完善。

做完 PPT，直接就能预览演示。手机端也能打开查看，很适合当提词器。

## 多媒体生成

豆包电脑客户端之前就内置了 Seedream 和 Seedance，一个用来生图，一个用来生视频。

加上豆包 2.1 大模型支持的 Agent 后，可以组合出更多玩法。

最近“牛来”电影爆火，很多人做各种梗图、二创视频。

网上随便找张原图，输入提示词：

> 用 10 个不同设计师风格重绘我给你的图片，然后做成一个 HTML 幻灯片发给我

用这种方法，不仅能生成图片、生成视频，还能直接内嵌到网页中展示，非常适合交付作品。

## Vlog 视频制作

前几天去辽宁朝阳旅行，参观了古生物化石博物馆，拍了不少照片。

于是想能不能用豆包工作模式制作Vlog？

打开豆包手机端，点输入框上方的“快速”，弹出菜单中选“工作任务 Turbo”，这时会切到豆包工作模式。

最多支持选20张照片，输入提示词：“把选择的图片内容生成一个旅行vlog视频。”

等了一会儿，一段类似苹果 iOS 回忆功能的 vlog 视频就做好了。

（注意：如果调用生图工具，可以打断，要求只用图片生成视频）

豆包手机端与电脑客户端完全打通，电脑端也能看到这个任务，是在用“云电脑”执行。

第一版视频没字幕介绍，想起豆包 2.1 模型支持多模态，要求识别图片内容，生成视频时给每张图来个标签。

做完比较满意，顺手让豆包做了一个 Skill。

除了图片生成视频，豆包客户端也支持调用 Seedance 2.5 直接生成视频，这里就不演示了，可以自己探索。

## 写在后面

体验完新版豆包电脑客户端，说实话，比之前的对话版豆包强很多。

果然 Agent 才是王道！

豆包 + 飞书，对办公场景来说，实在是王炸组合。

另外，个人很喜欢云电脑模式，因为能一直在线，手机也能操控，很适合开发需要定时抓取更新的网站。

哪怕合上笔记本，任务仍在跑，手机上随时看进度，换一台电脑，也能无缝衔接继续干。

真正的 7*24 小时助理，还得靠云端。

不过本地电脑也有特定优势，数据不出本机，上下文更丰富，私有 Skill 更多、更全。

需要哪种，取决于你手头的任务，不存在哪个更好。

但有一点很确定，豆包工作模式很赞，值得抓紧用起来。

省下来的时间，才是真正属于自己的时间。
