### Muse 为何在北美大火

**主持人**: 聊一下最近大火的 **Muse** 哈。闲哥作为北美人民，你给我们讲一下，为什么这个 Muse 在北美大火？

**闲哥**: 这个 Muse 火，我觉得有两个原因。咱先说一个简单的：北美人太习惯用邮件和各种网站去处理事情了。Muse 把 **Agent** 能力接进来之后，很多人发现原来真的有这么一个东西，AI 原来真的能代客上网，去帮我买东西、处理事情。现在有个产品出来，又是免费的，别人都用，我也觉得挺好用，慢慢人传人就传播开了。这点上也反向说明 **Meta** 本身真的是擅长做这种 ToC、社交类的东西。

但更深一方面，我觉得从咱们中国人角度来讲是什么样？这个 Muse 就相当于是私人企业的**董事长助理**。什么意思呢？就是说他不光能干公司的事，更重要的是能帮你处理点私事，老板那些不愿意见的人、不想办的事，他能帮你干了，让董事长老婆没有怨言，最关键的是他还嘴严。

所以我觉得 Muse 就踩着这个点。比如说举个例子，信用卡账单上面有些该取消的订阅，有些时候一个月扣几块钱、十几块钱那种，你说疼吧也不疼，但凑一块难不难受？肯定难受，算下来一年也好几百呢。那这种事情让 Muse 去帮我找找，人就真能给你找；你说你帮我取消一下，他真能想办法给你发邮件去取消订阅，甚至跟客服联系申请退款。如果是一个上市公司老板，他想省的是什么？一是省时间，二是省心，三是嘴严，这 Muse 都干到了。

**主持人**: 但你觉不觉得这是一个非常牛逼的洞察？这就是因为**北美互联网太碎了**，碎到说恨不得连买菜都是专门一个网站。小扎这个 Muse 其实基本上我们说难听点就是“代客上网”，把北美这么碎片的互联网给串起来了。

而且它做得特别好的一点，是让大家忘记了**基模拉胯**的事情。今天谁讨论扎克伯格、讨论 Meta 的基模拉胯？没人讨论，人家就觉得 Muse 好用、Muse 香。

**闲哥**: 不是，我一上来用 Muse，我就先问他：你后端基模是什么？你的虚拟主机是多少？我跟你讲，你后面有没有放 **Kimi**、有没有放 **DeepSeek**，我都是打个问号的，不得而知了。但没关系啊，这个事情给你干成了就好。我觉得这是他做得非常成功的一点，让我忘记了基模的存在。

最近小扎上节目也顺水推舟，讲了这个事情：“我们这个 Muse 背后的模型，是专为 Agent 训练的。”不再考虑刷榜那些事了，不跟你们比那套，我们换赛道。

### 算不起的账与踹门策略

**主持人**: 作为一个中国人，我之前比较惊讶的是，为什么之前别人不做？你说这个事谁该做？**Google** 就该做，可是 Google 做了个 **Spark**，到现在还是测试版；Apple 也不做。

**闲哥**: 不不不，你忘了一个事情，**Manus** 满7个月无理由退货这个事情。Muse 这个产品，我以前是很不屑 Meta 的东西的，但 Muse 这个产品体验还是非常好的。比如说要你输入密码，人家还有专门的 UI 让你去输入密码，不用你自己去操作，不用发成明文。就这些体验，我就不信老美能干那么细，这背后肯定有神秘的东方力量。Manus 也出了 2.0 版本，里面还有一个专门叫 Q 的 Agent，大家可以逐帧对比找不同。

**主持人**: 收回来收回来。接着刚才的话题，我真的很惊讶为什么北美之前这么多大厂不做？Google 该做吧？Apple 该做吧？都该做，但为什么都不做？后来我明白一件事，我觉得不做的原因就是因为**算不起账**。

这事不赚钱。你给私人做 Agent，谁给你付钱啊？你做对公的，像 Grok 也好，还是 GPT 工作流也好，都有明确的场景，以前几天能做的事现在几个小时做完，用户就得付钱。但你做 Personal Agent 谁付钱？

你不觉得这个事情是这样吗？二线厂商是用户为产品付钱，一线厂商一定是“羊毛出在猪身上，狗来买单”。Meta 做 Muse 这个东西，一定是不希望羊自己付钱，一定是羊毛出在猪身上让狗去买单，Meta 一定是要赚这个钱的。所以他也得“踹门”，他要去掠夺、去抢、去整合。

你说 Meta 做这个事情本质上是什么？我跟你类比一下，本质上就是**在美国做个微信**！又有社交入口，又有个人助理，还有小程序、支付、电商，说不定后面还能刷小视频。这就是扎克伯格的野心。

**闲哥**: 你刚才说“踹门”这个太形象了。这个事情不靠踹门哪里来？你不去发现新大陆，谁封你做土皇帝？

小扎苦 Apple、苦 Google 久矣。自己没有入口，没有生态，没有 OS，不太上得了台面，川总出门也不太带你。你个做社交、赚广告费的，不受待见，不搞供应链，不搞算力。小扎以前也是很有野心的人，现在野心也藏不住了，只不过前几年比较背，布洛芬都不知道他有多痛。

他现在不是憋着一口气，我觉得真的是一直吊着一口气。这口气万一哪回喘不上来，有可能就是最先被干掉的“七朵金花”之一了。所以 Meta 这个 Muse 是必成、必做，而且一定不能失败的事情，小扎有点毕其功于一役的感觉了。你看他发布会一直在聊 Muse，甚至说要给 Muse 做硬件；跟 **Amazon** 决裂也没关系，一定要把这扇门踹开，把别人的钱先装到自己兜里面。

你说为什么别人不做？没人敢，这个门谁敢踹？踹亚马逊的门，是 OpenAI 能踹的吗？OpenAI 不敢。踹苹果的门，谁敢踹？放在整个美国，可能就小扎敢踹，而且小扎是真敢踹的人，他是个狠人。Google、Apple 都是体面人，西装革履打领带的，不能互踹。小扎随时都光着膀子，心想：“我已经忍你们很久了，好歹一年也赚几百上千亿，你们国会晚宴不带我，买单的时候叫我，加官进爵的时候不叫我。”

### 商业算法的重构与生态博弈

**闲哥**: 不过咱们也不能光看产品，还是要算账。一开始我陷入一个误区，老想算 Meta 这两年承诺和真正投出去的几百上千亿什么时候能赚回来。就像梁文锋说的，我买批卡或者买硬件，十个月之内得先回本，只要拿到这个钱就可以不用赚钱了。

但后来再算这笔账，尤其是看了 Connect 大会之后股价往上涨，我就开始反思：这笔账不能这么算，还是要看他能从别人那里抢多少钱。你要想在 Agent 时代做出增量来，他和 OpenAI、Claude 还不一样。OpenAI 可以卖套餐、卖 Pro，因为他们是川普供应链的重要一环，处在关键点上，谁也撤不了他们。

但 Meta 不是，Meta 芯片不行，云服务不行，模型也不见得最强，Muse 这件事关键看他抢了谁的钱。他踹的是亚马逊的门，如果真把亚马逊每年几百亿的广告费捞点过来，再加上股市对新产品的认可，未来卡住一个新的入口通道，联合当地的小豪杰，那带来的价值就远不是之前投入的几百亿成本了，股价涨个百分之十几二十全回来了。所以不能只看算力投入和有多少人买单 Token，过几年看，这可能是一个非常重要的转折点。

**主持人**: 那你觉得他下一步会踹谁的门？

**闲哥**: 我觉得下一步踹的就是 Apple。发布会他说要给 Muse 做硬件，这也是 OpenAI 和 Apple 一直心心念念的事；再加上去掉摄像头的眼镜，没准真走出一条新路来。

但这毕竟是赌。苹果是现成的，苹果今天什么都可以不做，Mac mini 卖得好好的，妥妥的算力黄金，不需要做什么应用，自己本身就是算力的一部分。但在中国人看来，你不能坐吃山空，但苹果可能就觉得躺平赚钱就可以了。对 Meta 来说也简单，踹门不丢人，能赚钱就行。

**主持人**: 这就是个悖论。小扎野心特别大，但他战略基于的是一个掠夺的立场。出师名不正言不顺，天下与你为敌，今天踢到亚马逊这块硬骨头，明天还会踢到别人的。

反过来看，我觉得 Muse 让大家意识到必须开始**重视 CPU** 了。去年大家就喊要重视 CPU，但没有现象级产品。你看 AMD、亚马逊、英伟达都在推出包含 CPU 架构的产品，CPU 的比重会越来越高。我觉得 Meta 应该保持 ToC 的优势，小扎多花点精力去解决 ToB 的黄老板（黄仁勋）、苏老板（苏姿丰），去台湾走几趟搞定供应链，把大家绑在 Muse 这条船上，大家才会推你。今天你要打亚马逊，老黄不支持你怎么办？总得找人支持你，不能全世界都是敌人。

**闲哥**: 没错，锁老黄的产能，其实他之前已经在做了。现在 CPU 变得更重要，对芯片厂来说是个纯增量。以往做 GPU，现在又多了一个 CPU 增量，为什么不做？小扎以一己之力把 CPU 需求拱上去，老黄天天上门跟你抽雪茄聊天。

再过一两年回头看，Muse 的发布真可能是一个转折点：大家不再过分讨论模型的参数和底层能力，更多看的是 Agent 能做什么事、大家愿意为什么 Agent 买单。这跟开超市一样，供应链成熟后，每家都有自有品牌的鸡蛋牛奶，供应商都是那几家国际标准，最后比拼的就是产品定义、定价以及跟供应链的关系。AI 就像新一代的水电基建，最开始做电网赚钱，到一定阶段就是看谁能把电转化成电器、开游戏厅，创造出新的消费场景。

### 流量变现：从 Shopify 到百亿补贴

**主持人**: 小扎过去几年被苹果、Google 这些有 OS、有生态、有入口的巨头压得太惨了，真的是布洛芬都不知道他有多痛，现在鼓起勇气搞了个 Muse。如果 Personal Agent 能够让用户在不知不觉中消耗算力和 Token，这就是成功。但这门生意不是直接为 Token 付费，还是回归到“羊毛出在猪身上让狗买单”。

**闲哥**: 但现在“狗”还没找到对不对？

**主持人**: 也不见得，**Shopify** 不是已经接进来了嘛。在北美和海外，Shopify 背后是大量在亚马逊受不了的商家，或者进不了亚马逊而在外面做独立站的人。做亚马逊苦久矣，要给广告费、进仓管理费，临期还要给处理费，一年流水不错全是给平台打工，自己只能剩一点。

这就存在美国版“拼多多”的机会。阿里这么大的盘子，依然能杀出一个拼多多。亚马逊 650 亿的盘子还没到顶，电商远没有到天花板。国内电商见顶了还能出拼多多，北美更有机会。这些独立站商家就是应该团结的朋友。疫情期间很多人用 Shopify 就是因为亚马逊太卷、抽成太狠，如果 Muse 这边收费低、没有乱七八糟的广告分成，商家就愿意尝试。这就看扎克伯格能不能“农村包围城市”、团结群众了。

**闲哥**: 亚马逊垄断太猖獗，小扎就应该站出来说：“我 Muse 就是要给大家建立一个更公平的世界，更少的抽成，更高的购买效率，大家跟着我干！”搞一个“Muse 百亿补贴”，去把黄老板的炮楼给端了！找个场景，比如二手车买卖，一单几千上万美金，直接把 GMV 做起来，支付也顺势搞定。

**主持人**: 而且 Meta 还有 Facebook 和 Instagram，自身根本不缺流量和用户，大招都还没完全放出来呢。

**闲哥**: 但是前两天看新闻，到七十几万用户的时候大家就觉得反应变慢、开始卡了，说明背后的算力已经吃紧了。真要到四五千万用户，不见得撑得住。所以它的难点不在 C 端，而在 B 端：一是老黄和苏妈愿不愿意撑他，拿多少钱把他们绑在一条船上；二是 Shopify 这些独立站盟主，能不能把他们从原本在 Meta 投广告变成核心供应商，一起反亚马逊。

这两件事干成了，把亚马逊每年几百亿广告费抠出 200 亿过来，拿出 100 亿搞百亿补贴，供应商全上 Muse，做成 Agent 版拼多多；再拿 200 亿跟老黄锁 CPU 和算力；甚至再拿 100 亿买 AWS 的云，让亚马逊电商部门难受。

### 中美生态差异与终局思考

**主持人**: 你这都是贾诩的不留后路之计啊！那这给国内有没有启发？我觉得国内想拆炮楼太难了。字节跳动据说要求几周内快速复刻 Muse 类产品，腾讯也在做自己的云主机 Agent 产品，大家都在盯着 Muse。但中美环境大不相同，在美国做“拆墙”或“踹门”有价值，在中国这个墙拆不了。

**闲哥**: 这里有一点误会，我觉得**美国不是拆墙，美国只是踹门**。大家像北美的独栋房屋（House）一样，每个人有自己的草坪，中间没有栅栏，平时大家自觉不踩别人草坪，小扎是直接上去踹门。而国内不是大楼，国内全是一座座碉堡和炮楼：微信一栋楼，拼多多一栋楼，淘宝一栋楼，京东一栋楼。你在国内除非集团内部打通生态，像阿里打通高德、飞猪、淘系，类似 Google 把 Drive、Calendar 装进 Spark 里一样。

国内大家都在盯 Muse，小扎要是做成样板，微信、豆包也能复刻。这也给生态不够强或者产品分散的厂商打了个样。

**主持人**: 小扎是个狠人，不只是少年得志，中年可能还会有一段腾飞。但他必须把朋友搞得多多的，先搞定老黄、苏妈和供应链。决定胜负手的影响因素，恰恰是 Meta 这种擅长 ToC 的公司最不擅长的 ToB 供应链与生态协同。

**闲哥**: 做公司有时候就是这样，成败皆系于此。明知道自己没有这个基因，但被逼到这个份上，只能揭竿而起去做 Muse。你刚才说他憋着一口气，我真的觉得他是吊着一口气，但起码现在明显喘了一大口气上来。

**主持人**: 无论如何，我们还是希望 Muse 能成功，给这个世界创造多一种可能。那我们这一期节目就聊到这里，大家有什么想法，咱们在评论区见！
