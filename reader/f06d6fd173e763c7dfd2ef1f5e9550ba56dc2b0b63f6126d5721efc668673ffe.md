### 市场大跌与投资心态

[Speaker 1]: OK，好。理发是不可能的，我上次刚刚理过，一周之前还两周之前吧，刚理完发是吧？

但是在我这个频道比较久的一些观众知道，一般来说当市场走得非常不好的时候，我会穿一个红色的衣服，那一天市场是要下跌的；然后走得好的时候就会穿一个绿色的战袍出来。那么希望下一次……有一段时间我记得大家让我去多买几件战袍的时候，那时候是什么时候？22年吧，我记得22年大家让我多去买几件战袍的时候，我真的从亚马逊上买了好几件一模一样的衣服，全是绿色的，现在还在那边，但不咋穿。那是绿色的战袍嘛，有必要的时候可以拿出来。所以今天还是穿了一件红色的T恤，还是应个景吧。

今天是这样的，我没有准备太多的东西，主要是我聊一下市场，然后我会聊一下AI当下的一个现状，包括现在市场所交易的这个逻辑性，我不会做过多的展开。我认为比较重要的是把当下市场——你可以理解为它交易的一个点或者杀跌的一个点——背后的一个逻辑到底是什么呢？交易的这个逻辑能不能去做一个线性的外推？这点是我所希望把它讲清楚的。

然后其他的话，还有个股的话，大家想问也可以问。但是我觉得在这种情况下，聊一些个股的话，我觉得意义可能没有那么的大。聊基本面，昨天我在App里面直播的时候，我说我可以和你聊个股的基本面，我觉得在这时候如果通过我的一些分享，可以去增加对于一些个股基本面的一些conviction或者理解的话，挺好的。但是如果这些理解本身不是来自于内心的话，其实我今天讲完之后，也许可以帮你撑着一天两天。但是如果接下去继续下跌，如果川普扔一个核武器扔到伊朗去，再跌个10%——我昨天聊，我说再跌个10%，结果今天一半跌掉了，今天直接干了5%——我说如果再跌个10%，你能不能坚持得住？那么我今天讲这些内容，可能对你来说其实意义不大的。我不可能每天都在你耳边帮你去讲一些个股基本面的一些东西。真的，当看着价格在下跌，看着账户在下跌的时候，很多时候真的没有一个非常强的conviction是没有用的。

我今天发了一条推嘛，我说当市场下跌，特别是这种下跌的时候，这是一个非常好的考验自己的方法和考验自己conviction的时候，就是在现在这种情况。

我每一次……稍后我和大家分享，起码我和大家做视频以来，今年其实已经是……今天是正好是第七个年头，其实还算是一个纪念日。我是11月4日开始的，是2020年的11月4日开始，到现在已经是第七个年头了。那在这六年的时间里边，其实我们一起经历过很多次下跌了，而大多数比较大幅度的下跌都是在2022年。今天周四下跌的这个波动，反正从我和大家分享到现在吧，排名第三，比现在更多的全部是集中在2025年当时的一个下跌，就是关税那一次的一个下跌。

反正我当时印象还是非常深刻的。当时出现那一波下跌的时候，我是坐在回家的火车上，然后那一天听川普的直播嘛，一块牌子举起来之后，蹭蹭蹭蹭蹭，在盘后就一路下跌的，就是那块牌子惹的一个祸。然后之后那块牌子也撤掉了，然后把很多关税往后延，算是一个比较标准的一个川普的配方。那再之后就是今年的3月份，那今年的3月份当时反正市场也是一顿分析，然后认为这一次川普没办法tackle啦，然后一定要需要三方的这个tackle啊，其实我们也度过了。其实你说这两年的市场其实比较难的，因为整个市场板块、个股之间的分歧非常的大，所以我能够理解。

但从过去两年算上这一波下跌的话，这一波下跌其实挺严重的。从指数这个角度还好，但是从连续程度和速度来说其实挺严重的。但往往我个人的感受啊——大家可以跟我分享你们的感受如何——往往出现这种比较大幅度、比较急速和快速的这种下跌，其实比比较长期的这种下跌会好很多。你回过头来看的话会好很多；站在当下的话，哪种下跌都是难受。要不就是从幅度上给人体感不是非常好，要不就从时间这个角度去折磨。而往往很多时候时间上的这个折磨，其实比速度上的这个折磨来得难得多，真的要来得难得多，因为会把你人的耐心给抹掉。就像今天大家都来听我的这个直播，听一下我到底有些什么东西可以聊的。你今天来一次，你一周来一次，下一周再来，连续来四周、连续来五周，可能这波下跌就结束了。但是22年你知道和现在是完全不一样的，连续10个月、连续11个月的一个下跌，那当然中间一定会反弹嘛。那算上反弹的话，当时那一波熊市是11个月，那时候是真的把市场的信心全部抹掉，但是一样也过来了。

所以没办法，下跌是市场的一部分。而当我们在选择方法的时候，方法也造成了我们现在所看到的这些结果。我的意思就是说，在现在这种情况下，我上几次下跌每次都是这么说，从个人角度来说最简单的方法，你会觉得很轻松的一个方法，就是我为什么去做交易？我为什么不去清仓？我为什么不去做空？然后我聊过很多次，我说对于做空的人来说，无论是在过去两年所经历的25年还是26年，做空本身你会觉得很轻松很简单，然后短期之内做空赚钱了，你会觉得他很厉害。但是你往往发现没有人可以非常准确地看这个市场，有的话你让他站出来。无论是25年也好，26年也好，多数的空头在当时……因为做交易的人比较多的人一定会知道，你是会有这种自我的骄傲和自信、膨胀在里边的。特别在市场大多数的人都在亏钱的状态下，你觉得自己却在赚钱了，通过做空在赚钱，觉得自己是整个市场里面最清醒的那一个人。而多数时候你会发现做空的人他是不知道什么时候出来的。26年也是一样，然后25年也是一样的，根本不知道什么时候出来。

25年是很夸张的。25年当时川普妥协之后，直接紧接着的一天上涨了10%，指数上涨了10%，是历史第二大单日的一个涨幅。26年的话是一个没有非常明显的契机的情况下，然后整个市场就出现了一个反弹，先从养老资金的再平衡，然后慢慢地开始走出来。但是如果从空头的这个思维，或者从你做空的这个思维，认为当时在这一波下跌如果没有三方配合的话，这个战争是不可能结束的。到现在为止，我们在已经看到了第二波整个年内的下跌的时候，战争都没有结束，对吧？但是股市也已经从当时的一个低点走出来，无论是纳指也好，标普也好，指数都已经走出来了。所以当时做空的这个逻辑，你会发现最终反弹的话，也许就不按照这个逻辑去出发了。

我说做空的话是一时爽，但是做空那些人他需要做两个决定：第一个决定，什么时候开始减掉做空的这个仓位；第二个决定，什么时候开始进行做多，并且什么时候开始进行大仓位做多。即使你在那一波下跌或者接近于低点的时候，你开始慢慢地减你的一个做空的仓位，但是在反弹的时候，你不可能非常准确地看这个市场。当市场开始反弹的时候，你觉得做空的人能够在市场的底部就去all in进去吗？即使他能够在底部all in进去，到了4月份和5月份，他难道不会买飞吗？那一定会买飞的，我敢保证百分之百会买飞的。不可能在3月份的时候在那边做空做得非常舒服，然后在3月底的时候满仓做多，4、5月不减仓，整个市场里面不可能有一个人做到，也没有这样的人。

所以这就是我说在市场下跌的时候，是最好地去考验自己的策略到底是不是——特别是对于投资的人来说嘛——是最好地去检验这套方法到底是不是适合自己。在上涨的时候，你会发现从投资这个角度会比较轻松，你只要拿着不动，然后让它上涨就可以了。但是从交易的这个角度，你永远会担心什么时候见底，会不会已经见顶，现在是不是要去做空。甚至于很多做交易的人，在4月份的时候一波上涨完之后，认为5月份一定要下跌，所以5月份进去做空了，对吧？那5月份做空所亏的这部分比例，可能要把4月份非常大一部分的涨幅擦掉。但是你4、5月份一路拿过来的人，对于这些人来说，你马上从交易和投资这个角度就拉开这个差距了。

所以每种策略一定会有它的一个好和它的一个坏，它一定有它的一个弊端和它的一个优势。这就是我说在下跌的时候，是非常考验自己方法的时候，有很多人是坚持不住。在这种时候你会发现我为什么要那么难，看着自己账户的下跌好像什么东西都做不了；但是做交易的人你会发现好像就很简单，现在没有仓位，现在在做空，现在多空同时在那边做，觉得非常舒服一样。任何的策略，相信我，任何的策略一定都是有两面性的。

另外一个，就不要去幻想着在市场下跌的时候我可以去换一个策略，在市场上涨的时候我再可以去换一个策略。不可能的，我说不可能的。你选择在3月份的时候进行做空，你就一定会在4、5月份的时候进行踏空，且在5月份的时候甚至进行做空，一定会、一定会、一定会发生这种情况。所以不可能下跌的时候你换一个交易的策略，然后上涨的时候你会长期持有这个策略且不去做任何一些减仓，是完全不可能发生的。所以这些东西是我们需要去考虑的。

也不一定说每个人都要去做投资，反正我个人的想法、也是我一直的看法，我认为条条大路通罗马，每种方法都可以，根据自己的能力圈，根据自己的时间，然后去找到一个比较符合自己的一个策略。

### 市场走势与机构表现

回到今天市场，首先今天市场非常难看，标普500、三大指数都出现了比较大幅度的下跌，美债收益率下跌。那过去这段时间，特别是整个10月份到现在，美债收益率下跌的幅度是比较大的。10年期也从最高点的5.5%、5.6%吧——我记得四十五个基点，差不多5.3%、5.4%嘛，5.4%左右，然后下跌的幅度比较大。当时在5.4%的时候，你就发现市场就是这样，当市场在恐慌、在下跌的时候，他就会觉得无限的恐慌。在5.4%的时候，市场里有多少人出来喊美债收益率要到10%？记不记得？但是现在没有人了，现在没有人去喊美债的收益率要到10%了。因为几乎今年1月份到9月份，在9个月的时间，美债收益率是单边上涨，或者美债的一个价格是单边下跌的。但到了5.4%就轻轻松松打破了5%，轻轻松松打破了23年11月份当时最高点10年期5%的时候，来到了5.4%，市场马上做线性外推认为要到6%。但之后马上从5.4%的时候，那一波是CPI数据超预期，成为了一个契机，收益率就出现了一波下跌。

虽然今天出现了非常大幅度的一个下跌，但是YTD到现在为止，标普500仍然是上涨的。标普仍然是上涨了7.5%，纳指也是上涨了4.6%，道指是7.2%。即使芯片板块在经历了那么大一波下跌——从10月份到现在，10月份加上11月份前几个交易日，总共芯片板块下跌了30%，但是YTD芯片板块仍然上涨了31%。

所以如果从今年投资到现在，你说和标普走得差不多，或者跑输了一些标普，我觉得问题也不大。但是如果比如说浮亏浮得比较多的话，就今年你起码在这个市场、整个今年一年到现在都在这个市场里面的话，我觉得是需要思考一下自己的一个方法的，包括是需要思考一下自己在风险这一块，还是在仓位这一块，我觉得是需要去思考一下的，或者这个策略本身适不适合自己。

当然一年跑输市场是很正常的嘛。我给大家总结了一下今天市场里面所传的一些消息，几家对冲基金都做出了一些……有些是退钱了，就是我不干了，我觉得这个市场太难做了，所以我不干了。比如说这家叫缩卢资本，他说在经历了2020年3月份以来最糟糕的月度业绩之后，该公司正准备返还部分的现金，就是把整个基金要退钱退给他们投资者了，就不做了。没有亏完，对吧？只是把钱给退回去。通常来说把钱给退回去，在过去这段时间还是赚钱的，所以就觉得整个市场比较难，所以就把钱退给投资者。

另外一家资产管理公司录得了有史以来最大的单月跌幅，结束了连续16个月的上涨势头。就这家基金或者这家资金管理公司，过去16个月每个月都是上涨的。你说这个市场里边有什么样的策略能够做到过去16个月都是上涨的？那我们经历了过去16个月，起码中间要包括一个今年的3月份，对吧？基本上每一个月都在涨。而且今年本身今年的市场是板块轮动非常快，再加上有宏观这边的一些影响，美债收益率这一块的一个影响，有多少人能够做到连续16个月全部出现上涨？那即使是这样的一个基金，在过去一个月也出现了下跌。

所以市场里面是没有神的，也没有一个非常完美的一个策略可以帮助我们每天账户都上涨、每个月账户都上涨，是不可能的。即使这样的一个基金，在过去的一个10月份也出现了非常大幅度的一个回调。

所以，无论是哪种策略也好，无论是再怎么样好的一些基金也好，我们一定要允许策略本身或者方法本身在某一个时间段里边走不过市场，这是一定会发生的事情。市场里面没有神的。就巴菲特，每一次市场下跌——这段时间倒还好，倒没有看到社交媒体里面疯狂地在聊巴菲特。那巴菲特其实又跑回来了，因为手里有的苹果走得非常地好。然后在整个十月份到现在，整个价值股板块是走得不错。除了今天，今天是某种程度出现一些 correlation equal to one，就是所有的一些资产、美股里边所有的板块是全部出现下跌，就是相关性趋向于一嘛。

### 市场交易逻辑：数据中心延期对芯片链的影响

讲到背后的一个理由，市场现在在交易什么？中期选举完之后，现在市场交易的主要担心——你看半导体被伤得比较厉害，那主要市场的一个担心是：这一波民主党控制了参众两院之后，对于数据中心这一块会进行非常大的抑制。那会导致数据中心的抑制，就会导致——这背后这个逻辑就一层一层去推这个逻辑。我先说市场交易这个逻辑，然后说我自己一个判断。

市场交易的逻辑背后：你数据中心放缓，那就是大科技的资本开支被迫放缓。记住这是被迫放缓，不是主动放缓。被迫放缓，那就是有可能会让数据中心放缓。所有在数据中心里面的半导体全部进入数据中心了，那所有和数据中心相关的一些半导体就全部会下跌。

但是如果我们这样去细究的话，不一定所有的半导体的影响都是一样的。比如说我在昨天的直播里面其实我有聊过，我们举三个例子：英伟达、AMD 和英特尔，我们拿这三个例子出来举。你觉得对于英伟达来说是不是一个利空？首先这三家公司肯定都是利空，但是对于英伟达来说，应该是非常直接的利空。因为英伟达主要的业务是在 GPU 里面，而 GPU 的话就是进入数据中心了。如果你数据中心交付往后延的话，那你英伟达 GPU 的交付一定会往后延嘛。

但是如果你把英伟达和其他比如像和博通之间 ASIC 这个芯片去做对比的话，可能英伟达相对来说又会稳一些。为什么？因为英伟达它的 GPU 本身它有一个叫做 fungibility，就是你移到哪里你都可以去用，所以从这个角度来说，它的可替代性、可转移性会比 ASIC 要高很多。所以从这个角度，同样的大家都是数据中心往后延，对于每家公司的影响是不一样的。对于你定制芯片的影响、对于 ASIC 芯片的影响，和对于你 GPU 进程的影响是不一样的。

这是英伟达。那如果拿英伟达和 AMD 去做对比的话，应该 AMD 受到这个影响相对来说会比英伟达要稍微小一点。为什么？当然了，AMD 它主要的 GPU 这一块和英伟达一样也是会受到影响，某种程度可能它受到影响的比例会更大一些，实际上可能更加偏一些英伟达这个 GPU，这是一部分。但是 AMD 的这个 CPU——因为 CPU 本身，因为现在 AI 还在落地嘛。我们现在首先有一点我们需要确认是：AI 现在的落地是没有问题的。稍后我有短期 GPU 租赁的价格和大家分享，AI 现在落地是没有问题的。那问题就是潜在的被迫数据中心的延期往后延，有可能会造成资本开支的放缓或者资本开支的往后延，对吧？

聊到资本开支，然后聊到 GPU，对于英伟达的影响，然后对于 AMD 就是 GPU 加上 CPU。但是 CPU 的影响，AI 智能体落地的话，对于 CPU 的要求会更高。甚至于从美光的角度、从 HBM 的角度，在前段时间我们有看到英伟达包括 AMD——当然这次 AMD 财报我还没时间去听——他们都对自己的 GPU 进行降规了，我们叫 de-spec。为什么进行降规？因为背后 HBM 是短缺的。

所以如果我说我先照着市场这个逻辑线去推，我先不是说我自己的一个判断。我们照着市场这个逻辑线去推：你数据中心交付往后延，然后使得你五月份的 GPU 被迫交货也得往后延，那在这种情况下，从英伟达的角度来说也好，从 AMD 这个角度，他们就不会 de-spec，他们就会按照原来的规格。你一块 GPU 的芯片该配多少 HBM 就配多少 HBM。因为一旦数据中心你原本期待的交付总体的一个计划和原来去做对比要下降的话，那市场其实一定会更加偏好于你在数据中心里边的 GPU 也好、HBM 也好，所有的配备一定是最好的配备。因为最好的配备你一个 token 的产出才是最大的，token 产出最大化。所以市场会对于每一个数据中心里边每一块 GPU 所做的整个系统，它要求更高。所以你说对于 CPU 的这个影响其实是二级的这个影响，包括对于 HBM 的这个影响，相对于 GPU 来说它就是一个二级的影响，对吧？这就是英伟达和 AMD 之间的差别。

### 存储周期与大科技资本开支
