### 个人 Agent 爆发与巨头布局

美股播华尔街专栏。大家好，我是美投君，你们的美股探路者。

个人 Agent 终于来了。前不久，Meta 推出的个人 Agent 产品 Muse 一上线就成为了爆款。仅仅三十六天时间，它在美国的下载量就达到了九百万次。同样的数字，ChatGPT 当年用了一百一十天。现在看，它已经成了除了 ChatGPT 以外最成功的消费者端 AI 产品了。

Muse 这一火，其他科技巨头也都坐不住了。OpenAI 在九月底发布了 Operator，Anthropic 上周也推出了 Claude，谷歌面向消费者的版本预计在四季度推出。可以说，几乎所有的大公司都开始布局自己的个人 Agent 了。这么多巨头同时下场，足以说明个人 Agent 会是接下来 AI 一个不容忽视的逻辑。

但另一边，它也面临着不少质疑。那么，个人 Agent 这条路到底能不能走得通？这么多巨头里，最终谁又能笑到最后呢？这对于我们未来的投资又意味着什么？今天这期视频我们就来好好聊聊个人 Agent 这个大趋势。

最近这段时间回国探亲不方便录视频，所以本期视频采用了 AI 声音，稿子都是我在火车上熬夜改的。内容制作不易，还望大家给美投君点个赞，让更多人看到美投的股票研究。

### 什么是个人 Agent 及其核心痛点

可能还有很多人不清楚什么是个人 Agent，为了照顾到所有朋友，我就来给大家快速介绍一下。简单来说，它就是一个能替你在生活里办事的 AI 助理。你跟他手说一句，他就能自己去帮你订机票、退订服务，甚至主动提醒你各种事情。

那问题来了，咱们已经有 ChatGPT 了一般人为什么还需要一个 Muse 呢？这就要说到把 ChatGPT 当做个人 Agent 来用的时候有几个绕不开的痛点：

第一，ChatGPT——主要说的是免费版的 ChatGPT——本质上还是一个聊天机器人，没有执行的能力。它可以给你答案，但最后去执行的还是你自己。虽然已经帮了很大的忙，但一旦什么都还要自己亲自动手，就没有那么省事了。

第二，就算你真的想让他替你办事，往往也会卡在密码这一步就进行不下去了。这也能理解，一般人本来就不太愿意把密码、信用卡这些交给一个聊天机器人，所以真要办事的时候，他其实做不了什么。

第三，你不去找他，他就不会主动来找你。但你想想，如果是一个真正的个人助理，是不是应该主动帮你发现问题、解决问题才对呢？就像是你请一个秘书，如果一上班就耍手机，你不主动找他，他就说没活干，那这样的秘书其实就帮不了什么了。

这些就是当前的 ChatGPT 作为个人 Agent 还实现不了的问题，而 Muse 就是专门冲着这些痛点来做的。

### Muse 的破局机制：云端虚拟机与主动提醒

接下来一个一个来看。咱说第一点，执行力不够。这个问题大家应该都有感觉，过去这一年 AI 之所以能带来这么大的变化，很大程度上是因为有了 Agent。以前的 AI 只能回答你的问题，而现在的 Agent 能真正去帮你干活，像 Codex、Claude Code 可以替你写代码、跑任务，在工作上实现很多非常厉害的效果。

但奇怪的是，面向普通人生活的个人 Agent 却一直都没有成气候，这是为什么呢？其实 B 端的 Agent，也就是企业端的 Agent 能够干活，是因为它能控制你的电脑、你的浏览器，在上面帮你操作。可普通人的生活主要是在手机上，手机上就是一个个 App，Agent 没法像在电脑上那样到处操作。而如果专门去买一台电脑，像年初很火的小龙虾那样，对普通人来说这个门槛实在太高了。这一直是挡住个人 Agent 发展的重要原因之一。

那 Muse 是怎么解决的呢？他想了一个很聪明的办法：给每一个用户都单独配了一台云端的虚拟机。你可以把它理解成 Meta 在云上给你分了一台只属于你的电脑，你在手机 App 里跟他说话，背后真正干活的是这台云端的电脑。这台电脑上有浏览器，所以它可以像人一样去打开网页、登录账号、填表下单。而且它是二十四小时在线的，就算你把 App 关掉了，它还在后台继续帮你干活。这就解决了个人 Agent 没法在手机上替你操作的问题。

当然，让 AI 替你登录账号、替你付钱，安全就成了一个大问题。Muse 在这上面下了很大的功夫，账号密码单独保管，连干活的 AI 自己都看不到，付款用的是一次性卡号等等。这样一来，很多人才敢真的把事情交给它去办。所以说，Muse 在执行力上不见得比 Codex 更强，但他把使用场景给变了，把原来只能在工作电脑上用的 Agent 搬到了每个人手里的手机上。有了这些基础设施，个人 Agent 终于可以直接帮你把事情给办了。

再来说第二个问题，就是想把 ChatGPT 真正做到用来办事的门槛其实并不低。不知道大家有没有意识到，现在不管是 ChatGPT 还是 B 端的 Agent，都有这么一个问题，那就是你得先主动去找他，他才会给你干活。本来这也没什么，可 ChatGPT 什么都能做，正因为他什么都能做，你反而不知道该让他做什么，这就有点像谷歌搜索，你没什么事的时候总不会说“今天没事干我刷两下谷歌搜索吧”。至于 B 端的 Agent，它就是一个工作时的生产力工具，你本就应该工作的时候才主动用它。

然而，如果一个产品的目标是要做个人 Agent，那么整件事就变得完全不一样了。你想想，如果你真的请了一个个人秘书，你会希望他每天上班就躺在沙发上，等你想起什么事了才吩咐他一句吗？肯定不会。你希望的是他一上班就主动帮你把事情给办了。个人 Agent 就是反过来的，是他主动来找你，他会去看你的邮箱、日历，然后主动给你提醒、给你建议。用过 Muse 就知道，这个小羊驼会隔三差五地提醒你一些事情，你根本没有要求过，只要他觉得对你的生活很重要就会来提醒你。他其实是在不断尝试了解你的意图，以此保证你会经常回来用它。

我就举一个我自己的例子。之前 Uber 给了我一个月的会员免费试用，到期的那天 Muse 就主动来提醒我说，你的会员马上要到期了，如果不喜欢的话记得去取消。这便是一个以前我完全不会想到的需求，但他找到了，帮我解决了问题。这种主动带来的一个最明显的效果就是降低了使用门槛。很多人第一次接触 Agent 最大的难处在于不知道该怎么用，现在他主动把能做的事摆到你面前，大家自然就知道怎么用了，也慢慢发现 Agent 真的能帮自己做很多事，那些原本对 AI 没那么了解的普通用户也能很轻松地用起来。

把这两点放在一起，你就能看懂个人 Agent 和之前的 AI 最大的区别了：ChatGPT 更像是一个大号的搜索，B 端的 Agent 是一个帮你完成工作的工具，而个人 Agent 更像是一个真正的私人助理。

### 商业空间与底层需求逻辑

那个人 Agent 到底是一门多大的生意呢？非常大。

你想想看，如果像旅游订酒店这些事情以后都可以直接交给 Agent，那 OTA 网站的生意就可能被它替代掉。再往大了说，当大家想买什么、想做什么都直接跟 Agent 说的时候，整个数字广告都有机会转移到 Agent 上来。按大摩的估算，未来能够通过 Agent 实现数字化的消费支出大约有三十二万亿美元，其中一半多是电商和旅游。当然这些钱不可能都是 Agent 的收入，但哪怕只按百分之三的抽成来算，也是一个接近一万亿美元收入体量的潜在市场。这么看，C 端 Agent 的空间其实和 B 端大致相当，这也就不难理解为什么这些科技巨头都开始布局这个赛道了。

不过个人 Agent 真的能成功吗？老实说，现在就说它会成为下一个杀手级应用确实有点太早了。很多人就会质疑说：你看现在大家用 Muse 做的无非就是退订个服务、换个保险公司，这些看上去都是一次性的事情，会不会大家下载了 Muse 把几个订阅退掉，然后就把它删了再也不用了呢？说到底这个需求真的能持续存在吗？

我承认这些质疑短期之内可能都会存在，但长远来看我个人认为这些其实都不是问题，个人 Agent 这条路是一定能成功的。

为什么我有信心呢？咱们得先回到一个最本质的问题。什么问题呢？就是人天生就想偷懒。人类社会一直以来都在想办法把自己不想干的事情外包出去。不想洗衣服，于是有了洗衣机；不想洗碗，于是有了洗碗机；再到现在的外卖、网购，很多时候也不是你真的没时间，就是懒得下楼、懒得出门而已。可是到了今天，社会越发达，服务分得越细，我们的生活似乎被照顾得越来越好了，但不知道你有没有发现，我们每天要操心的事情可一点都没少：付账单、管理密码、比价购物、去各种预约等等等等。虽然都不是什么大事，但每件事都要操心，又烦又碎。

而个人 Agent 要做的，就是帮你把这些琐事接过去。这其实和洗衣机、外卖是一个道理，只不过以前外包出去的多是体力活，现在连这些要花心思的琐事也能交出去了。说到底，这背后都是人的好吃懒做。好吃懒做是人性，也是很多生意背后的第一生产力，只要是能让人生活更方便、更省事、更轻松的服务，就一定是有需求的。

其实私人助理这种服务一直都有，只不过以前只有有钱人才请得起。你不妨问问自己，假如不要钱你想不想有一个私人助理？我相信绝大多数人都是想要的，这本身就说明这个需求一直都在。而现在的 Agent 是免费的，这就相当于每个人都有了一个不要钱的私人助理，所以长远来看这门生意一定能做成。

那回到前面的质疑，今天大家用 Muse 做的确实很多是退订、比价这种一次性的事情，但这并不说明需求不会持续。Muse 肯定不是个人 Agent 最终的形态，它只是目前最接近的一个，接下来一定会快速不断地迭代，能帮你做的事情也会越来越多。今天咱们看到的只是一个很初级的形态，一年后、五年后它肯定会变得很不一样。这就好像智能手机刚出来的时候，很多人还在讨论我要这么多功能干嘛，能打电话发短信不就行了吗？可后来呢，谁都离不开它了。个人 Agent 也一样，形态一定会变，但只要每一次迭代都能让人变得更懒，它最终就一定会成为人人都离不开的产品。

### 商业模式落地的三大困难与胜出条件

不过，长远来看能做成，不代表这个过程会很顺利。个人 Agent 和一般的互联网产品很不一样，它有很多自己特有的困难，也正是因为这些困难，很可能使得个人 Agent 这套商业模式现在很难跑通，也正因为这些困难，可能使得一些玩家最终能够胜出，一些最终会被淘汰。

那具体有哪些困难呢？

第一个困难，也是这门生意最大的挑战，就是它太烧钱了。以前的互联网产品多一个用户几乎不多花什么钱，所以可以放心地免费送，但 AI 不一样，因为算力是要看成本的。你每多一个用户，甚至每多问一句话都要消耗算力，都是成本。而个人 Agent 的成本又比 ChatGPT 高出一大截。可能很多人不知道，一个免费的个人 Agent 它的运行成本大约是免费 ChatGPT 的十倍。

为什么这么贵呢？一方面执行任务消耗的 token 远远高于简单问答；另一方面，全天候在线、每人一台独立的虚拟电脑、各种安全设置，这些都要花钱。按大摩的估算，每一位 Muse 用户每个月的成本在三美元到一百三十美元之间。如果一个用户把免费额度全部用满，每个月的成本就要一百二十八美元，一年下来就是一千多美元。

也正因为成本太高，OpenAI 直接把个人 Agent 产品 Operator 捆绑在了他每月一百美元的 Pro 套餐里，不光免费用户用不了，就连每月付二十美元的用户也用不了。以 OpenAI 的技术实力做出来肯定不是问题，之所以这么定价，说到底还是因为成本实在太高了。可大家想想，又有多少人愿意为了这些生活琐事每个月掏上百美元呢？本来 C 端用户对付费就非常抵触，所以超高的成本就成了个人 Agent 发展过程中一个巨大的阻碍，就连扎克伯格自己也在财报会上提到成本是限制 Muse 扩张的一个重要因素。

第二个困难是信任。个人 Agent 想要真正把事情办成，很多时候必须拿到你的权限。比如你想让他帮你跟电信公司争取一个更便宜的套餐，就得把电信公司的账号交给他；想让他帮你买东西，就得把信用卡交给他。可现实是大多数人还不放心这么做。美国有一项调查显示，只有百分之三的人愿意让 AI 不经确认就去做交易，只有百分之四的人愿意让他独立完成购买。如果大家一直不愿意把这些交出去，个人 Agent 能帮你办的事就会很有限，也就很难做大。

第三个困难是平台不一定让你进。就算用户愿意把账号交给 Agent，平台也不一定让他进去。比如亚马逊就直接把 Muse 给封了，摩根大通也不让这类 Agent 访问客户的账户。虽然亚马逊对外说是出于安全考虑，但在我看来他更担心的其实是广告，因为如果消费者直接告诉 Agent 想买什么，就不会再去看亚马逊上的广告了。而且现在几乎所有的个人 Agent 都还要用到谷歌的 Gmail 和日历，这些连接理论上也随时可能被切断。当然长期来看，这些平台大概率会一点点放开，只是过程中少不了拉扯，从而导致产品的 scale 不够快。

聊到这里，咱们先把逻辑捋一下：个人 Agent 这条路长远来看一定能走得通，市场空间也非常大，但过程中有三个困难：太烧钱、需要信任、平台不一定让你进。

那这么大的一门生意，最后到底谁能做成呢？其实只要把这三个困难反过来看，就能知道一家公司需要具备什么能力了：

首先是烧钱这个困难。个人 Agent 的成本这么高，用户又不愿意付钱，那你就得有别的业务赚钱来补贴才能长期免费下去。但光能烧还不够，烧钱总有个头，你还得尽快找到变现的办法，比如广告或者交易抽成，这样才能一直撑下去。

其次是信任。用户愿不愿意把密码、信用卡交给你，很大程度上取决于他们本来就信不信任你这家公司，这种信任往往需要很多年才能积累下来。

再就是平台不让进的问题。没有哪个 App 拥有一个人所有的数据，你的邮件在这家，购物记录在那家，银行账户又在另一家。所以一家公司要么有足够的话语权能让商家、银行这些平台放他进去，要么自己本身就掌握着大量的用户数据，不用太依赖别人。

除了这三点，还有两样是所有面对消费者的产品都需要具备的：
一个是分发渠道和用户基础。比如 Muse 之所以能够扩展得比当年的 ChatGPT 还快，Meta 背后庞大的分发渠道和用户量功不可没，这是当年的 ChatGPT 根本不具备的。
另一个是捕捉用户意图的能力。尤其是个人 Agent 这部分，我们说它和之前的 AI 产品一个巨大的不同就是它能主动去找用户的需求，所以你得有好的产品力，而不仅仅是模型的能力。

当我们把这些条件放在一起之后就会发现，其实答案还是比较明确的，那就是基本只有巨头才能做出来。他们能烧钱、有数据、有渠道，还有一定的信任基础。虽然市场上也有一些很有特色的小公司在做个人 Agent，比如 Instinct，但他们很难长期撑下去，最后大概率会被收购。因此真正能参与这场竞争的其实也就这么几家：Meta、谷歌、苹果、OpenAI、Anthropic，再多的话可以加一个 Grok。

### 各大玩家横向对比

那谁最有可能成功呢？我们不妨捋着他们几个挨个看一下。

先说 OpenAI 和 Anthropic。很多人可能觉得这两家最有可能赢，毕竟他们是 AI 的领头羊，模型最强，尤其是 OpenAI，C 端的用户也最多。但在个人 Agent 上情况真是如此吗？前面说了，个人 Agent 是一门非常烧钱的生意，而这两家恰恰是最缺钱的。别看他们俩现在的市值很大，但从现金流上看，他们远远比不上其他对手。两家公司现在主要靠外部融资，收入主要来源也是 B 端，在广告、电商这种消费者变现的渠道还非常初期。所以这俩公司不仅差钱，而且在 C 端还不好变现。而当下光是 B 端的竞争就已经够他们烧的了，如果再做一个免费的 C 端产品可能不一定扛得住。至于模型强这个优势，你看 Muse 做的这么好，可 Meta 的模型其实也不算最强，所以很明显个人 Agent 这件事模型并没有那么重要。也因此，这两家反而不一定有那么大的优势。Grok 的情况也差不多，而且他的位置还更尴尬一些。

那 Meta 怎么样呢？他的优势目前来看非常明显，这也是他现在领先的原因。首先是烧钱和变现的能力，Meta 每年的广告收入非常可观，自己的算力也是行业里最多的，还有一个要多少资源就给多少资源的创始人。也正因为烧得起，Muse 的基础功能可以完全免费，token 也给得非常大方，而且 Meta 本来就是最会对消费者变现的公司之一，手里又有三十多亿 C 端用户，如果真跑通了变现，赚起钱来也应该是最快的。再来是捕捉用户意图的能力，他的社交媒体业务本身就是靠抓住用户的意图来赚钱的，主动给你推送内容、一点点培养你的使用习惯，这些事 Meta 已经做了很多年，经验非常丰富。第三是做 C 端产品的能力，Muse 用起来是很顺手的，就是一个对话框，像在 WhatsApp、微信里聊天一样操作很顺畅，这说明 Meta 确实很懂 C 端产品，不过这些东西以后别人也会慢慢学走。最后是 Meta 的数据优势，现在 Meta 并没有将社交媒体上的数据接入 Muse，所以这部分数据优势还没有体现，但未来这将会是 Muse 和其他个人 Agent 产生差异化的核心。这么看，Meta 的优势确实很大。但他有一个很大的问题，就是前面说的信任。根据 Oppenheimer 的一项调查，问大家愿意信任谁来保管自己的密码，结果谷歌是百分之三十，苹果是百分之二十三，ChatGPT 是百分之十六，而 Meta 只有百分之八，排在最后。现在个人 Agent 还在初期，大家用它做的事情还比较简单，信任的问题可能还没那么明显，但越往后他要帮你办的事越多、碰到的钱越多，这个问题就可能越突出。所以 Meta 现在虽然领先，但未来还需要继续观察。

那有没有谁可能后来居上呢？我觉得谷歌很有看点。为什么这么说呢？咱们还是按前面那几个能力来看。先说信任，这恰恰是 Meta 最大的短板，而谷歌是大家最愿意把密码交给的公司。再说烧钱和变现，谷歌的广告生意一点也不比 Meta 小，完全烧得起。至于分发和数据，大家每天在用的 Gmail、地图、YouTube、安卓都是谷歌的，所以单看这几点谷歌的条件都非常好。不过现在市场对于谷歌还是有些顾虑，一个重要的原因是担心和自己的搜索业务左右互搏。如果个人 Agent 能够帮你买机票了，那谁还会去搜索引擎上看机票广告呢？这个风险确实存在，也会是短期谷歌面临的最大问题。但换一个角度看，谷歌其实已经无路可退了，因为个人 Agent 注定会来，来了又注定会冲击到谷歌的搜索广告基本盘，那么谷歌反而是最有紧迫感去做好这件事的人。别人都是锦上添花，而谷歌则是生死存亡。在现在谷歌已经 All in AI 的背景下，长期来看这反而不是一个问题。那谷歌真正的问题在哪儿呢？在我看来是内部产品太多，大家互相抢资源，很难统一产品战略，他也没有像扎克伯格这样敢孤注一掷的创始人。可做好个人 Agent 恰恰需要很大的决心，既要投入大量的资源，还要扛住短期的亏损。那谷歌到底有没有这个决心持续做下去呢？这点还是需要验证的。整体来看，谷歌的条件不比 Meta 差，只要管理层下定决心把资源集中起来，把 Gmail、日历、安卓这些都打通，追上来并不难，这一点我个人还是保持积极的态度。

多说一句，刚刚过去这周谷歌发布了最新一季度的财报，财报后股价大跌了百分之十二。关于本次财报的深度分析已经在美投 Pro 上发布了。这次财报可以说是谷歌近些年来最重要的一次财报了，搜索业务史无前例下跌，但另一边的谷歌云业务史无前例大涨。那这是不是意味着 AI 的冲击终于显现了？谷歌最担心的情况还是发生了？如果你是谷歌的股东，那么本次财报分析你一定不能错过，感兴趣的看官欢迎移步美投 Pro 查看。

最后再来说说苹果。苹果的好处是握着 iPhone 这个最底层的入口，在分发上没有人能跟它竞争，软硬结合的能力也很适合做个人 Agent，最关键的是他有着别人都无法掌握的私人数据，以及所有科技公司中最强的隐私保护口碑，所以很多人觉得苹果最后能赢。但苹果自己也有一个致命的问题，那就是他自己没有模型。现在苹果用的是谷歌的 Gemini，看起来也不太想自己去做模型，在软件层也明显慢了一拍。而且入口这件事可能也没有想象中那么重要，你想想按一下锁屏键叫 Siri 和打开一个 Muse 真的差很远吗？所以对于苹果来说，未来还是比较 mixed 的。

好，说了这么多，那最后谁最有可能胜出呢？这个问题其实很难有标准答案。不过既然都说到这儿了，我也跟大家说说我的预测。我个人认为目前优势最大的还是 Meta，他也最有可能最快跑出来；谷歌虽然慢了一步，但条件都在，还是很有可能后来居上的；至于其他几家我目前并不太看好，OpenAI 和 Anthropic 两条战线都要打，免费这条线不一定烧得起；苹果因为没有自己的模型，有这个硬伤在，我觉得它最后更可能成为一个收取“入口费”的角色，就像今天浏览器和搜索的关系一样。当然这个判断很主观，变量也很多，这件事才刚刚开始，咱们还是要走一步看一步。

### 投资影响与变现时间线

那这对投资者来说意味着什么呢？

首先大家一定要注意，对应用层的公司来说，个人 Agent 这个趋势短期之内其实没有太多可以期待的。因为这个市场现在还处于烧钱阶段，变现还没开始，接下来很长一段时间这些公司的现金流都会很难看。只要投入还在继续，变现还不确定，市场的质疑就很难打消，所以大家也别指望个人 Agent 在短期内能给前面说的这几家公司带来爆发性的增长。

那接下来该看什么呢？其实就是变现。一旦个人 Agent 开始变现、真正赚到钱了，大家就会把这些质疑一点点地抛到脑后，也会觉得前期的投入是值得的，这才是真正爆发的信号。这就像今年早些时候 B 端 Agent 成功变现之后，才带动了 OpenAI 和 Anthropic 两家公司的估值一样。而目前投行基本预估个人 Agent 要到 2027 年年底才会开始变现，我个人也同意这个判断。这么倒推过来，最快可能也要到 2027 年年中个人 Agent 才有可能给这些公司的股价带来爆发。

那在这之前呢，还有别的机会吗？有。在我看来，2027 年将会是个人 Agent 竞争的一年，也会是新一轮的军备竞赛。现在 Meta 已经在融资了，谷歌也肯定会参与进来，其他公司也都在跟上。在这种情况下，最先受益的就是基础层的公司，因为不管最后谁赢，大家都得先砸钱买算力，这场军备竞赛的好处基础层马上就能看到。就像过去这两年大家为了抢 B 端的客户展开竞赛，结果最先受益的反而是半导体这些基础层的公司，而这一次我认为很可能又会是同样的剧本。
