填表的时候说，你填个表，你政治面目是什么？什么叫政治面目？问你是不是党员。“你他妈才是党员，全家都是党员，全家都是党员。”

我说当愤青，我们当年就是愤青。当愤青要学会包围中南海，你去包围中南海，让习近平出兵武统。记住，是被压迫者最卑微的反抗形式，但别否定，别忘了，它绝对是反抗。

### 闯关回国投案的尝试

>> 我们可以把话题收回到您的经历上来。因为我昨天说今天采访您，就搜我以前有个事儿我真的不知道，你肯定是因为我孤陋寡闻，就是您其实有好几次要自首回国的经历。

>> 是是，这个有意思。

>> 我是看那个《亚洲周刊》的一个报道，我才看到还有这么一回事儿。

>> 对对，很有意思。

>> 我猜很多人其实也不知道。您说说，昨天也讲……

>> 在我在网上跟五毛粉红辩论的时候，他们最爱讲的一句话就是：“你们离开中国很久了，回来看看再说。”我说：“我回来，共产党不让我回来。”“什么叫共产党不让你回来？”我说我投案，我是被通缉的，我是中国政府被通缉，1989，现在还没撤销。

>> 还没撤销。

>> 而且你投案不止一次。

>> 四次。

>> 我讲讲讲。

>> 对，谢谢。

>> 谢谢你问这个问题。因为五毛粉红最爱讲这些话：“中国，你回来看看再说。”

>> 对，“你没看，没有发言权。”

>> 是。第一，“没看没有发言权”这句话很无赖。你一看就是浑身上下都是病，这件事儿大部分是不用真的经历过你的痛苦。就你这个人，远远第一次见到你，我就可以得出结论说你有皮肤病，这个事儿不用跟你当家人当多少年。所以“你没看过，没有发言权”，一个读过联合国新疆报告的人，肯定比一个去新疆旅行过一次的内地人更知道发生了什么事情。你去过不代表什么。

>> 我们在里边住着，我们也没有发言权。

>> 对对。这个发言权又分两个意思：就是到底让不让你有权利发言？

>> 对，好像你在里面就明白一样，其实在里面更糊涂。

>> 另外一个发言权也是中文的叙事里面说，你这个人没有发言权的意思，不是说剥夺你的讲话的权利，是说你没有发言的那个立场和根据，是这个意思。那我相信五毛粉红是不敢来否认我发言的权利，但他说你没有发言权的意思是说：“好，你有权利说话，但你没立场，你没资格，足够的资格。”大概是这个意思。

那好，第一，有没有资格？你们是最被剥夺资讯的人。你们在没有足够的资讯的、只听共产党给你的宣传灌输的资讯的情况之下，你觉得你比我更有资格来评论中国这件事儿，有点可怜。

>> 可怜。

>> 那我很努力地追求的民主，也是帮你解决你的可怜的状况，至少让你也得到充分的自由，也得到足够的资讯。得到共产党剥夺你获取资讯的权利之后，你得到了资讯之后，你更有资格来跟我对话，所以我在帮你，我们追求自由民主是在干这件事儿。

那如果说我们对中国的了解不够就没有发言权的话，所以我们要在为中国有充分的了解、中国人民对中国的情况有充分的了解这件事而努力。其中最主要的一件事情，就是突破共产党对资讯的封锁。

>> 同意。

>> 同意。所有的五毛粉红应该都同意。因为任何人堵住你的耳朵，捂住你的耳朵不让你听，堵住你的眼睛这件事，你不能为他鼓掌。然后你到最后说：“你们也不知道，你离得远，知道不知道。”我为什么离得远？是因为我回不去。我为什么回不去？你给五毛粉红说“你回来看一看再说”，我很想回来，而且我不仅很想回来，我尝试过四次。

回答你的问题，就是我第一次尝试是2009年。2009年对我来讲是一个特殊的年份。那一年，2008年中国有《零八宪章》，刘晓波被捕；中国申办成功的奥运会，所以中国一副就是大国崛起的样子。而对于我来讲，是八九年学运20周年，我流亡20年。

“流亡是一个精神酷刑”，这句话我讲过很多次，流亡现在已经37年，我这次在日本也讲了这个话，流亡是一个精神酷刑。我听过不少人描述流亡给自己带来的这种精神的残酷状况，我听过最让我震撼、震动的是我的一个维吾尔朋友讲的，他说：“我在我的心中已经埋葬了我的父母。”他在海外流亡，已经多年没见到自己还健康活在新疆的父母，“但我在心中已经埋葬了他们。”

我听到这句话的时候是非常震撼的。我听到他讲这句话的时候，震撼的原因就是马上想到自己，我父母当时还健在。我们流亡最害怕的是接到远方的噩耗，而且说实话，你从流亡第一天开始就已经想着会不会有这么一天。然后周围的人慢慢开始，尤其年龄比我们年长一些的人，就看到他们收到远方的噩耗，回不去，没办法送终。其实流亡是个精神酷刑，这句话我呼吁大家设身处地，你自己想象一下，30多年见不到自己父母，被剥夺见不到自己父母，而且随时可能会接到远方传来的噩耗。

设身处地不难，也难。难是因为第一很痛，谁设身处地来替别人想一想，自己可能30多年见不到自己父母，都是很痛苦。设身处地本身是个痛苦的过程，然后会接到噩耗，光想象一下都会很痛。那我的维吾尔流亡朋友说“我在我的心中已经埋葬了我的父母”，说实话，我听到的时候就是潸然泪下，已经很难控制自己的情绪不受影响。

我其实在2009年的时候，流亡20年，当然这个问题会在我脑子之中不断地回响。我2009年的时候40多岁了，41岁，流亡20年，所以我离开中国是21岁。流亡20年，难道我要一直流亡下去？2008年，我的老师、我的好朋友刘晓波被捕入狱，《零八宪章》然后被捕入狱，然后中国这个时候却是一副普天同庆，中国大国崛起，我们办了奥运会、世博等等，一副就是这样子。然后中国老百姓似乎也在享受着大国崛起的乐趣。

但我们知道，你们并不能理解，说流亡者是少数，人数也很少，而且我们是反贼，共产党叫我们反贼。那好，我也就利用这个词儿，我们是反贼，既然我要反抗，我要付出代价。合理？不合理。但是有没有这个脉络？有，这个是有脉络。你反抗一个国家、一个政府，当然把你当敌人，它至少有逻辑上的通顺。你说它合理，合理的意思不是说逻辑通顺而已，它也合乎人情事理才叫合理。

但是我在2009年的时候，我就做了一个决定，我说我要闯关回国投案。我还记得我准备了一篇宣言，全世界旅行过去这些年，我旅行用的是中华民国护照、台湾护照。台湾护照要去中国是要办台胞证，那我是办不了台胞证的，我的护照上的名字写得很清楚，我是吾尔开希，办台胞证是办不下来的。但是持中华民国护照，有意思的是去中华人民共和国特别行政区澳门免签证。我持台湾护照可以上飞机、可以登机，你可以买机票，可以登机，因为他看台湾护照就让你免签证嘛。澳门是一个赌城嘛，台湾是个重要的经济来源，那我就买了机票，然后也成功地登上了飞机。

我准备好的闯关投案宣言，就是委托我的朋友在我登机之后在台北宣读。刚好也是六四纪念，所以整整是09年6月4号，六四二十周年的时候。我就6月3号那天登上飞机飞往澳门的时候，我上了飞机，飞机起飞，我的朋友在台北帮我宣读闯关宣言，那当然这就变成了大新闻。

然后从台北飞到澳门一个多小时的时间，很多的媒体也就到了澳门机场，说实话也不多，算快了，很多是从香港赶过去的，但是来了。我当然也进不去，我在无法入关。我在那个宣言里边，当然不光是让媒体跑来了，首先是澳门政府已经知道了，这宣言宣布了嘛。

我在宣言里面写的就是我决定投案，我是中国政府的通缉犯，我决定投案。投案的原因我是这么解释的：我说第一，我是八九年这场学运的发起者、组织者、参与者，对这场运动我有责任要继续坚持这场运动。我们提出的最主要的要求是对话，而过去20年我们从来没有停止过呼吁，继续呼吁跟中国政府对话，从来没有停止过。

但也不光是我们，其实达赖喇嘛、西藏流亡者也从来没有停止过跟中国政府对话的努力。中国的无论是民主运动者，甚至哪怕跟政治运动保持很大距离的环保、女权，所有的这些都希望跟政府对话，中国政府完全拒绝所有的对话。环保运动者要求对话的次数非常多。西藏达赖喇嘛主张对话，而且为了能够跟中国对话，达赖喇嘛特别提出所谓“中间道路”：我们西藏可以不要求独立，我们可以接受是中国、中华人民共和国的一部分，但我们希望能够贯彻中华人民共和国当初跟我们签订的协议，来贯彻对西藏的自治嘛。

>> 这个要求很合理。

>> 对对，退多少步都很合理。

>> 协议嘛，你自己共产党答应的，我要求你落实嘛。

>> 对，但共产党听“对话”这两个字，对共产党来讲就是巨大的挑战。这一点，我很希望中国的今天在碰到任何议题都会自动站队站在政府那一边的年轻网民朋友们，能够思考一下。任何对话都拒绝这个事情，不该稍微想一想？不应该稍微挑战一下我们的政府？你自己答应的事儿你为什么做不到？你答应藏人的事儿为什么做不到？

《中英联合宣言》，关于香港问题的联合宣言，我们的外交部发言人在面对全世界的记者会说，《中英联合宣言》那个是一份历史文件，意思是已经失效了。为什么？你那个不是一个国际宣言？而且是在联合国备案的两国——中国和英国这样世界的大国签署的关于香港问题的一个协议，你说失效就失效？

难道挑战一下中国政府这件事情上，你们网民们也都决定自动站在中国政府这一边？不稍微问一下自己的良心，至少问一下自己的头脑，它有逻辑问题。

所以对于对话这件事情，我在闯关的那个宣言里边讲，我说我还希望继续对话，哪怕对话的形式是以起诉书和答辩状的方式，哪怕这个对话是在中国的法庭——这个我完全没有信心的一个地方能发生，但它至少是一个我要求的对话。我知道可以用起诉书和答辩状的方法完成的一个对话，第一个对话，这样的一个完全没有信心可以公正的对话，可以走到下一步。

这也是刘晓波所讲的，他一直在包括他的答辩状里边也都承认中国的一丁点儿的进步。一丁点儿的进步，就是比如说中国的司法现在可以稍微重视一点被告的尊严了，还没有说权利，权利还差得远，但至少稍微重视一点你的尊严了，夜里边不在审讯了，诸如此类的这样的一个情况发生，这就是进步。我愿意承认，我觉得承认进步是一个更多进步的开端，这是刘晓波的意思。

那我坚持我的老师、我的好朋友刘晓波给我的指教，就是如果能够在法庭上以起诉书、以答辩状的方式开始第一个对话，那我们就有希望进行第二场对话，那么这样的对话总归有一天能够带来中国更长远的进步。

当然，我在我的投案宣言里面还讲了另外一句话：我想回来看看中国。如果五毛粉红一直说我没看中国没有发言权，我希望有更多的发言权，那你共产党也说我没有发言权，好，让我看看。

更回归到人性。我反中国政府，你惩罚我，我至少承认这里边的逻辑，我不承认这里边的道理。我认为公民有权利反对政府，但我至少知道这里边的道理，你惩罚我父母算什么？

>> 当时您父母也是被控了？

>> 对，不允许出境。问题是被剥夺了看他孩子的权利。我和我父母不能相见，不是只是对我的惩罚，也是对我父母。

>> 中国那时候还通过了一个法律，挺有意思，好像要强调孩子要孝顺什么诸如此类，把它立法，共产党还干这种事儿。

>> 那你不让我父母见我、见他们的孙子，我那时候也有小孩，这算是什么文明？什么中华文明？我想从回归人性的角度来讲，我可以问一下中国政府。当然我也想问一下凡是中国政府的立场我都支持的我们的这些网民朋友们，你可以从人性的立场上说服你自己，顺便也说服我一下，人性在哪里？惩罚我父母的人性在……

惩罚我，OK，没道理，但至少我知道，我承认那个逻辑。没道理，有那个逻辑：我反对中国政府，所以中国政府拿过来惩罚我，也就是这么一点逻辑而已。

从道理上来讲，你不是叫人民共和国？你不是也主张民主这个概念？别忘了我们是中国大学生，中国能够考上大学都是好学生，我们都上过政治课，政治是中国大专联考考试的重要送分的100分。所以这个政治课里边一直教会了我们，共产党取得政权是建立了人民民主政权，所以“民主”这个词共产党并没有完全否认。但他当然用不断地给它加新的定义来完成这个否认，来否认我们这些海外的民主运动者，或者天安门的民主运动，民主得是“人民民主专政”。所以民主和专政放到同一个词里边，这也是共产党的发明。

>> 对，是是是。

>> 那这种事儿也希望，只要在政府的立场我就支持的……你不喜欢我们叫你五毛粉红，我也不喜欢给你扣这么个帽子，我也希望你能够在充分的资讯的情况之下，能够秉持着良心和理性和逻辑，能够来说服你自己，也说服我，那你总可以说服，我们来讨论一下这个问题嘛，对不对？那民主和专政放在同一个词里，这个发明有点无聊，我这句话可以成立。

最后我刚讲了，闯关宣言里边最后一个就是说惩罚我父母不对，那我总希望回国能够跟中国政府对话，哪怕用起诉书和答辩状，那我也希望能跟我父母见见面，哪怕是隔着厚厚的玻璃墙，能够以探监的方式让我父母能见面。

秉持着这样的想法，2009年我做了第一次闯关投案的努力。飞机飞到了澳门，然后在澳门被澳门政府……澳门政府当然也是大概一个多小时之前才知道我宣布我要闯关，他们才知道，那他们也不敢做主。所以我到了入关的时候，我就说我是中国政府通缉犯，我来投案的，那到底是一国还是两制，你们决定。按照一般任何的基础逻辑来讲，我作为中国政府的通缉犯，我来到中华人民共和国特别行政区来投案，你把我逮捕递解回中国是最合理的一件事儿，你们应该同意。

>> 对。

>> 他们拒绝回答我任何问题，就把我请到小房间。那也很简单，我当然也知道他们在干嘛，他们在打电话到北京嘛。

>> 请示，请示。

>> 但那是个礼拜五的晚上，我到澳门的时候已经五六点钟了，反正在北京找人上班还不容易这个时候，所以留了我一段时间，留了一夜。到了第二天，大概终于得到了答复，或者是没得到答复，我不知道，但澳门政府至少做了一个决定：把我遣返回台湾，因为我是从台湾来的。

他们给的理由是什么？危害国家安全。危害国家安全应该不是按照澳门自己的入境条例。然后他给我的任何东西，我都说我拒绝签字。他说没问题，我们知道你有拒绝签字的权利。很有意思的一件事儿。而且我也可以打电话那个时候，媒体来采访我也接受。我就说澳门边境检查的警察是足够专业的、足够文明的，我没有被暴力对待，但是他们显然做出来的这个决定——拒绝逮捕我、把我遣返回中国——这件事情是逻辑上完全站不住脚，政治上也荒谬的。那这件事情是我2009年第一次闯关。

2010年，在2009年到2010年这段时间，我还发生过，就是我到美国的时候，在美国的中国大使馆试图投案。你看中国大使馆的门锁得很严，不让你进，完全不让进。

>> 他知道你要去。

>> 这六四在抗议，外边人都在抗议，所以我按门铃什么的，一边抗议……

>> 现场就禁止。

>> 对对对，按门铃也没有用。

如果刚您讲说很多朋友关心这件事情，很多人在政府和民运之间会自动选择站在政府那一边，我充分理解，我再三表达充分理解，甚至可以用同情。为什么？因为他们被剥夺了资讯自由的权利，他们没有得到充分的自由，是共产党剥夺的。而我们推动的中国的民主运动，就是要让人民获得充分资讯自由的权利能够被重建，能够让中国人民除了得到共产党灌输宣传的资讯之外，能够得到人民应得的所有的资讯，这是民运的宗旨。89年到今天37年过来，仍然是。
