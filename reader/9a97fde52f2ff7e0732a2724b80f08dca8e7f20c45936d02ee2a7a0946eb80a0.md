### 開場：亞洲女性的減重誤解與荷爾蒙影響

>> 亞洲女性最大的誤解是總是想著要燃燒卡路里，而不是增強體質。他們沉迷於節食，不斷稱體重，並過分關注體脂，卻忘記關注肌肉量；他們通常不是「過胖」，而是「肌肉不足」。

>> 禁食和低碳水化合物飲食對男性非常有效。過去許多醫學研究其實都是以男性受試者為研究對象。我們大大低估了荷爾蒙對人體的影響。我非常擔心圍絕經期和更年期體重增加；女性所面臨的不僅僅是「不夠」，而是「什麼都不是」——這是一場巨大的、即將到來的風暴。

>> 你曾經有過體重焦慮嗎？

>> 是的，因為我自己都沒意識到。

>> 真的嗎？難道我們真正需要關注的，是我們的體型，而不是我們身材焦慮嗎？是焦慮本身造成的，對吧？

>> 現在您看到的是精彩片段版本；如果你想看完整版，請加入我們的官方 LINE 帳號。我是宋彥仁醫生，今天這不是來賓訪談。這是一次內部會議。我邀請了我們自己人中的一位。醫生，歡迎您。請你自我介紹一下。

### 臨床經驗與更年期案例

>> 我是家庭醫生，當然也是體重管理專家，擁有十多年的臨床經驗。我對減肥有了一些新的看法，也許是因為我自己也是女性，所以我的病人群體也以女性為主。從減重和女性體重管理，在過去幾年裡，我越來越關注更年期和女性健康等議題。

>> 我知道您越來越關注女性減重、女性荷爾蒙，甚至更年期護理。你如何定義你現在所做的事情？

>> 我把自己定義為女性健康和自我價值的倡導者。從醫生的角度來看，與其說我在治療他們，不如說我在引導他們增強自身能力——使我的病人，特別是女性，意識到我們實際上可以更好地掌控自己的健康。

我認為這一點尤其重要，因為事實上正是患者把我帶入了這個領域。我記得我剛加入的時候，宋醫生，您教了我很多關於女性體重管理的經驗，對吧？然而，我從一開始就遇到了瓶頸。

起初，這個案子看起來很簡單。她大約46、47歲，體重長期以來一直穩定在55公斤左右，但在過去一年增加了4公斤，從55公斤增加到59公斤。她其實很焦慮，因為她本來就不胖，但你知道那種體重快要達到60公斤時的焦慮感嗎？說實話，真是讓人緊張兮兮的，嗯哼。我想，用我們的減肥方法，減掉四公斤應該不難，對吧？你知道，這簡直易如反掌。

結果，我還是花了大概半年。起初，我覺得四公斤很簡單。從她的飲食習慣來看，她其實吃得很健康。當她開始增重時，她已經戒掉了加工食品和含糖食品，甚至控制了碳水化合物的攝取——基本上就是血糖管理。然後，她和丈夫一起跑步，但丈夫瘦了，她卻一點也沒變。

看到她當時的飲食狀況，我感覺有點「哇，她的飲食真的沒有太多調整的空間了」。所以我開始幫她適應，但兩個月過去了，她只減掉了一公斤。

但這位病人很有意思；她感覺很好。我問：「真的嗎？」「為什麼？」「因為我覺得我的腰圍真的小了，褲子也寬鬆了，而且我也不再覺得那麼脹氣了。」雖然她仍然希望減掉剩下的三公斤，但她覺得這是一個好的開始，而且她實際上比以前吃得更多了。

>> 嗯哼。

>> 我心想：「哦，還不錯，她的新陳代謝似乎有所改善，但這三公斤體重到底是從哪裡來的呢？」「我該如何幫助她減肥呢？」

於是我想，「好吧，那我再問幾個問題吧。」我發現她過去兩年月經一直不規律，但她並沒有太在意，也沒有意識到這與她的體重增加有關。她當時就想，「好吧，我沒有潮熱之類的症狀。」所以她就沒理會。

我心想：「等等，這或許有關聯。」所以我檢查了她的荷爾蒙水平，發現她確實已經非常接近更年期了。然後我開始和她詳細討論荷爾蒙如何影響新陳代謝，以及我們是否應該考慮補充一些荷爾蒙。實際上，這是一次非常個性化的討論，因為並非所有女性都適合或必須服用補充劑，所以她說，好吧，她願意嘗試一下。

>> 嗯哼。

>> 然後，令我驚訝的是，自從我們開始使用荷爾蒙後，她回來的時候，她又瘦了一公斤。我們花了兩個月才減掉之前的一公斤。

>> 唔。

>> 但這一次，不到一個月，她就取得了突破，而且她還沒有改變其他任何事情。哇，我突然意識到：「哦，這行得通！」

我們最初以為只是性激素的問題，但實際上它們對她的新陳代謝有著巨大的影響。它讓我明白，對於處於更年期過渡期的女性來說，我們有時會認為性激素無關緊要，但隨著我們身體逐漸失去這些激素，它們就像一股小力量，卻有著巨大的影響，你實際上需要首先關注它們。但同時，由於它並非獨立運作，而是與壓力系統和甲狀腺有關，我們最終能夠幫助她成功減肥。

### 男女減重的生理差異與荷爾蒙波動

>> 我真心認為，在減肥領域，應該設立一個「女性減肥」的次專科。我認為你最大的優勢在於你的同理心，以及你如何與你的病人建立起非常親密的朋友關係。所以，在這個角色上，我想問：您認為指導女性和指導男性減重的最大差異是什麼？

>> 從心理層面來說，這當然是一回事，但內在的生理條件從根本上來說是不同的。我們過去的許多醫學研究其實都是基於對男性的研究，直到最近幾年我們才開始關注性別差異。如果我們繼續從男性的角度看待女性的肥胖、肌肉量和身體成分，實際上會存在許多差距。

>> 好的，那我們就直接從先天條件開始吧。

>> 簡單來說，男性肌肉和體重都比較多，而女性的體型則比較小。所以，雖然我們不提倡暴飲暴食，但這並不代表我們認為卡路里或能量不重要；只是我們看待這些事情的方式不同而已。

>> 沒錯。

>> 第一個差異主要在於肌肉和基礎代謝，第二個差異在於脂肪其實也大不相同。每個人都應該聽過「必需脂肪」；女性的比例自然比男性高——男性約為 2% 到 5%，而女性約為 10% 到 15%。由此可見，女性的身體天生就更容易儲存脂肪。當我們試圖減肥時，女性很容易陷入困境，但這背後的原因是，我們的身體非常傾向於保留脂肪，因為它們感到不安全。

第三，是什麼在調節所有這些事情？當然，我們必須談談激素，尤其是考慮到男性和女性的性激素有顯著差異，對吧？男性主要受睪固酮驅動，而女性主要受雌激素驅動，嗯，但這些荷爾蒙實際上對我們的新陳代謝有著非常非常大的影響。所以，我一直對「性荷爾蒙」這個詞感到有點不自在，因為人們很容易認為它只與生殖或性有關。我認為「活力激素」這個說法更好，因為它們實際上與我們的活力、能量和生命力有關。

但更大的問題在於：男性的睪固酮水平不像女性那樣每天都在變化，它不會像女性的睪固酮那樣週期性波動。男性的睪固酮水平在一天中會有波動——可能早上較高，晚上較低——但每天的水平都比較穩定。

女性與女性不同；我們的雌激素和黃體素就像每個月都在跳一支舞，所以它們的波動基本上每天都不一樣，並且隨著月經週期而變化。隨著我們進入更年期，我們的卵巢也有使用壽命。我們體內雌激素的產生是有時間限制的；一旦卵巢失去功能，我們的雌激素，尤其是主要的雌二醇，基本上就完全停止產生了，更不用說孕激素了。

正如我之前提到的，這些物質是新陳代謝的主要調節劑，因為性荷爾蒙在人體中扮演著非常重要的作用，不是嗎？它們有助於肌肉合成和修復，也負責調節食慾激素，甚至我們的基礎代謝率也與雌激素有關。所以，說到男性和女性在減脂方面的差異，我真的要說——這不僅僅是因為我是女性——我們需要對女性多一些同理心。因為對我們女性來說，脂肪燃燒每天都發生在不同的生理環境下。這與男性截然不同。

>> 嗯哼，因為我自己也是個男人，所以我比較能體會男人的感受。

>> 正確的。

>> 此外，在我自己開始服用睪固酮補充劑後，我真切地感受到了這些荷爾蒙的力量；當時的感覺就像是，「哦，原來睪固酮水平低的時候就是這種感覺。」

>> 嗯。

>> 當然，當你補充一些睪固酮時——不用很多，只需少量——你會感到精力充沛，情緒穩定下來，你甚至可能會發現自己可以冷靜地處理一些你通常無法忍受的事情。所以，荷爾蒙是否充足或平衡，實際上不僅影響你的體格，也影響你的心態。

>> 確切地。人們總是說，因為女性體內有性激素，所以她們的情緒更容易受到影響，但正如你剛才提到的，區別在於性激素缺乏時和補充時發生的情況。

但女性面臨的不僅是不足；這是徹底的消耗。尤其是在更年期之前，它不會慢慢消失——它就像一場巨大的風暴，在高峰和低谷之間劇烈波動，「高峰」甚至可能超過我們生育年齡的巔峰，然後再驟然下降。即使週期看起來仍然像月經，雌激素和黃體素水平每個月都會變化，有時甚至一個月內可能會排卵兩次。

### 瘦胖型迷思與增肌的關鍵性

>> 從您的角度來看，鑑於您對女性問題的廣泛關注，您認為女性減肥方面最大的誤解是什麼？

>> 我認為亞洲女性，尤其是「瘦胖型」女性最大的誤解是，她們總是想著要燃燒卡路里。但他們並沒有考慮建造房屋。

>> 嗯哼。

>> 我的意思是，因為他們總是專注於自己的體脂率——可能是 30% 甚至超過 35%——他們總是想著，「我需要減脂，我需要減脂，我需要瘦下來。」所以他們的策略變成了瘋狂節食、過度運動，并不斷查看體重秤，看看自己是否減掉了 0.5 到 1 公斤，但他們卻忘記考慮自己的肌肉量。所以，他們往往不是“過胖”，而是“肌肉不足”。

就在不久前，我遇到了典型的這類女性；她心想，只要吃完飯，就得去跑步消耗這些熱量。她每天都會運動。如果你不運動，你會因為沒有消耗掉這些熱量而感到有點內疚，但你又會不斷地想著如何吃得更少；你為什麼不想想是什麼把你的脂肪鎖在了體內呢？那麼，由誰來決定這些脂肪是被分解、儲存還是釋放呢？那應該是激素。

>> 嗯哼，沒錯。

>> 第二個誤解是我們低估了荷爾蒙對身體的影響，尤其是對女性的影響。一旦感受到壓力、危險或不安全感，它就會透過壓力系統、胰島素阻抗，甚至減緩甲狀腺調節來輕易儲存脂肪，因此我們的新陳代謝可能會變得更糟。

有些女性體重下降到手腳冰冷、掉髮、極度疲勞，甚至閉經的程度，這會形成惡性循環。如果你真的停經了，你的身體就會進入類似更年期肥胖的狀態，這只會讓你更容易長胖，對吧？我希望女性思考如何保持荷爾蒙平衡，讓她們的身體感到安全、無壓力和營養充足，這樣她們就可以從自身的代謝中發揮作用，而不是只想著「我需要少吃，我需要少吃，我需要少吃」。

>> 許多女性表示她們不希望肌肉太多，因為她們害怕變得過於魁梧。從你的角度來看，我們需要增加肌肉，但我們真的需要舉重嗎？

>> 毫米。

>> 跑步、瑜珈或皮拉提斯等運動有幫助嗎？

>> 它們很有幫助，但重點不同。每項練習都有其自身的作用和目標，所以你不能說哪一項比另一項更好。首先，除非你非常投入、訓練很多、吃得夠多，否則很難練出非常健壯的身材。

>> 毫米。

>> 說到吃得夠多，我觀察到很多女性的想法是對的——她們想要增肌——但她們最大的問題是吃得不夠。

>> 嗯哼。

>> 最終還是回到了體重問題上，因為他們害怕體重計上的數字上升。他們可能會達到某個階段，心想：“好吧，我要增肌，我要舉重”，但一旦他們舉重一段時間，看到體重秤上的數字上升，他們就會害怕繼續下去，然後又開始節食。當我們到了某個年齡，例如 40 歲或 50 歲，我們的雌激素水平就會下降，這使得增肌變得更加困難。

很多女性都說：「我擔心更年期體重增加，所以我現在需要盡可能多地減肥，以便為更年期留出一些緩衝空間。」我說不，你應該反過來想。趁著雌激素仍然活躍並保護你，你應該現在就開始增肌。

>> 是的，要鍛鍊肌肉，這樣才能有代謝緩衝能力。

>> 而且這不僅關乎肌肉；這也與骨密度有關。這些能力的喪失並不僅僅在更年期後加速；這種情況發生在圍絕經期，此時荷爾蒙水平波動。

>> 您在診所裡有沒有註意到，很多身材苗條、體脂率高的「瘦胖」女性實際上患有糖尿病前期或高血糖？

>> 是的，很多。

>> 沒錯，還真是不少。

>> 他們常說：「我不能少吃，而且我已經在做有氧運動、慢跑等等了。我該如何控制血糖呢？」我問他們：「你們忘了嗎？」肌肉是人體最大的血糖消耗器官。

>> 是的，它是一個幫助你燃燒糖分的器官。

>> 所以，如果你想要一個天然的血糖控制夥伴，你需要增強肌肉力量。

### 禁食法在女性身上的應用與爭議

>> 關於肌肉方面，根據您的觀察或您閱讀過的文獻，禁食和低碳水化合物飲食對男性真的非常有效嗎？但許多專家表示，女性不應該禁食或低碳飲食。您如何看待這個問題？

>> 並不是說禁食本身從根本上來說是錯的；關鍵在於你怎麼用它。它只是一種工具。

當男人齋戒時，通常會遵守規則——如果你告訴他們在某個時間段內不能進食，時間一到他們就會吃飯，對吧？但女性的情況則不同；即使時間到了，他們也可能不吃東西。為什麼？他們會想，“反正我不餓，我可以少吃一點”，對吧？如果他們抱著低脂低碳水的心態，那就變成了禁食+低碳水+低脂。他們甚至連足夠的蛋白質都攝取不足。

>> 這是女性特有的思考方式嗎？

>> 我認為這是一種心理狀態和心態。尤其是在談到減肥動機時，男性通常是為了健康，而女性通常是為了外表、自尊和自我價值。所以，關於是否進食的焦慮，以及對食物的恐懼，我認為，嚴重得多。

>> 你的意思是說，當女性採用這種禁食策略時，她們往往最終會做出錯誤的決定。
