摘要

文章介绍了 Agent 工具 Enconvo，它被描述为一个“AI 操作系统”，集成了截图、划词、启动器、灵动岛、邮箱、视频会议等多种功能，旨在提供一个“AllinOne”的解决方案。Enconvo 的核心优势在于其对第三方 Agent 的兼容性（ACP 协议）和生态的整合，它将多个 AI 模型和工具（如 Codex, Grok, CC）统一在同一个界面，强调“谁离用户的工作流更近”而非单纯的模型差距。

一个你可能没听过但很牛逼的 Agent 工具：Enconvo

向阳乔木

在 Agent 产品这么卷的今天，我以为基本到头了。

直到朋友给我看了他们的产品 Enconvo，我震惊了，这 TMD 卷出花啊！

我只问了一句：明天北京适合钓鱼吗？

除展示天气外，竟然生成了一个建议钓鱼时段日历...

开启实时屏幕，选 Chrome浏览器，随口问：“有什么值得看的帖子”。

Agent 调用 Computer Use ，打开 X 看我的时间线，推荐了一堆帖子，质量竟然相当不错！

总结的帖子如下，有币安被盗、宝玉 Skill 更新，还有观看理由，比如传播速度等，摘要也言简意赅。

最恐怖的地方，这只是 Enconvo 产品功能的一小部分，大概 10%？

下面，再介绍 30% 有意思的功能，大家就能理解这个产品的含金量了。

安装体验

EnConvo 目前支持 MacOS、安卓和 iOS版本。

下载地址：https://www.enconvo.com/

安装后进入用户引导，做的很用心，还能给你的 Agent 选 3D Avatar 形象和对话语音。

如嫌引导长，可点右上角“Skip Setup”，以后也可以随时设置、调整。

IDE 与 智能体

刚进入 App，可能会愣住，为啥会有 Codex 、CC、Grok？

后来发现，它把第三方 Harness 工具全包在产品里了，因为这些 Agent 都支持 ACP 协议（Agent Client Protocol）

假如你同时订阅了 Grok、CC、Codex，完全不用来回切 App，每次重新说背景，点击切换 Agent 就行。

模型选择、推理强度、权限控制，几乎做到了 1:1 复刻，跟用原版产品差不多。

想想就觉得巴适，复杂任务让 Opus 5.5 规划，更难上 Fable 5.1，Computer Use 用 Codex，生视频用 Gemini 或 Grok build。

工欲善其事

想让 Agent 发挥出潜力，那必须要有插件、Skill、MCP，获取更多上下文数据。

海外大量常用工具全有内置插件、MCP，也可以自己上传，或从 Github 安装。

触手可得

很多朋友电脑都会安装各种划词翻译工具，方便读外文。

所以，豆包等 AI 客户端都会支持划词功能，EnConvo 也不例外。

说实话，我很讨厌这类 Popup 划词工具，装多了互相打架，但有时又真需要。

看 EnConvo 的设计就比较合理，专门有个减少弹出的设置，层层递进：

当前网页域名不弹 -> Chrome 不弹 -> 彻底关闭

有些朋友可能知道 Popclip 这个划词工具，感觉他们被 EnConvo 不小心偷家了。

EnConvo 的 PopBar 完全兼容 PopClip 插件，直接共享生态繁荣，哈哈哈。

https://www.popclip.app/extensions/

相比 Popclipr，我日常用 Raycast AI 这个工具比较多，逢人就安利。

EnConvo 也有类似功能，按快捷键 Option + Space（空格）就能换起快捷对话框，就能跟设定好的模型提问对话，还会给出建议添加的上下文。

屏幕涂鸦支持截图标注，作为上下文交给 AI 对话，连第三方截图工具都省了。

像 Raycast 一样，也支持很多高频小工具，比如 OCR 识别图片、截屏、听写、下载视频等等。

为了更方便，EnConvo 还支持灵动岛交互。

只需把鼠标移动到刘海屏位置，就会出现 AI 对话框和小工具入口。

记忆系统

很多 Agent 产品的记忆系统设计都很不直观，你也不知道去哪里修改。

EnConvo 做的不错，不仅可以从聊天中自动学习记忆，还能从知识库、录音中学习检索。

每天也有“做梦”机制，整理记忆。

还能主动添加记忆，随时查看，基于记忆问答，演示如下：

让它读取我的官网，了解我存为记忆，所有信息都变成一条条事实记忆，自动打上标签。

办公效率

提到办公，那少不了开会，跨国团队不需要安装钉钉、飞书或其他会议工具。

EnConvo 直接就能开会，视频会议-> 立即开始

把链接发给别人就能一起开会。

EnConvo 产品迭代很快，你如果你喜欢尝鲜，可打开内测版。

设置 - 通用 - 内测（开启内测版，每天都会更新）

今天更新了在线会议，可多语言实时同声传译，太方便了。

为测试同传，我随便打开了一个视频播放，能实时识别显示字幕。

服务商支持

打开设置，最靠前的是各种服务商设置，几乎把所有服务商都涵盖了。

无论 AI 模型，文本转语音，图像生成，视频生成，OCR，网页搜索/抓取，全是行业最佳实践。

如果懒得自己配，那就直接用官方订阅，如果有 API，也都可以填自己的用，还支持连接 ChatGPT 等订阅。

开发体验

试着用它开发了一些网页，体验和 Codex 一致，支持内嵌浏览器，支持生图，支持选择元素编辑。

做了个万有引力科普漫画。

对子 Agent 支持也不错，要求它调用不同智能体和模型，对比生成效果。

有意思的地方：每个项目都会给个看板，随时查看运行状态，哪些在进行，哪些要你确认。

开发过程中，灵动岛也会显示进展，让 AI Coding 更有掌控感。

移动开发

EnConvo 提供 iPhone 和 安卓客户端，可以用手机随时对话，也能控制电脑，随时随地给 Agent 安排任务。

也支持即时通讯工具连接，不过主要是海外的流行 IM 绑定。

个性化

Codex 的虚拟形象推出后，各家纷纷效仿，EnConvo 也有，还给模型加上了动作和语音口型...

我原以为大可不必这样卷，直到我捏了个形象，然后发现 Avatar 可绑定不同智能体。

觉得还是有一定价值和可玩性。

除了 Agent 虚拟形象，还有专门的宠物，居然是两个系统，团队开发战斗力太旺盛了！

写在后面

别看介绍了这么多，还有大量功能没讲到。

比如语音转写/问答、知识库、密钥管理、本地模型等等…

一篇文章根本写不完。

高强度用一天，最大的感受是：EnConvo 不是一个 Agent，而是一个"AI 操作系统"。

截图、划词、启动器、灵动岛、邮箱、视频会议、各 AI Agent...

EnConvo 思路很简单：全收了，AllinOne。

且不是简单堆功能，ACP 接第三方 Agent、兼容 PopClip 插件生态，都是很聪明的做法。

不过缺点也很明显，功能太多，给普通用户压力有点大。

但瑕不掩瑜，小团队能把产品做到这种完成度，挺让人佩服的。

说下工具适合什么人：

订阅了多个 AI 工具，想统一入口

重度 Mac 用户，喜欢 Raycast、PopClip 这类效率工具

OPC 或远程协作小团队

如果你是，建议下载试试：

https://www.enconvo.com/

Agent 卷到今天，本以为大家拼的是模型。

用完 EnConvo 才发现，模型差距越来越小，拼的其实是"谁离用户的工作流更近"。

EnConvo 的思路，没毛病！
