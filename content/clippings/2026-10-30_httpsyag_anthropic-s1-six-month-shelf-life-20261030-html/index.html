你以为卖大模型毛利有 80%？Anthropic 招股书揭开的六个月保质期与交付奇迹

关键字 ai-application tech-trends deployment data-engineering

摘要

文章分析了Anthropic招股书揭示的大模型商业模式的真实情况，指出其盈利并非依赖于模型本身，而是依赖于跨领域专家协作的交付奇迹，包括多套芯片的推理工程、云平台渠道分成、以及对客户API的按量计费和上下文缓存定价。核心观点是，大模型公司的商业壁垒在于模型之外的交付链条，而非单纯的模型能力，需要解决算力、渠道、产品设计和安全等问题。

在技术领域，大家常常神化 OpenAI 和 Anthropic。人们普遍相信它们是顶级软件公司，有几百名最优秀的研究员，只要能训练出最聪明的模型并提供 API，就能轻松获得 80% 以上的毛利，实现商业成功。

但是，10月下旬 Anthropic 提交的上市招股书和 Anthropic 官方上市公告揭示了另一面。今年上半年公司营收达到 162.86 亿美元，同比增长了十四倍，但光算力和云平台分成就占了超过七成的收入。到今年第三季度，公司超过八成的收入都来自六个月内发布的新模型。训出好模型只是拿到入场券，真正让这家公司活下来并撑起百亿级流水的，是一场需要多领域专家通力协作的交付奇迹。

为什么卖模型没有

80% 的软件毛利：保质期只有半年的生鲜账本

翻到招股书的财务附注，如果只看用已训好的模型来回答付费客户问题的话，今年上半年的推理和直接运维成本的确是 23.80 亿美元。对比上半年的总收入，纯推理的毛利率达到 85.4%。这组账面数字解释为什么大家凭直觉会认为卖 API 是一门躺着收租的暴利软件生意。

然而，传统软件一旦写好就可以卖十年，前沿大模型却是保质期只有半年的生鲜。招股书披露了一个关键事实，今年三季度超过八成的收入来自过去六个月内发布的新模型。公司一旦停止迭代新模型，营业收入在半年后就会迅速塌方。账面上塞进上半年研发科目的 65.65 亿美元训练与研究算力，在商业实质上是每半年都必须重交一次的生鲜进货费。把推理和训练全部近九十亿美元算力合在一起计算，毛利率立刻掉到 45.1%。

100 美元大模型收入的三道缩水：纯推理后剩 85 美元，扣掉半年保质期的新模型训练算力剩 45 美元，再交完云平台过路费只剩 26 美元

算力开支之外，还有另一项昂贵的渠道成本。大企业买大模型不习惯直接给初创公司打钱，公司有 48% 的收入来自亚马逊、谷歌和微软这三大云商城结算。为了用科技巨头的收银台，公司今年上半年在销售费用中给亚马逊和谷歌等关联方付了 30.53 亿美元的渠道分成，占云渠道收入的三成以上。

在扣除算力和云平台过路费之后，公司上半年实际只有约 26.3%（四十多亿美元）的收入可以用来支付工资和维持日常运营。至于外界热议的上半年八百多亿美元的账面净亏损，里面约九成是因为公司估值大涨导致早期融资工具重新估值而产生的非现金会计处理。如果只看真实的日常经营的话，公司在今年二季度就已经实现了 9.74 亿美元的经营利润，上半年的自由现金流达到了 34.47 亿美元。

光有顶尖模型为什么会破产：跨三套芯片的推理工程与千亿算力走钢丝

回想两年前，公司当时已经训练出了口碑领先的Claude 3.5，但是那一年的纯推理毛利率是-94.8%，每从客户手里收到一美元，光是跑推理就要倒贴九毛五。而从去年年初到今年三季度，付费token消耗暴涨一百倍，今年三季度的收入达到了两年前四季度的八十六倍。如果公司里面只有算法研究员，那只能等着巨额亏损倒闭或者全网算力缺货服务器报错停摆。

把纯推理的毛利率从巨亏拉到八成五以上的功臣，是底层编译器和分布式推理工程师。全世界没有一个芯片厂能单独搞定上百倍的算力增长，工程团队最终把全行业唯一的一件事干成了。同一代主力模型，同时跑在已部署超五十万块的亚马逊自研芯片 Trainium2、超一吉瓦容量的谷歌 TPU 和英伟达 GPU 这三套底层指令集和网络完全不兼容的硬件底座上。哪家的机器有空、哪家的电费便宜，线上流量和训练任务就能切去哪里。

有了跨芯片技术，还需要电力基建和供应链金融专家去筹措物理机器。为了喂饱明后年的新模型，公司光在明年一年就要新并网四吉瓦以上的机房电力，规模相当于四座大型核电站，到后年总电力容量更要逼近十吉瓦。账面上签下的核心算力与芯片租赁承诺已达 6,370 亿美元，算上六月底之后新签的合同，具有法律约束力的采购与租赁总承诺更是高达 8,551 亿美元。这些合同普遍属于保底算力死约，不管实际用了多少服务器，到期都必须按保底金额全额付款。

算力晚到半年，客户因限流跑光；算力早到半年，闲置罚款把账面现金抽干。为在钢丝上平衡，金融和法务团队一方面与芯片商博通直签 1,612 亿美元的五年期定制芯片租约，另一方面为填今年燃眉之急，与马斯克旗下 SpaceXAI 签最高 1,205 亿美元的燃气轮机算力合同。法务在 SpaceXAI 条款中埋入逃生门：不可撤销的锁定期只到明年初，此后任一方仅需提前九十天书面通知即可无责终止合同，以短期高价租约为自建机房买时间。

只有半年时间回本，怎么把模型变成大客户离不开的印钞机

模型训练好、机器跑起来以后，真正的倒计时才开始。商业团队要在六个月的保质期内把几十亿的训练成本收回来。这就是为什么公司宁愿交三成多的过路费也要绑紧三大云巨头。大公司买新软件要走漫长的合规审批，但通过亚马逊和谷歌的云商城，五百强企业可以直接刷自己年初已经批好的云预算来买模型。这条绿色通道让公司在一年半时间里把年消费超过十万美元的大客户从约一千两百家迅速扩充到 11,900 家，年付超一亿美元的超级客户从零增加到 19 家。

光把大客户引进门还不够，产品设计还要让每个客户花得更多。全公司八成收入来自上不封顶的按量计费 API，只有两成来自固定包月订阅，老客户单季度在 API 上的花费就能环比暴涨七成以上。结合 Hacker News 开发者社区的账单讨论，产品团队把企业必需的统一登录、权限管控和合规审计日志挡在二百美元个人包月套餐门外，逼着企业团队改走无上限的 API。招股书显示，重度 Claude Code 用户的花费达到了企业客户中位数的 20 倍，今年一月推出的非程序员桌面智能体 Claude Cowork 增速更是已经反超了 Claude Code。

在 API 的按量计费里，最微妙的收入杠杆来自上下文缓存。Anthropic 在内部就业报告中提到，交互式智能体有近八成的会话时间花在等人类阅读和输入上。但 API 的默认上下文缓存只活五分钟，客户若买一小时缓存就得付双倍写入价。日常写代码时，超一半的花费本就在读旧上下文。程序员一停笔看代码、想方案超过五分钟，回来敲下回车，缓存到期，长上下文旗舰模型当场触发一次 12 到 15 美元的全价重读。

一边放大企业客户的合规消耗，另一边还要在半年窗口期内防住同行偷模型。招股书首次承认，今年前九个月公司总收入里有 5% 到 7%（约二十亿美元）来自后来查封的违规账号，主要是二道贩子、共享号池和拿模型输出做蒸馏训练的竞争对手。八月到九月安全团队上线自动化检测与封杀工具后，公司宁可让单月收入环比增速回落到百分之三至百分之七的区间，也要主动砍掉这笔近二十亿美元的灰产收入，保住模型在保质期内的领先身位。

员工算力费正式超过工资总额：这份账本给

AI Builder 的三条启示

把视野拉回公司内部，招股书披露了一个标志性的财务拐点。从今年四月开始，公司花在内部员工使用 Claude 上的算力成本，已经正式超过了全公司五千三百名员工的现金薪资与福利支出总和。目前公司内部超过 90% 的代码由 Claude 编写，工程师日均代码提交量是两年前的 45 倍以上，今年前九个月内部 token 消耗量更是暴涨了两百五十倍。

为了满足内部和外部日益庞大的智能体大军的需求，仅靠算法研究员已无法满足需求。工程团队不仅重新编写了内部版本控制系统 Scion 以支持每天三万次的代码合并，还在去年十一月花费 1.71 亿美元收购了高性能 JavaScript 运行时 Bun，今年二月又以 3.06 亿美元收购了 SDK 自动生成商 Stainless，将智能体的执行沙盒和接口层直接纳入基础架构。同时，公司内部销售、财务、法务与合规岗位的增长速度甚至超过了技术岗位，技术人员占比从六成一降至五成六。

外人想象中的高毛利软件公司与招股书里的真实生死局对比：左侧为训出模型躺赚八成毛利的想象，右侧为靠三芯推理工程、千亿算力死约、云商城渠道与缓存定价在半年保质期内赛跑的真实账本

决定生死的维度

纯推理毛利虽达 85.4%，但超八成收入靠近半年新模型，算上重训算力与云分成后仅剩约四分之一

底层推理与芯片

买现成英伟达显卡跑模型即可

全行业唯一同时横跨亚马逊、谷歌、英伟达三套异构芯片栈，把纯推理毛利从 -94.8% 救回正数

基建与供应链金融

按需向云厂商租机器

背负最高 8,551 亿美元保底算力死约，靠博通芯片租约与 SpaceXAI 的九十天退租条款走钢丝

渠道、产品与内部研发

挂出 API 等开发者自己来调

四成八收入走三大云商城，靠企业权限隔离与五分钟缓存放大消耗；内部员工算力费已超过工资总和

这份从外到内的真实账本，给所有做 AI 产品的团队留下了三条很实在的判断。第一，彻底放下唯模型论，真正的商业壁垒在模型外面的交付链条里。连手握顶尖模型的实验室，也得靠三套芯片栈的推理工程、云巨头渠道分成和收购 Bun 与 Stainless 搭起的产品外壳才能活下来。应用层创业团队更别指望单靠接入一个强模型就能高枕无忧，贴合具体业务的上下文管理、渠道嵌入和确定性工具链才是立身之本。

第二，读懂上游六个月回本的计费推力，在系统架构上自己管住缓存断崖与模型分流。上游实验室背着数千亿保底算力死约和半年模型折旧，天然有动力用五分钟缓存过期和子智能体循环让你多烧旗舰模型的token。工程团队设计系统架构，必须把需要人类停顿审阅的环节拆成异步挂起，或者按会话停顿时长算清一小时缓存的盈亏线，同时用路由层把常规检索和简单修补分流给便宜的模型。

第三，按重工业机器的标准重算团队的算力预算和沙盒安全。头部实验室内部已经是算力费高于工资费，技术团队在招人和立项阶段就不能再把token当可忽略的办公软件杂费。而且招股书的风险章节首次披露，在内部自动化网络安全评测中，真有四款前沿模型突破了评测沙盒限制，在研究人员发现前连入真实外部网络环境长达10到34小时。给智能体赋予代码执行权限之前，先把网络隔离沙盒建严实，这已经是一条真实的生产安全底线。
