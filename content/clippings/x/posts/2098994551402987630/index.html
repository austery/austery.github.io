过去一年我的 P&L 超过了 150% https://t.co/urE6Bthoxc 今天起床到现在，饭没吃，水没喝，用 GPT-6 Ultra 跑掉了约 7.1 亿 token，消耗了一份 $200 Codex Plan 一周额度的 90%。过去的12 小时，烧掉约 7.1 亿 token。我正在把自己的投研大脑快马加鞭蒸馏出来 目前在开发的，一共五个功能： 1/ 一个被“蒸馏”出来的芒格君 把我的投研思考方式做成可以直接对话的大脑：一家公司的生意怎么理解，哪些变化值得追，什么证据会让我改变判断。 你可以拿着自己的问题，跟这个大脑一层层聊下去。投研大脑 as a Service，这是我最想做好的部分 2/ 把一只股票过去一年的财报和电话会议，变成可以随时追问的资料库 先从我们深度追踪的股票做起，接入第一步的大脑，带着大家读细节。比如：“管理层这次的说法，和上个季度有什么不同？” “之前承诺的增长，到底兑现了多少？”我希望这些问题，都能回到具体材料里讲清楚 3/ 投行研报的收集，以及真正能聊明白的深度对话。 对深度追踪的公司，把研报收集、整理起来，让大家可以继续问：这家投行为什么看多？它最关键的假设是什么？另一家为什么不认同？读完之后，你应该能理解它的判断，也能知道自己是否同意 4/ 把不同渠道的观点和华尔街预期放在一起看。 整理我平时从各类渠道收集的观点、机构分析师的分析，以及华尔街目标价共识、新增目标价和调整。我尤其想让大家看懂：同一家公司，大家到底分歧在哪里？这次上调目标价，背后的理由变了什么？ 5/ 把我的投研 Agent Team，也开放给大家 Agent Team as a Service，全部由 GPT-6 / Fable 5.1 驱动。这支团队每天挖出的关键基本面信号、公司变化和新闻解读，我会放到平台上。让大家持续追踪自己关心的公司，理解新消息会怎样影响原来的投资逻辑 做到这里，我很想听听大家的真实需求： 你研究股票时，最费时间、最头疼、最想交给 AI 帮你完成的一步，到底是什么？可以直接在评论区讲具体场景。你平时怎么做、卡在哪里、希望它帮你做到什么程度，越具体越好 还是老规矩，点赞、收藏这个帖子，到时候拿着记录来，我送大家GPT-6 和 Fable 5.1 Token 来使用 如果你提的功能被我们采纳，并且真正开发上线，我会邀请你进入核心用户体验群，给你一对一 VIP 服务 平台还在做，大家现在提的需求，有机会直接决定它接下来长什么样。评论区欢迎分享，我会认真看 还是那句话，我不是一个短线交易的高手，因此短线数据点位依然给不了。这个平台不是给大家一个买入点位的，更多的是为了看懂。谢谢理解
