Ian Quigley: 好的，没问题。当你从事小分子药物研发时，终极目标就是找到一个小分子——也就是一个微小的化学结构——让它与你认为在疾病机理中引发问题的特定蛋白质靶点相结合，然后再以此为基础推进后续研发。在这些靶点蛋白中，有些蛋白很容易找到能够牢固附着结合的化学分子，而另一些则困难得多。传统的解决思路是把大量不同的化合物分别装在无数个单独的试管或小孔里，然后每次将蛋白质浸入一个试管中去测试反应，这种高通量筛选不仅极其缓慢，而且极其消耗时间和资源。

组合化学的结构相似性与机器学习的理想契合

Ian Quigley: 没错，确实如此。进一步拆解来看，如果你拥有数百万个分子构成的库，其实际本质是各类分子结构砌块的组合式产物。而这些基础砌块的绝对数量，要远远小于所有砌块完全排列组合后生成的最终化合物总量。在不同的设计示例中，最终产物数量往往是基础砌块数量的平方甚至立方级。因此，通常仅需几千个或几万个初始构建砌块，就足以通过组合化学衍生出一个包含数千万分子的庞大化学库。

从某些角度来看，这种机制存在一定局限性，因为你终究受限于那批相对较小规模的初始砌块种类。但是从机器学习的角度来看，它却具备一个无与伦比的绝佳特性：在生成的海量化合物中，你拥有了极多彼此高度相似、仅仅存在一两个局部差异的化学分子组合。正如我们稍后肯定会深入探讨的那样，这种密集而系统的微小突变极为适合用来做对照归因分析，让你能够精准辨别：“噢，正是小分子的这个特定基团驱动了与靶点的结合，因为我看到另一个区域发生大量衍生变异时，整体的结合活性并没有受到显著影响。”事实证明，这种系统性的对比特性对于算法模型的学习具有不可思议的巨大价值。

Ian Quigley: That is correct. Yes, yes. And so to unpack that a little bit, if you've got some number of millions of molecules, what this really means is it is a combinatorial mixture of building blocks, and the number of building blocks is going to be a lot smaller than the final product of all of those. So you might be squared or cubed, right, in some different example.
