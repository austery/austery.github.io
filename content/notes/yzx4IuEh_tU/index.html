评估与优化 Agent Skills：如何量化模型先验与新知识增量

关键字 agent-skills model-evaluation context-optimization prompt-engineering

摘要

Nikolai Petrov 探讨了 Agent skills 的评估与优化方法。通过构建评估任务（evals）并结合类似 FActScore 的拆解方法，对技能按条目生成问答，借助模型裁判在有无技能下进行对比测试，建立包含知识冗余、技能退化、新知识习得与概念未掌握的四象限分析，帮助精简已知内容并减少 token 消耗。
