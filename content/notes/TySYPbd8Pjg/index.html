AI 與公司提效的迷思

就千萬不要把 AI 拿來用來整個公司的提效。其實提效是一個很被動的東西，就你真的有增長的公司，你他媽不需要提效，對不對？對，你用增長就可以蓋過低效，你不需要提效。只有沒有增長的公司，你才會聊提效；只有需要業務對齊的、只有層層彙報的、組織效率低的公司，你才需要提效，對不對？你聽過字節跳動談提效嗎？就這句話嘛，就說哪個公司開始查考勤了，這公司快黃了，哥，基本就是這概念。所以我覺得提效是一個很爛的生意跟很爛的場景。就千萬不要把 AI 拿來用來整個公司的提效。你個人提效可以，但是你不要拿去給公司提效，對，我覺得這個沒有意義。

你要去做增長。但怎麼做增長，問題就來了：原本不會做增長的，給你 AI 你也不會做增長；原本不會寫代碼的，給你 AI 你也不會寫代碼，你寫垃圾代碼。對，但是原本寫優雅代碼的頂級程序員，給你 AI，原本做這個 SEO 的頂級操盤手，對吧，給你 AI 你就可以做到頂級。就這就是一個悖論嘛，對吧？因為我增長不好量化，ROI 量化不出來，那我就說我提了多少效，我幹了多少人，對吧？但你會發現說，你去年或者今年年初，你因為 AI 幹掉的人，雄心勃勃你裁掉了 30% 的員工，可你明年又要請回 10%，這個怎麼搞？所以我覺得說，這個應該是說口徑不一樣，或者是說大家對 AI 這個東西沒有個共識：它到底是省錢的，還是幫你賺錢的？但我覺得大部分現在老闆能想到的是拿去省錢。

大企業 Token 預算與合規困境

那我覺得我分享一些更有意思的啊，就是我最近還是有蠻多朋友在聊，也是年底做 AI 預算這個事情。然後老闆啊，但凡開會就要講 AI。但是呢我說我申請個 WorkBuddy，哈哈，老闆不批對吧？好不容易老闆換了個預算把你報銷了，讓你 TOKEN 自由了，對不對？然後呢這個 IT 內網不給用，哈哈哈，對吧？合規審計不通過，IT 內網不能用。啊就變成什麼，最後回家把公司的數據帶回家偷偷摸摸用用，哈哈哈，對吧？

你說這個事情怎麼解決？這個我解決不了。我跟你講，就是你越大的企業，這個事情越解決不了。我覺得這個真的是大企業面對一個 Token 的問題，就是我覺得越大企業越解決不了。這兩個原因啊，我個人分析啊。第一個原因是什麼？就是說這個 TOKEN 的使用無法量化，這個東西不能靠量化，對吧？就說前一段時間不是什麼 Amazon 還有說 Meta 都搞個排行榜，叫什麼 TOKEN Maxim，對吧？然後呢直接把這個所謂這個 TOKEN 最大化，誰排在前面誰就受表揚，誰就拿榜單第一，對吧？但是問題是這個發現什麼呢？很多員工都開始開很多無用處的東西 agent，然後開始把什麼 PDF 啊轉成這個什麼 PPT 啊，轉成什麼動畫呀等等，就做這種無用、無效功，然後把這個 TOKEN 加上去。可是呢，跟實際業務真的產生不了什麼實際效果。越大公司本身就涉及到什麼？就是每一個公司、每一個人的考核問題。然後這時候你再搞一個 TOKEN 在裡面，就變成這一個特別大的變量，所以這個事沒法搞。

可能跟編程有關的，對吧，那這種公司起碼還能有個人能來評估。但更多什麼呢？就是說 OK，到了一個企業裡面，比如說做銷售或者做客服，所有人都說我要用最新的模型對吧，我要做什麼動畫，以前我要出一個什麼圖我花多長時間怎麼怎麼樣，還是回到提效上，就還是回到提效上。但最終這個業績怎麼來衡量？到底這個事，比如說做了動畫出來，真的變成了多少點擊嗎？多少流量嗎？啊流量變成多少銷售嗎？所以這個事變成了，就是說我覺得這是一個螺旋架，就是變成了什麼：從 TOKEN 開始，但是又無法從 TOKEN 結束。就是 TOKEN 畢竟還是一個輸入，它並不是最終結果。所以這個事來講的話，對大公司來講，層級越多、然後業務越複雜，越無法說只是看一個 TOKEN 消耗量來看這個最終業績是不是真的，其實這個對大公司來講很難掰清楚的。你就說每個公司接了網線，那我接了網線上了互聯網以後，我的公司效率提高了嗎？我的公司多賺錢了嗎？對吧？除非你是原生的互聯網公司，對吧，你所有業務就依託於互聯網，從接網線的那一天開始你賺錢了，你生意模式構建於互聯網。但是對於大部分這種互聯網 plus、AI 的這種公司來講，其實它要算的這個事情要比別人掰扯得更多。所以你剛才說嘛，就是說有些公司以不變應萬變，這個還真的是一個選項，真的是一個選項。

而且還有一個問題，就是今年有一個特別明顯的現象，就因為 agent 嘛。agent 出現之後，agent 的 TOKEN 消耗量和個人的消耗量那不是一個概念。我看好像說有個數據，今年是咱就「JustSayAI早晚報」說的吧，就今年好像是在幾月份開始，就是 agent 的 TOKEN 消耗量已經超過人使用的這個 TOKEN 消耗量了，然後到年底的時候有一個 7 倍的差值。比如說現在全球啊，agent 使用的 TOKEN 和人使用的 TOKEN 來比的話，那 agent 是 7 倍的量。

啊你就想這個事吧，就說以前啊，比如說以前你在這辦公位上打開電腦弄個小窗看個視頻，或者說刷個抖音，完了呢你還怕老闆過來。現在幹嘛？現在你在工位上大張旗鼓的對吧，然後你突然開著好幾個屏幕，完了在裡面各種 agent 在跑來跑去，然後號稱在討論業務，然後呢你看這個東西在轉著啊，用時多少分鐘，然後你去接咖啡去了。老闆問你幹嘛，你說我等著我那 agent 跑呢。所以 AI 跟 TOKEN 消耗就是新時代的帶薪拉屎。對對對，沒錯，而且真正的結果別人又看不到，對吧，而且這還是在雲上。

所以反倒就是像你說一刀切，也不失為一個辦法。就是說索性所有人在公司都不讓用 AI 啊，然後你要想用 AI 回家用去，回家用我也管不著，你也別讓我報銷。你讓我報銷，現在就是說明你這個事跟我公司有關了啊。所以這個真的是，因為從審計來講哈，審計來講這個事情非常不可控的。我也理解非常多的大公司，你原本這個數據不出網，但實際上你要 AI 獲得智能，你就得給上下文，你就得讓 agent 去了解你的數據，給它記憶。那這個事情你不餵給它數據，你不主動餵它，那是不可能的，就完全不可能，你做不到不餵它，對吧？所以這個又陷入到一個兩難。

自建模型算賬與傳統企業的 AI 落地

就像當年上雲還是不上雲，對吧？這個事情爭了好久對吧。那最後大家當然都上雲了，對，大家也發現：誒，上雲我也沒什麼損失對吧，最後大家都上雲了。但目前是現在說大家有這個共識說能夠都用這個雲端 TOKEN 嗎？我覺得這個挺難的。為什麼呢？就是至少你現在自己布 Deepseek 肯定沒有比買 API 便宜。對了對，現在這是一個大部分團隊你自己去布 Deepseek 一定做不到它的 API 的價格。那這個問題就給到所有的企業了：那我是要相信 DeepSeek 呢，還是要布在自己公司呢？那是不是又不降本了？那這個設備折舊啊、然後人員維護啊、機房啊、雲端算力租賃啊等等這些怎麼做？啊這個就變成老的問題了，就是對跟新的 AI 帶來的老問題。

歸根結底還是算賬嘛，對吧？就是如果說咱不考慮業務的屬性，咱只考慮成本的話，那現在自建肯定是不划算的，對吧？你 API 的話本身是不斷更新模型的這個能力的，你自建了，你自建完了以後半年以後你模型都落伍了。然後第二點來講，現在顯卡你都買不到，啊你根本就買不著服務器、買不著顯卡，然後去做自己的這個數據中心或者說自己的這個自建模型。然後第三來講的話，對吧，現在還在不斷降價，就是即使同樣的模型，咱就不說性能提升，然後模型價格還在不斷降價，每年基本能夠按 50% 的價格往下降。所以怎麼著算，你這個折舊啊各方面都算下來的話，自建肯定都不是一條首選項。那有可能在很長一段時間裡頭，我覺得自建都不見得是首選項，因為畢竟來講的話，各個模型廠還在卷性能、還在卷這東西。然後有可能就是說，像這種保密性的、涉密性的，有可能是需要自建的，比如像銀行啊，或者說像這種量化公司，他自己需要搞 AI 實驗室，因為他畢竟所有的賺錢本事就是他的那些策略、那些方法。

但是咱其實我覺得這個事情是反過來的。這筆賬我是認為說大部分企業到今天這個時間點，誒，不需要用到那麼先進的 AI。對，我覺得是不需要的。是的啊。比如說像 TCL 這樣的企業，他所謂的通過 AI 創造 25 億元綜合收益這幾年，有多少成分是 AI？我覺得這個要打個問號對吧。對，我覺得可能 AI 的比例一半不到，啊有可能更多是用 AI 去把原本沒接通的接通了、沒打通的打通了、原本沒做完的項目給做完了，啊頂天是這樣子對吧。然後有的地方可能是視覺識別啦，就傳統的這種 AI 1.0 的東西。對，那實際上真的你說他 TOKEN 消耗量有多大嗎？我覺得未必，有可能他用一些本地的、相對一些簡單的模型就可以保障業務的運轉；有可能在開發的時候、在調通的時候，他可能用的是更先進的模型，有可能是這樣一種情況嘛。

所以我們現在說很多東西會打出 AI 的旗號，但其實我覺得這個背後東西是舊的。就像這個 FDE 對吧，FDE 為什麼我們從來不談？因為我們做了那麼多年 Saas，我們都知道 FDE 你最後在中國做的結局最終就是外包，對不對？那人家中國老闆是非常擰巴的，對不對：「來，你來給我這個提效。」然後我 FDE 到你公司完了做半天：「誒老闆你數據沒通啊，誒老闆你那個業務數據有斷點啊，對吧，老闆你這個原本數據很髒啊，老闆你這個信息化不行啊，你這幾個系統沒通啊。」老闆說：「媽的，腦子裡都是問題，我要你何用對不對？對，你教我做人嗎？」對不對哈哈哈。老闆就覺得說你最後你是要教我做人嗎？整天在我耳朵嗶嗶嗶嗶嗶，我是有那麼差嗎？對吧，你滾對吧，不付錢了。要付錢怎麼辦呢？要付錢就：「來，你給我帶來生意的收入。」然後結果 FDE 他跑去幹、跑去前線、啊跑去門店去做銷售，把你這業務流捋順了，幫你老闆賺到了第一塊錢的時候，老闆說：「媽的，那是我產品好，你滾。」哈哈哈，最終終局就是這樣子。

效率提升的矛盾與個人 AI 投入

嗯哎，你這個確實很形象啊，從這老闆這個角度來看。但是我從生意經看啊，我覺得在很多生意上面、就在很多行業裡面，無論是說做製造業也好，還是做服務業也好，還是做零售業、各種行業也好，我覺得好多生意都是很穩定的。這個穩定指的是什麼？不是說這個客戶穩定、市場穩定，而是說他賺錢的這個本質很穩定，可能就是那幾個核心的東西。比如說你把供應鏈控制得好，對吧，你把整個的流程控制好，你把整個的企業管理，比如像富士康，把企業管理、把人用得每個人用到位，然後呢甚至說這個資本的壓榨。反正你不管你怎麼來定義它，它的這個本身的系統是非常穩定的。然後這個時候你在 AI 可能能夠做到，可能也就是替代，比如說以前 10 個人做的事，現在能不能變成 3 個人做，完了呢加上 AI 的輔助，所以還是提效，就還是提效。它並不能改變說整個把這個生意本身改變掉，然後把生意的這個賺錢的本質改變掉。所以在這個情況之下，其實 AI 作用就很有限。

但我要挑戰你一個問題，就你剛才講到一個點嘛，就這個效率的提升嘛對吧？那我們假設一個公司原來 100 個人，那現在用 AI 每個人效率提高 10 倍，那請問老闆能真的賺到錢嗎？對對，首先我覺得這個事就是老闆和員工之間的不可調和的矛盾。咱舉個例子就說，假設啊，你現在的工作就是 8 小時都是寫報告，咱舉個段例，就是 8 小時就是給老闆寫報告。然後現在你有了這個 AI 了，不論是誰家的，你現在變成了兩個小時能夠把 8 個小時東西寫出來了。那你剩下 6 個小時老闆會給你放假嗎？不會，老闆會給你找 6 個小時的新的活幹，對，因為還有勞動法對不對，你得做 8 個小時。對，而且你工資不會漲的對吧。而且就是說你只能是自我感覺就是說 OK，我這確實比以前幹得輕鬆點了，然後呢我可能對這 AI 已經離不開了，以後你要不讓我不用 AI 那我是活不下去了。但是你放心，工資不會漲，然後老闆的活也不會變低。同樣，老闆那邊可能收入也沒漲，因為做報告這件事以前可能就是必須要做、但是不見得產生收入的事，但是如果沒這報告以後可能連收入都沒了，但是並不會因為說你兩個小時把報告寫完了，然後就能多搞出 4 份、就公司就產生 4 份的收益來。所以這個我覺得是不可調和的，這是第一點。

然後第二點就是剛才說的這個問題，就是說好多模型不見得非用最強那個模型。就是這麼講，就是說咱就說寫報告這事，可能以前就是年初模型就已經很強了，完你再自己要是再有點心，做一些自己的上下文的這個訓練等等，他就能寫出很漂亮的、很符合你的要求的東西來了。然後呢可能這件事就是你再雕花，你也最多是從 90 分到 92 分、93 分、94 分，就算你到 100 分，同樣不會給你帶來只有 10% 的收入增長。所以這個我覺得是很重要的。那你說那明年你 TOKEN 還會再漲嗎？你 TOKEN 使用量還會多嗎？所以好多時候還是這個問題，就是說到底 AI 能帶來什麼，在各個行業是完全不同的答案。除了那種就像咱們說的，它以這個編程或者像這個量化，它專門是以這種東西，就是說計算機輔助已經是佔了絕大多數的這個我的生產要素了，然後呢就整個 AI 來講就變成了我完全不可或缺的原料了，這種時候我覺得才有效果。但這種工作畢竟太少了啊。

所以提效是你自己的事啊。所以我覺得提效是你員工自己的事情，對吧？就是原本說這個會被 AI 淘汰，可能是那些不會用 AI 的員工；但我覺得這個句話今天打個問號，我覺得今天會被淘汰那些是只會用 AI 提效的人，或只會用 AI 提效的公司。就你提效是沒有任何增長的，對吧？你不像製造業，你說製造業我確實可以通過提升良率、提升效率，從成本裡面把這個錢給摳回來，但是它不直接面向客戶。你但凡是直接面向客戶的企業，你第一要義一定是增長，不是提效。

我有一個暴論啊，我覺得對於所有讓 AI 來提效的公司來講，最好的方法就是讓員工不要再加班了。就以前來講的話，就是說大家都在加班，加班是為什麼？就是今天的任務明顯幹不完 8 個小時，8 個小時之內我還要上廁所、吃飯，然後各種各樣的東西午休，所以我只能佔據我平常其他時間，對吧，8 個小時以外的工作時間，然後免費加班來把事幹完。但如果有了 AI 之後，如果 AI 的工作是提效，那能不能就說 8 個小時的事就讓我 8 個小時幹完，然後回家我去消費去，我去看電視也好，我去逛商場也好對吧，我去那個跑步也好，無論怎麼樣都產生消費，讓整個社會變成一個消費型社會，然後呢變成了大家都愛花錢。

堅決反對！哈哈哈堅決反對，閒哥你這個是資本主義的烙印，哈哈哈，來來來，給我一社會主義鐵拳，哥哈哈哈。我是特別反對這個的，因為其實這個情況啊在歐美正在發生嘛，對不對？就是理論上我是一個個人的，比如說北歐，我單位的生產值很高，然後我所在行業又是這個隱形冠軍或者是超高毛利、超高利潤的這樣一個行業，我只要提升我自己的效率，我 work life balance，我下班了我去消費了，對不對？但是你反過來，在中國或者在大部分的東亞地區，這種叫做普遍生產型社會，它不是消費型社會，這種情況是不存在的。不存在說你效率提高了 8 小時走了，不可能的，哼，因為你要面臨的是大量的競爭、大量的內卷，然後呢你不做，千把萬人要做，對不對？所以我覺得提效本質上是你個人的事情。

所以如果我們拋開這個企業視角啊，拋開老闆視角，就是以個人來說，比如咱自己就小蘇，咱們在自己做公司，然後自己同時也是在用 AI 的人，就是你怎麼來分配自己的錢呢？你覺得在 AI 上投入多少是合理的？

比如說就我個人來講，每個月在 AI 上至少投入人民幣 2,000 塊錢。怎麼講？就是我覺得寧濫勿缺，對哈哈哈一定要新造成語啊，對哈哈哈，就是一定要先讓他有足夠的充分。因為如果這個 TOKEN 的量啊達不到，你就是用 Astra 自由，達不到你用這個 Neon 自由，最近 Gemini 的新的模型，那這個很多想象力你出不來。那一旦這個東西自由，你就會想就是我不能讓他空轉對吧，哈哈哈我什麼事情都得讓他幹，誒有可能就會出奇效，原本你沒有去做的、懶得去做的或者是沒有去打通的一些事情，他可能就通了。所以我覺得從個人來講，這個還是一筆蠻重要投資。

挑選 AI 工具：別養老黃牛，要養刺頭

因為我覺得這個跟管人可能有點像，就是我覺得你個人花多少錢在預算、花多少精力在這個 AI 上面，有點像企業管員工。那最怕就是你管到了一群老黃牛，比如說能力平平對吧，但是很積極，這個情緒價值給你給滿，你講一個事情給你阿諛奉承，然後呢吭哧吭哧幹，幹出來都是垃圾，還要你去點評、還要你去註釋，然後呢再去幹，幹了 10 輪都不滿意，但是就是很勤快，啊我覺得就最怕就是這種老黃牛，這種是最怕的。那我覺得反而要是什麼呢？就是要去找刺頭，就企業裡面大多數老闆他不會管刺頭。其實是這樣的，我舉個例子大家就明白，就是什麼叫刺頭：他不一定說懟你，他可能是比如說我不會編碼，但是我買編碼最好的模型，它的編碼能力一定比我強 1 萬倍。對，這個對我來講就是刺頭在教我做人。嗯對，他在教我編碼。我覺得應該是從這個角度，就是你不能養老黃牛，你要去養刺頭，你要把所有的錢、所有的精力放在刺頭上面，但是告別那些老黃牛。

舉個例子，我最近是退訂了 Grok bot，對吧？什麼原因啊？他太迎合你了是嗎？嗯，他就是老黃牛。對，他就如果有 Opus 的時候，我覺得這個 Grok bot 還不錯，就是能夠成群結隊地去幫我做一些事情；但是當它沒有 Opus 的時候，我覺得就是在成群結隊地幫我做一些很低效的工作。原本一個 Astra 能解決的問題，它要給我拆 5 個 BOT 去做，那這個事情就是跟企業裡面老黃牛一樣嘛。那當斷不斷對吧，後宮必受其亂，對哈哈哈對吧，一定給他斷掉。

但是我反而我們就增加了在這個 GPT、在 Gemini 上面的預算，包括最近 Gemini 就是口碑非常好、非常出圈對吧，那其實我們最近又多買了好多的 Gemini。感覺 Google 又支稜起來了？不是它又支稜起來，就是我覺得它下一輪還是會下去的，就這個公司就是這個鳥樣啊，它是一個散裝的 Google。它支稜起來是模型支稜起來，它的 Harness、它的這個其他的部分沒有支稜起來，啊所以它下一輪的這個進步、它被掉隊還是可以預見的，啊所以大家不要高興太早。對，今天得用且用，能用且用，對對對我也想這麼說。

企業 AI 預算的出路：從預算制到懸賞制

那當然你說這個情況，我覺得反倒和企業成為一個反例。就是說咱說回到 AI TOKEN 預算這個事，就是國內來講的話給出了一個方式吧，就是什麼呢？就是弄一個 TOKEN 池，弄個 TOKEN 池之後交給一個小組組長，這小組組長有可能是什麼 CTO 啊，也有可能是說負責銷售的呀，有可能負責宣傳的啊等等都有可能。然後這個 TOKEN 池的大小是大家要 PK 的，對吧？這咱們熟悉嘛，在這個零售行業什麼阿米巴什麼的對吧，大家要 PK，然後呢要承諾，然後誰拿到 TOKEN 池大，那你要承擔責任要大，那未來你要對這個東西……就是我覺得像把 TOKEN 變成廣告投入一樣的類似的方法來管理。當然了這種東西效率好不好我不知道，但起碼是個方式。

但在海外來講的話，就是什麼呢？就是因人設崗，那這個不同崗位可能對應的不同的這個額度，或者說 OK，有的人大方把這個 TOKEN 自由或者說叫 AI 自由作為福利之一對吧，來吸引一些高級人才。反正我是覺得就說這個事情本身，就是 AI 已經像一面鏡子一樣啊，把每個行業的不同和每個人對 AI 的一個接受程度和這個工作性質不同就照出來了。

然後如果說，我能夠理解你的觀點，就是說從財務角度來講，你覺得 AI 或者 TOKEN 這個東西還是應該像預算這樣來管的，就是說首先 TOKEN 這個單位它等同於錢，這個錢的分配你們各個部門要去搶，然後呢你們要去通過你要做的事情、你的 plan 去獲得這個 TOKEN 的預算，它可能是獨立錢外的一個額外的權利對吧？那我覺得從我的角度反而是，我覺得在國外成立，但是我覺得這事情在國內不成立，嚴重不成立。因為為什麼呢？因為反而我覺得在國內已經進入一個垃圾時間，就大部分老闆已經聽不進去任何這種所謂跟 AI 相關的刺激了，就是你再怎麼刺激他已經麻了。對，麻了是吧？麻了對，因為他上半年喊了半年的 all in，下半年呢對吧，下半年整個人差點都進去了還 all in，對吧哈哈哈。

那我覺得反而在國內，我是覺得應該有一小撮公司是要把 TOKEN 的這個自由這個事情給標榜出來、給拉滿的，就必須要拉滿。對啊，為什麼？因為在國內有非常多的行業、企業公司，其實它的工作流程、它的工作規範並不標準，或者它的系統是割裂的，這個有各種各樣問題，因為是中國進步太快了。對，有可能我上一秒還在用 DOS 呢，可能下一個時代這個 AI 時代已經來了。我就舉個比方、打個比方，就它是碎片化、多系統共存，然後多代際人有不同的共識，70 後、80 後、90 後、00 後每個人腦子裡的 AI 跟先進科技是不一樣的，那概念是不一樣的。所以你其實很難在中國去拉齊的。你只有一種方式，就是讓少部分人擁有 TOKEN 自由，去把你的業務流給做成 AI native，只有這種方式。對，否則你這個問題給到 IT，他解決不了，他說這個事情歸 HR 管；HR 解決不了，他說這個事情要問老闆；每個人心中的 AI 都不一樣，這個管道就堵死了。

所以最後就推到財務身上了嘛對吧？就是說最後這筆錢到底是公司報還是不報，啊公司到底準備不準備這筆預算。所以我的角度是做獎金。對，直接給個大獎。這一點上，我倒是確實部分同意這件事。首先我覺得就是說，剛才我說到一半嘛，就是說咱們都說企業，反正我覺得個人來講的話，只要你現在接受 AI，然後呢只要你覺得就是說 AI 還不能滿足你的所有需求，那就是越用最先進的 AI 越好。但這件事來講，你不能指望著公司把錢給你報銷，或者讓公司來幫你買那個 TOKEN，但是你可以有獎學金呢！

哎你對，懂我意思沒有？我覺得你的意思特別好，就是這個事變成什麼事了？就是說 OK，這個公司要不要用 AI，並不是說由老闆說了算的對吧，應該是說一線的人或者說每個環節的人他怎麼樣去用 AI，但是這種用 AI 做成了什麼，如果說真的對公司有效，就應該發獎金，而且這獎金應該很高才對，肯定應該是比你這個套餐或者什麼的話多出 5 倍、10 倍甚至百倍來講，因為它真正帶來的是什麼？是說你比如說流程的提高、提升，或者說真的能變成未來的收入的提升，或者說自己的這個競爭力的提升。

但這個事，如果你說靠預算、靠公司來說「哦我把這個 100 塊錢，或者說每個月可以花 1 萬塊錢這個 TOKEN 錢給到你，你就必須產出」，那我對你的期待潛臺詞就怎麼樣？這種事情就不能讓你們這些財務知道，就應該是老闆小金庫對吧？你像我們以前，員工表現得好，你真的預算上獎勵不了他了，「媽的你全家給我去旅遊」，誒對，就沒錯，以其他方式來做。就是現在你搞什麼亂七八糟預算啊或者什麼，我覺得就是反的，就是說你說比如說潛臺詞「我給你 1 萬塊錢預算這個 TOKEN，我就希望你能夠產生 10 萬塊錢的這個收入」，這不可能啊對吧？它就並不像說廣告說我可以去有地方去買流量，然後說去換點擊對吧，然後或者說是上央視打廣告，這種事它還不是。

然後你像這個我覺得有點像招待費，真的就有點像這個差旅費、招待費——這不是差旅費，應該叫就是餐飲招待費。就是我把這個錢給你了，那我不知道你去請誰吃飯，我也不知道你平常是誰跟誰打高爾夫球，但我相信你，錢給你，因為如果做不到你就給我滾，就這麼簡單對吧？你拿了我這個錢，你光吃飯了，然後最後簽不回單了，那你只能走啊，因為畢竟後面還有人可以做的。然後呢 AI 也一樣，就說你可以先用，然後呢至於說你覺得你的這個工資抵扣不了你這個 TOKEN 錢，那你這個說句不好聽的話，你也不見得是什麼重要崗位。

哥你看啊，我們這個事情就不是說要納入財務範疇討論，我覺得它是一個貨幣化的事情對吧？你現在就可以理解說為什麼有那麼多公司它會去做員工的賽馬，就是一個業務多個部門同時做，其實是把人力資源貨幣化嘛，就當做投資對不對？那你一樣啊，這個 TOKEN 這個事情也是這樣子的：今年劉步閒同學這個今年年會表現得非常好，給老闆賺了多少錢，上臺給你頒個 TOKEN 自由大獎，對不對？對沒錯，這種我覺得獎金性質的、就說以這種懸賞性質的，反倒比這種預算性質的要效果好很多。我管你去幹嘛，你可能拿去你家裡下 A 片我也不管，對不對哈哈哈，是吧我管你幹嘛？反正我就這麼多 TOKEN 的預算，大獎獎給你了，你來公司用、拿回去用都可以。
