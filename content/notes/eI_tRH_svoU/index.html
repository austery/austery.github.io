甲骨文绑定OpenAI

[Speaker 1]: 好，那咱们在讲解关于费半的统计和一些新的情况之前，我想先讲一只大家问得比较多的个股，就是甲骨文。关于这只个股，其实有很多朋友都在问，问什么呢？就是说它走成了这个样子，它到底还有没有底？那么有没有底，说实话，咱们说了不算，谁说了算呢？OpenAI 说了算。我今天就把一些基本情况还是给大家看一下。因为这只股票问的朋友太多了，感觉似乎很多人还不知道它在发生什么，或者不知道它什么状况。

简单介绍一下，就是甲骨文现在之所以走成这个样子，是由于他已经深度绑定了 OpenAI 的合同。OpenAI 是它最大的单一客户。现在甲骨文大部分的借债都是为了履行和 OpenAI 的合同去借的。因为先给他签了个合同，告诉他：“哎，我会给你付钱，然后我会需要你的数据中心，然后你拿着我的合同借钱去吧。”他就借了很多钱。结果甲骨文的资产负债表就非常糟糕，而且他的债务在信用违约互换的价格非常高，相当于就是持有他债券的人付出的保险费用是极高的。代表什么呢？代表这个债务的风险极高。

所以 OpenAI 如果有好消息，他能够证明有持续付账给甲骨文的能力，那么它就能够刺激甲骨文利好。反之 OpenAI 如果越来越差，逐渐落后，上市也受阻，那么甲骨文就没什么希望。所以你是不是还持有这只股票、准备持有多久，取决于你认为 OpenAI 能不能在 AI 竞争如此激烈的市场里占优，能不能够把账单付给甲骨文。

那么现在 OpenAI 是一个什么样的情况呢？他们的合同到底需要付多少钱呢？我还是给大家看一个数据，OpenAI 与甲骨文的合同，现在的情况总价值差不多是三千亿美元左右，期限是五年左右。从2027年就是明年开始履行，然后去开始收钱。所以你要算一下的话，3000亿除以5年，平均每一年 OpenAI 就要付给甲骨文六百亿美元的营收。

那这个账就比较好算了。就是那 OpenAI 这边能不能够赚到六百亿一年呢？好，我们看一下 OpenAI 的现状。之前是预计2026年可能上市，包括提交了一些潜在的上市文件。但是后面市场又不是那么好，包括半导体也在回撤，加上 SpaceX 上市之后价格还破发了，所以整个综合起来来看，今年上市的可能性已经大幅降低。现在市场预期 OpenAI 可能会转向2027年才上市。它的核心诉求是一万亿美元的估值，但是现在市场只能给到大概八千九百多亿九千亿左右，实际上里外里还差了一千亿。

好，那它的营收是多少钱呢？营收从2024年的差不多37亿，到2025年大幅增长到130亿，再到当前2026年的250亿到300亿的预期，以及2027年就是明年440亿到620亿的预期。这是 OpenAI 现在市场的一个预期情况。也就是说到2027年满打满算，它的利润率100%，那么 OpenAI 就有钱付给甲骨文六百亿。当然我们这里是一个简单平均，它有可能第一年不付那么多，但是2028年增长更快，再付更多；2029年可能又翻了好几倍，付给甲骨文没有问题。所以它这个地方是一个动态变化的，它不是一个确定值。

所以你成不成功，甲骨文能不能顺利地度过这一关，就看 OpenAI。它在整个的目前的 AI 生态的竞争中，到底能不能够实现这种高增长、高营收。他能赚到钱，那自然有钱付给甲骨文；赚不到钱，那就很难讲了，那甲骨文就算被他坑了。所以这是一个很长期的战略情况，他会一直跟随着甲骨文、OpenAI 未来几年。

那么这种情况，你要去问现在他怎么办，他会不会有什么起色，你没有任何可看的东西。因为现在说实话，技术面走成这样，一直跌到了一百二十几块，那都是一些很古老的支撑了，上方全部是套牢盘。你从127往上，几乎全是套牢盘。你说它没有什么特别大的利好消息，它靠什么走呢？它很难嘛。

所以甲骨文这只股票，大家如果问我更多的东西，我其实没有什么太多的东西能够提供给大家，只能够把这个技术面的信息给大家看一看。但是在基本面风险如此之高的情况下，机构也吃不准。那大家都吃不准的情况下，实际上它的可预见性或者叫确定性，那基本上无从谈起。所以大家问我，有时候甲骨文我没有讲或者很长时间才讲一次，就是这个原因。那么今天我把这个甲骨文给大家一次性讲清楚，至于你自己是去还是留，那是大家自己要考虑的事情，你要去跟踪更多的 OpenAI 和甲骨文之间的一些消息。

费半回撤与盈利预期

[Speaker 1]: 好，接下来我想讲一讲关于费城半导体这个位置。大家从之前我们——因为我一直在休假，实际上上次跌到20%的时候，我没给大家做过统计。所以今天，因为才过了两天嘛，我准备和大家还是把这个统计要讲一下。就是从高点的费半的655跌到最低点的498。那么这个跌幅实际上是已经达到了百分之二十之多。

那么费城半导体从高点回撤20%，历史上有没有过呢？有过几次，那么之后会发生什么？后面的回报率到底是正是负呢？我还是以数据和图表来给大家讲解。

这张图表是统计了费城半导体指数在过去的十五年时间，从2011年到现在的2026年时间。费半股价下跌超过20%的情况一共出现了15次，其中有5次的跌幅超过30%，最严重的一次跌幅达到了44%。那么跌幅达到20%之后会发生什么呢？

这张表格是 GPM 的统计，他们的数据统计与结果分成了几天。我们看长期一点的，像20天、60天，下方那个地方黄色的字，大家可能看不清，我跟大家讲一下：20天的后面平均收益大概是8%，就是把历史上这15次全部统计起来，加总统计是8%的正收益；60天之后的平均收益是正11%。这是整个的目前的在费半下跌达到或超过20%之后的20天和60天的平均回报。这是历史统计。

还有一个新的关于费城半导体的基本面的新情况，我觉得有必要拿出来给大家看一眼。这张图表讲的是半导体的盈利预期，大家可以看到画圈圈的位置，那有一个高点已经从高点回落，什么意思呢？就是半导体现在行业的盈利预期已经从极高水平开始往下拐弯。

如果费半的盈利预期不是持续上调了，那大家知道会意味着什么。就跟我们说标普一样，标普之所以每年能够涨，是因为它的盈利 EPS 的总和的盈利预期一直在往上走。那同样作为费半来讲，你盈利预期一直往上调，那你当然其中的成分股股价一直往上走，这很合理。反之如果往下调，那就是另外一个故事，就代表它见顶了。但是现在由于下调的时间比较短，所以不能判断它到底是不是已经出现了 [AI_META_START] title: "美股半导体大反弹与科技股背离，甲骨文绑定OpenAI债务风险及CTA卖点更新" summary: "美股半导体大幅反弹，但标普500指数价格与广度背离达53次超历史纪录。甲骨文因深度绑定OpenAI面临高债务风险。历史数据显示费半回撤20%后60天平均收益达11%，但盈利预期出现见顶信号，标普CTA策略首个卖点调整至7440附近。"
