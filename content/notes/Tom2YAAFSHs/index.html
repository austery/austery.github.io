极简批判性思考：摆脱抬杠，掌握理性思辨 一席YiXi 2025-06-07

领域: society-thinking

分类: philosophy-wisdom

主讲人: 一席YiXi

来源: 查看

发布时间: 2025-06-07

摘要:

演讲者苏德超介绍批判性思考，将其与‘杠精’行为区分，强调理性思考的‘三板斧’（问题、立场、支持）框架。他详细阐述了五种常见的逻辑谬误（不相干、自相矛盾、逻辑缺环、不客观、价值分歧），并介绍了普遍性检测方法，最终指出批判性思考的关键在于追求真理而非胜利，以及保持开放心态。

大家好，我叫苏德超，来自武汉大学，是一位哲学老师。今天我想跟大家分享的话题是“极简批判性思考入门”。这是一个比较抽象的话题。我们今天已经进入到一个全新的时代，但我们面临一个新的挑战：我们被观点包围，观点太多了。打开我们的书，打开我们的手机，到处都是观点，铺天盖地。在海量的信息面前，我们怎么样找到那个最有效的观点，那个最不太可能出错的观点，用它来指导我们的生活？这变成一个巨大的挑战。

面对这个挑战，我们的先辈其实也给我们准备了一个很好的办法，那就是批判性思考。说到批判性思考，我们有一个常见的误解：认为批判性思考就是“恶狠狠地思考”，批评别人思考；认为批判性思考就是不同意见者在抬杠。我们来看看怎么抬杠。 “咱们食堂的菜不好吃。” “你嫌不好吃你可以不吃呀。” “隔壁食堂的菜也不好吃呀。” “给我们做菜的那个师傅他很辛苦的，他一家还有七八口都靠他养活。” “就你说食堂的菜不好吃，你成天把精力放在食堂的菜上面去，怪不得你成绩那么好。” 在我的大学还有一个更加常见的回答：“他说，你嫌我们食堂的菜不好吃？北京大学食堂的菜很好吃，你倒是去呀。” 你看，这里其实没有思考，只有抬杠。 要成为优质杠精，我可以在一分钟之内教会大家，只需要三步：

  • 切分要点
  • 重点滑转
  • 旁生枝节（口误） 比如，你上课打瞌睡。老师说：“你上课怎么打瞌睡？” 你可以回答：“老师，上课当然只能我打瞌睡，你要打瞌睡课就没办法上了。” 老师：“你上课怎么打瞌睡？” 你：“老师，我下课也打瞌睡。” 老师：“你上课怎么打瞌睡啊？” 你：“我是这样打的。” 老师：“你上课怎么打瞌睡？” 你：“老师，我上课不能打人，我要打人会被开除的。” 你看，这就是优质杠精三步：切分要点（老师、上课、打瞌睡），重点滑转（老师说你，你就说他），旁生枝节（你说怎么打瞌睡，我就说我不能打人）。 同学们学会了吧？切分要点、重点滑转、旁生枝节，成功！欧耶！

但是，批判性思考真的不是杠精，真的不是抬杠。根据**恩尼斯（Ennis）**1985年的一个经典定义，批判性思考是一个理性的思考过程，通过这个过程，我们决定要相信什么，又决定要做什么。它是一个给出立场，并且给自己的立场提供支持的过程。批判性思考是比较复杂的，我见到最厚的一本书关于批判性思考的书，有足足600多页，我都没有看完过。但没关系，今天我们可以利用二三十分钟，给大家讲批判性思考的精华。

我把批判性思考总结成“三五一”。 “三”是什么？就是我们在作批判性思考的时候，应该挥动我们**“三板斧”**：

  1. 我们到底在讨论什么问题？（问题）
  2. 在这个问题上我们的立场是什么？（立场）
  3. 关于我们的立场，我们又提供了什么样的支持？（支持） 看起来很简单，用起来也很简单。 比如：“男人就该好好做家务，做饭、拖地、辅导孩子做功课。男人不好好做家务，还是男人吗？” 好，挥动三板斧：
  • 问题：男人应不应该好好做家务？
  • 立场：应该。
  • 支持：不好好做家务的男人他就不是男人。 你看，我们挥动三板斧，马上就知道刚才的道理讲得好还是不好了。为立场提供支持，它可以让我们的思考变得更加有质量。

在清朝有一个大学问家，是一个儒生，他叫杨光先。他相信大地是平的，反对汤若望（Johannes Schreck）。汤若望是从西方来的，他说地球是圆的，是一个圆球浮在空中。杨光先反对。根据我们的常识，杨光先肯定错了。但是各位同学，各位朋友，我们来看一看，杨光先是怎么支持他的立场的。 他说：“假如地球是圆的，是浮在一个空中的球，那么我们在这个球的上面，脚在下面，头在上面。那么在这个球下面的人，他们就很怪了，他们是脚在上面，头在下面。这就奇了怪了，他咋不掉到空中去呢？” 有没有道理？很有道理啊！同学们大家笑，是因为我们通过物理老师、地理老师知道地球它真的是浮在空中的一个圆球。但是我们扪心自问，我们能够为我们的立场提供支持吗？你能够反对杨光先为他的立场提供的支持吗？“地球下面的人怎么没有掉到空中去？怎么没有掉下去呢？”你能够回应吗？很难吧。 在这个时候，应该被嘲笑的不是杨光先，而是我们。我们只不过是相信了教材的话，但我们却不一定能够为教材的话给出足够的支持。要回答杨光先这个质疑需要牛顿（Isaac Newton），而牛顿在他50多年之后才出现，也就是牛顿比他年轻大约50岁。我们现在有了牛顿，我们就知道地球下面的人他怎么没有掉到空中去，是因为地球它有万有引力（Universal Gravitation），它就像磁铁一样，地球也把我们吸附在它表面，所以地球对面的人并不会掉下去。 只要我们给我们的立场提供足够的支持，哪怕立场错了，也可以启发出后代更加伟大的科学家、更加伟大的思想家。

说到牛顿，我就想到了牛顿那只苹果。苹果砸在牛顿头上，牛顿才想到了万有引力。故事就是这么讲的。 那我们问一问，按照三板斧，我们问一问：

  • 问题：苹果它为什么会落地？
  • 立场：因为地球对它有吸引力。 那接着问：
  • 问题：地球为什么对它有吸引力？ 这个时候，恭喜你，你召唤出了牛顿的亡魂。他说：“这是我知道的，因为任意两个质量体之间都有万有引力。” 好，你接着问：
  • 问题：那牛顿，请你告诉我，为什么任意两个质量体之间都有万有引力呢？ 恭喜你，你把爱因斯坦（Albert Einstein）从棺材里叫醒了。爱因斯坦说，是因为质量让时空弯曲（Spacetime Curvature）。也就是说，引力并不是一种真实的力，它其实只是时空的一种几何性质。 那我们接着再问：
  • 问题：爱因斯坦，你说质量让时空弯曲，那质量为什么让时空弯曲？ 恭喜你，人类到目前为止没有回答。 这是著名的科普作家袁岚峰举的一个例子，非常好。 你看，各位，只要我们坚持追问三板斧：什么问题？什么立场？什么支持？只要为立场提供支持的链条足够长，我们就可以成功地抵达人类知识的边界。从此我们迈出的一小步，都是人类的一大步。这就是批判性思考带给我们的成就。

要是我们只有立场，不给支持呢？那会怎么样？那就是吵架。 我们来看一个比较经典的吵架的片段。中年夫妻看到这个，就会发出会心的一笑。简单分析一下： 男的说：“你嘴巴给我放干净一点。”（立场：你的嘴巴已经不干净了，我希望你放干净一点。） 女的回应：“我的嘴怎么就不干净了呀？”（试图讲道理） 但她突然意识到，我是要吵架，我要跟我老公吵架，我干吗要跟他讲道理？所以她马上接：“我今天就是骂你了！” 针锋相对，果然是中年夫妻：“你现在怎么像个泼妇一样？” 女：“我当然是个泼妇呀！” 针锋相对。 吵架的要点就是只给立场，不要给出支持。你给出支持你就输了。你在我们吵架的时候你居然讲道理，你好意思吗？吵架的制胜法宝就是让自己气势如虹，让对方痛不欲生。你赢了，恭喜你。 其实吵架的双方，夫妻再吵，能够吵架是一件好事。为什么呀？你们至少还在沟通观点。虽然你们的沟通显得很激烈，你们知道你们相互的立场是什么。

生活中还有一类人，他喜欢当老六。他什么观点他不告诉你，但你什么观点，他老给你找茬，老找你的错。在旁观者看来，他还赢了，你还输了。但对于这一类老六来说，不给出自己观点的老六来说，他们其实根本没有思考，因为他们连立场也没有，更谈不上给自己的立场提供支持。 要讲道理，我们必须提出问题，表明立场，提供支持。

不过，在讲道理的时候，也有一些常见的错误，我们也需要去防范。这些错误包括五类：

  1. 不相干 (Irrelevant) 牛头对上了马嘴。生活中90%以上的错误都是这样的。 我们来看一个：“我花三个小时来到这里，主讲人讲得再差，我也要把它听完，不然就白来了。”这样想的时候，总是觉得有点不对劲。你要不要继续听下去，并不取决于你为了到达这里你付出了什么，那只是你的沉没成本（Sunk Cost）。你要不要听下去，仅仅取决于主持人所讲的，是不是你需要的。不相干。 再来：“咱们食堂的菜不好吃。”“北大食堂倒是好吃，你怎么不去？”不相干呀。我没有上北大，这并不意味着我没有资格评论我们食堂的饭菜好不好吃。不相干。

  2. 自相矛盾 / 不一贯 (Contradiction / Inconsistent) 西方是基督教社会，他们相信上帝。他们的上帝是全能的。这个时候就有一个人，比如说我，我就给上帝提了个要求：“上帝，你不是全能吗？你能不能向我证明一下你的全能？” 上帝说：“嗯，可以，小伙子。” 好，我就提要求了：“我说，上帝，你能不能创造一块你自己也搬不起来的石头？” 初一听，上帝是不是就会傻眼呢？他说：“我要是给那个中年人创造一块石头，但我搬不起来，我不全能。我要是干脆不创造出来，我也不全能。”总而言之，我就不全能了。是不是我通过这个要求就已经击败了上帝的全能呢？ 不是的。我刚才提了个要求：上帝要创造一块他自己也搬不起来的石头。很复杂，我们把它分解一下。其实他提了这么几个要求：

    • 第一个要求是：你为了向我证明你全能，你必须创造一块石头。这个要求是合理的，上帝可以满足。
    • 好的，接下来，第二个要求：上帝，你为了向我证明你的全能，你必须搬不起这块石头。这个要求就有点怪。你要求上帝向你证明他的能力，但你却要上帝展现他的不能？你自相矛盾了吧？
    • 上帝假装没听见，他说：“好吧，你让我搬不起，我就搬不起。”他就搬不起了。
    • 在上帝搬不起的时候，我接着说：“上帝，你居然搬不起这块石头，你果然不全能。” 当我这样说的时候，我就跟上帝提出了第三个要求：要求上帝搬得起这块石头。 大家看一看，第二个要求和第三个要求，是不是自相矛盾了呀？所以我们用上帝能不能够创造一块他自己也搬不起来的石头，去反对上帝全能的时候，真正自相矛盾的不是上帝，而是提出要求的这个人。

  3. 逻辑缺环 / 不闭环 (Logical Gap / Incomplete Loop) 我们缺条件。举个例子：“她是你妈，她不会害你的，按照她说的做。” 这个话好像还比较熟，但它错在哪里了？它错在我妈是不是害我的，并不取决于她主观愿望是不是为我好，而取决于她事实上是不是为我好。所以它的逻辑缺环是：“我妈事实上是为我好。”只有当我妈事实上是为我好的时候，我才应该按照她的做。如果她事实上没为我好，她就算有个良好的愿望，我也不能按照她的做，她会好心办坏事。逻辑缺环。 再看一个例子：“最近总有人造你的谣，你得注意一下，你得好好想一想。” 这不是指责受害者吗？别人造我的谣，是别人的错误，不是我的错误。你让我好好想想干什么呀？除非你有一个前提是说：“凡是被造谣者，都是被造谣者自己出了问题。”但这不一定是对的。这逻辑缺环。

  4. 不客观 / 不符合事实 (Not Objective / Not Factual) 来看下面这个问题：“第一个造出钟或者类似计时器的人，他怎么知道当时是几点钟呢？要是当时是5点，他却把钟拨成了4点，那我们人类岂不一直错到了现在吗？”对不对？这真的是个问题。 怎么回答？提这个问题的人犯了一个事实错误。因为在第一座钟，或者第一个计时器发明出来之前，我们并没有“几点钟”的概念。是先有钟，先有计时器，然后才有“几点钟”，而不是先有“几点钟”，然后才有计时器。我们犯了一个不符合事实的不客观的错误。 我们生活中，我们也容易以我们的揣测、好恶、我们的愿望来代替事实，来犯下这个错误。 再举个例子：“因为我是新转学来的，没有熟人，不能拉票，所以在这次学生会的竞选中失败了，我极为愤怒。” 大家想一想，在刚才这段话中，哪些是事实？哪些是我们的观点或者揣测呢？如果说这句话的人他是诚实的，那么事实是：他是新转学过来的，他没有熟人，他在这次学生会竞选中失败了，以及他非常愤怒。 这样讲他都在讲事实。不对。在这里面还有一个观点，那就是“因为”和“所以”。“因为他是新转学过来的，没有熟人，所以他失败了。”这个“因为所以”是他的推断。当他把生气建立在这个“因为所以”的推断关系上的时候，各位要注意，他很可能只是把他的生气建立在他的臆想、他的观点的基础之上，而没有建立在事实的基础之上。如果是这样的话，他不过是在自寻烦恼。在生活中，我们经常自寻烦烦。

  5. 不喜欢 / 价值和偏好的分歧 (Dislike / Value and Preference Disagreement) 鲁迅这样写道：“楼下的一个男人，病得要死，那间壁的一家唱着留声机，对面是弄孩子，楼上有两个人在狂笑，还有打牌的声音。河中的船上，有女人在哭着她死去的母亲。人类的悲欢并不相通，而我只是觉得他们吵闹。” 我在第一次读到这段文字的时候，我当时还在念初中，读到这段文字，让多愁善感的我感觉到天都塌下来了。人类怎么能这样呢？都病得要死了，你为什么还要打牌？你为什么还要唱留声机？你为什么还让你的孩子哭？ 但是随着我慢慢地从少年成长为青年，从青年慢慢地蜕变为中年，我就意识到这个世界是复杂的。每个人都有自己生活的轨迹，每个人都有自己生活的问题。人间的悲欢并不相通。也许鲁迅只是想告诉我们这个事实，他并不一定想谴责这一点。这个事实也许很坚硬，也许很难让我们接受，但它真的是事实。所以鲁迅最后才说：“而我只是觉得他们吵闹。” 有时候我们相互不喜欢没什么问题。你不喜欢我，我不喜欢你，这就是个事实，没有对错。但要是你因为不喜欢我而认为我错了，我不喜欢你而认为你错了，那我们就犯下了错误。不喜欢并不直接带来错误。 在工业社会以后，跟农业社会、采集社会和狩猎社会不同，工业社会是个陌生人社会。在陌生人社会里，我们有不同的爱好，我们有不同的工作。在陌生人社会里面，我们有不同的爱好，我们真的很难相互喜欢。没关系，我们只要不伤害就够了。所以你不喜欢别人，并不意味着别人错了。

上面就是五类错误。在这五类错误里面，有形式错误（不一贯、不闭环），也有非形式错误（不相干、不客观、价值分歧）。形式错误，学学逻辑，我们就可以很容易地识别出来；而非形式错误，需要更多的生活的阅历。

要是你还是觉得麻烦，没关系，咱们还有最后一招，那就是普遍性检测。 普遍性检测的道理是，一个道理它是道理，它并不取决于：

  1. 是谁说的？
  2. 也不取决于在什么地方说的？ 也就是说，如果它真的有道理，我们可以把说这话的人删掉，把说这句话的环境删掉，看它还是不是对的。 来看一看，著名的哲学家苏格拉底（Socrates）说：“没有人有意干坏事。”你隐隐约约觉得有点不对劲，但你不好意思反对。那我们就把苏格拉底删掉。“没有人有意干坏事。”你是不是就有反对的勇气了呀？ 再接下来，我们换一个说话人试一试。欠你钱十年不还的隔壁老王说：“没有人有意干坏事。”你看，已经有观众朋友笑起来了。隔壁老王，你就是在瞎扯。你也知道欠钱不还是坏的，但你就是不还，你就是有意干坏事的那个人。所以你说错了。 你看，通过普遍性检测，我们就知道，“没有人有意干坏事”这个道理并没有那么有道理。

我们再来换一个例子试一试。 “2+2=4”呢？著名哲学家苏格拉底说：“2+2=4。”你想反对吗？ 把苏格拉底删掉：“2+2=4。”你想反对吗？ 好，再把你最讨厌的那个隔壁老王拉进来。欠你钱十年不还的隔壁老王说：“2+2=4呀。”你说：“老王老王，我给你点赞。你欠我200万，又欠我200万，你现在欠我400万，你知道吧，你知道该还了吧。” “2+2=4”它真的是道理，它跟是谁说的，在什么时间什么地方说的一点关系没有。这就是普遍性检测。

通过“三五一”，我们可以防范绝大多数错误。但是知难行易，批判性思考离我们的本能太远了，我们需要长期训练才能好好地掌握它。 在数字时代，我们被观点重重包围。打开我们的手机，打开我们的电脑，打开电视，甚至你逛街看见广告牌，到处都是观点。在观点的包围下，我们应该怎么办？我们应该检查这些观点，我们应该检查别人的立场，我们应该像检查别人的立场一样，来检查我们自己的立场。 注意，批判性思考重要的是思考，它不是批评别人，也不是批评自己。我们只是渴望得到一个正确的答案。如果像捍卫自己的钱包一样，捍卫自己的观点，捍卫自己的立场，那苏老师就会告诉大家，我们这样做就太危险了，就太错误了。 为什么很危险？是因为我们的立场并不就是我们自己，甚至我们的立场、我们的观点根本不从我们而来。什么是别人的观点？什么是你自己的观点？你能够区别出来吗？我可以告诉大家，我们区别不出来。你说有一个观点是我的，那怎么就是你的了？你说是我嘴巴说出来的，你嘴巴怎么就说出它了？你说是我脑袋想出来的，你的脑袋又是怎么想到它的？大家好好想一想，一个观点出现在你的大脑里，是不是就突然出现了？你说，“哦，明白了，啊哈！”这个叫啊哈 moment（Aha moment），叫顿悟时刻。在顿悟之前，你是不知道它的。它突然出现在你的大脑里，你都不知道它怎么出现的。然后你抓住了它，它也就抓住了你。然后它接下来就通过你控制你的嘴，让你把它说出来了。当你把它说出来的时候，你就把它当成是你的观点，当成是你的立场。其实只是那个观点碰巧经过你的大脑，然后你们相互抓住，它控制你的脑神经、控制你的嘴巴，你把它说出来，仅此而已。别人的观点也是一样的。 按照我们批判性思考所说的，为我们的观点提供支持，为我们的立场提供支持，最好的支持是什么？是像科学一样去支持。让我们对观点的支持，符合逻辑，符合直觉，符合事实。所以重要的不是谁的立场，而是正确的立场。 苏格拉底在《斐多篇》中就曾经这样教育，就曾经这样告诫他的学生：“孩子们，孩子们，朋友们，友伴们，重要的不是胜利，而是正确。”这个观点从你的嘴里出来，还是从我的嘴里出来，不重要。重要的是它是一个正确的观点。 一个立场只有获得足够的支持，它才可能正确。这就是我们批判性思考的要义。 面对问题，我们要敢于表明自己的立场，不要去当老六，不要总是给别人找茬。我有立场，要敢于为自己的立场提供支持，要敢于让自己为自己的立场提供的支持不但让自己接受，也让别人接受。也就是说，当我思考的时候，就在代表整个人类在思考，因为我思考的过程是你也接受的。当爱因斯坦思考的时候，整个人类也在思考；当牛顿思考的时候，整个人类也在思考。思考具有公共性。 要是我们做不到呢？没关系，那我们就欢迎批评，做到open minded（心智开放）。这就是批判性思考的要义。
