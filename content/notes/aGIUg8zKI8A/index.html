前沿模型当日上线与评测机制

那么，我们如何践行这些原则呢？我们的一项原则是：如果一个全新的前沿模型公开发布，我们希望当天就能将其应用到生产流程中。因为如果它确有价值，其中蕴含的价值是巨大的。但它到底有没有价值呢？我们需要能够在黄金数据集（golden sets）上对其进行基准测试。

英文原文 Right. So how do we move on these principles? Uh, one principle that we have is that, you know, if a new frontier model is made available publicly, uh, we want to be able to leverage it in production flows the same day because there's immense value in that if it is valuable. But is it valuable, right? We want to be able to benchmark it on golden sets.

这意味着我们需要有一套成熟的评测框架。我们与核心的客户交易团队合作，收集他们的基准测试集。我们将这些数据集接入进来，每当有新模型发布，我们就在这些新基准上运行该模型，立即获得指标，并能与公司内部的同事分享，看看：“嘿，这对于我们的使用场景真的有价值吗？”

英文原文 So that means that we need to have a mature evaluation framework. Um, and then we partner with key customer trading teams where we collect their benchmarks. 此外，每当出现不同的模型，通常意味着我们需要在网关中提供该模型，准备好合适的 API 和接口，正确配置成本管理等等。很多时候，新模型意味着测试套件（harnesses）需要更新等，我们也会负责相关的更新和交付管理。
