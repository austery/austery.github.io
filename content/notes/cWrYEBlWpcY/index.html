摘要

我们这里的目标是构建一个 Agent，帮助为任意给定模型找到最佳的 VLM 服务配置。

英文原文 So, what the goal is here is to build an agent that helps find the best VLM serving config for any given model.

英文原文 The purpose is to reduce the time it takes to manually find the best configs and the VLM serving recipe and if we can automate this and have it run in the background and have the agent find the recipes and the optimized parameters faster then it will save a lot of time. 该 Agent 采用的策略称为贝叶斯优化（Bayesian optimization）。贝叶斯优化是一种用于在任意给定场景中寻找最优数值的技术。在我们这个场景中，就是寻找这些 VLM 配方中的最优数值。

英文原文 So, the strategy that the agent uses is called Bayesian optimization and Bayesian optimization is a technique that's used to find the most optimal numbers in any given situation. So, in our situation it's to find the optimal numbers in these VLM recipe.

它通过数学步骤从本质上缩小搜索空间。通过缩小搜索空间，大幅减少了在运行过程中寻找该配方优化数值所需的时间。贝叶斯优化（BO）是所采用的策略，而 Optuna 则是在搜索循环中运用该策略的工具。Optuna 使用贝叶斯优化：它接收当前配方，即初始配方，贝叶斯优化在此基础上运行，经过多次迭代或多次试验（trials），最终找到优化后的配方。Optuna 基本上在每次试验后获取每个配方，对其进行评估，获得一个分数，运用策略来修改和改进配方，然后在搜索循环中重新运行，直到试验完成。

英文原文 It uses mathematical steps that essentially minimizes the search space. So, by minimizing the search space it reduces a lot of the time that it takes in finding the optimized numbers in this recipe during the run. So, BO Bayesian optimization is a strategy that is used but Optuna is the tool that uses a strategy in the search loop. So, Optuna uses Bayesian optimization. It feeds it the current recipe, the starting recipe. Bayesian optimization runs on that and over many iterations or many trials it eventually finds the optimized recipe and Optuna basically takes each recipe after every trial, assesses it, gets a score, uses a strategy to change the recipe, improve and then it reruns it within the uh search loop um until the trials is done.
