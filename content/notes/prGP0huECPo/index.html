摘要

Artificial Analysis 联合创始人 George Cameron 探讨了 AI 智能成本的演进与权衡。随着 Agent 任务走向复杂化，任务成本跨度达数个数量级。分析指出 Prompt 缓存命中率、输入 Token 数与任务轮数已成为决定 Agent 运行成本的关键驱动因素，并提出按需求区分有限与无限智能任务以优化模型选择。
