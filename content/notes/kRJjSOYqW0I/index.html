英文原文 So, so what is harbor? At a high level, Harbor is a framework that allows you to define realistic tasks in the form of natural language instructions to an agent. These are tasks that you would like your agent to be able to accomplish.

Harbor 会把这些任务提供给运行在全新沙箱环境中的智能体，沙箱中配备了与该任务相关的真实数据。

英文原文 Harbor feeds those tasks to your agent running in a fresh sandboxed environment with real data relevant to the given task.

然后，它允许你定义所谓的验证器（verifiers）。这些验证器针对具体每个任务，它们的作用就是检查智能体是否在环境内部产生了预期的副作用。
