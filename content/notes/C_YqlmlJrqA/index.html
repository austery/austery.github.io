OpenAI发布Atlas浏览器：中美科技巨头AI入口之争与生态战略

关键字 china code llm strategy tech

摘要

AI时代的浏览器之战与入口争夺

回溯至2000年，那是一个浏览器大战的时代。如今，OpenAI发布了Atlas浏览器，这似乎预示着在AI Agent时代，浏览器再次成为科技巨头争夺的焦点。尽管Atlas产品本身并未带来太多惊艳，但其背后抢占AI入口的野心显而易见。这不禁让人思考，或许硅谷的公司可以借鉴中国大厂在抢占入口方面的经验。例如，阿里巴巴旗下的夸克PC端在一年内实现了DAU（日活跃用户: Daily Active Users的缩写，衡量产品每天独立用户数量的指标）10倍的增长，这在中国市场是独有的现象。

目前，最先发力的OpenAI和势头最猛的字节跳动，在AI生态竞争中似乎处于第三梯队，距离降级仅一步之遥。未来两三年内，是否会出现一个像微信一样的超级AI应用，成为所有AI场景的入口，是一个值得探讨的问题。

OpenAI的激进策略与Atlas浏览器

最近OpenAI的产品发布频率之高令人咋舌。继Sora之后，Altman又推出了Atlas浏览器。这款产品虽然价值有限，但其战略目的非常明确：抢占用户上下文。Atlas的Browser memory（浏览器记忆: 指浏览器记录用户浏览历史、搜索偏好等信息的功能）功能默认开启，旨在通过分析用户的浏览和搜索记录，推测其行为和兴趣，提供个性化服务。这种激进的做法，通过直接查看用户的Browser history（浏览器历史: 用户在浏览器中的访问记录），与其他产品形成了鲜明对比。

然而，Atlas的发布也暴露了OpenAI的一个短板。目前它仅支持Mac OS（macOS: 苹果公司为其Macintosh系列电脑开发的专属操作系统）版本，这表明其完成度可能较为仓促。Mac OS在整个PC端的市场份额仅占5%到10%，这进一步印证了产品发布的紧迫性。据了解，Atlas由一位在谷歌Chrome工作20年、此前还参与过Firefox开发的资深工程师主导，他于2024年加入OpenAI。尽管有顶级人才，但产品资源似乎仍显不足，导致其初期版本较为粗糙，但其“先上菜，再加功能”的野心清晰可见。

当前，AI巨头们在2025年重演20年前的浏览器大战，这本身就令人称奇。甚至有消息称，Perplexity和OpenAI为了争夺默认浏览器设置，分别向用户提供20美元补贴和7天Plus会员，这引发了大量“薅羊毛”行为。

浏览器在AI时代的定位与未来

在AI Agent时代，浏览器是否仍然是必需品？有人认为，浏览器已经从最初的“互联网之门”演变为一个“房间”，承载着用户的账号、收藏和大量个人数据。现在，AI Agent的介入，如同在用户的房间里支起一张床，24小时不间断地提供帮助，这在带来便利的同时，也可能引发隐私和被监控的担忧。

OpenAI的急切可能源于增长瓶颈，其频繁发布产品，如Sora、Atlas和未来的Agent模式，可以被视为一种“撒胡椒面”式的投资逻辑，通过内部孵化多个项目来探索增长点。然而，这种急迫与谷歌的淡定形成了鲜明对比。谷歌的Gemini in Chrome产品至今仍处于灰度测试状态，只有少数用户能够使用。

谷歌的淡定可能源于其对底层技术的掌控。所有新的浏览器几乎都基于Chromium内核（Chromium内核: Google Chrome浏览器所使用的开源网页浏览器引擎，许多其他浏览器也基于此开发）。谷歌认为，无论上层应用如何变化，底层核心竞争力仍在自己手中。此外，谷歌在组织整合和盈利模式上也有自己的考量。它更关注产品是否能赚钱，以及是否会影响现有业务的盈利。谷歌拥有从模型到算力、应用到生态的完整布局，因此可以从容应对。

然而，浏览器在AI时代是否仍是入口，值得商榷。随着AI生成文字（AI-generated text: 指由人工智能模型自动生成的文本内容）的数量已经超越人类历史上的总和，以及视频生成技术的快速发展，人们获取信息的方式正在从主动阅读转向AI辅助搜索和答案驱动。未来，用户可能只需通过语音助手或脑机接口（Brain-Computer Interface, BCI: 一种允许大脑与外部设备直接通信的技术）直接获取答案，而无需打开浏览器。

虽然目前浏览器仍是ToC（To Consumer: 面向普通消费者用户的市场或商业模式）用户的重要入口，因为其承载了大量的用户习惯、身份认证和收藏夹，替代成本巨大。但随着AI Agent（AI代理: 一种能够自主感知环境、进行决策并执行行动以达成特定目标的智能系统）的发展，这种情况很可能改变。谷歌在Computer Use（计算机使用: 指AI系统通过模拟人类操作来控制和使用计算机界面的技术）、Chrome MCP（Chrome Machine Control Protocol: 一种允许AI系统以编程方式控制Chrome浏览器，实现自动化操作的协议或技术）以及Gemini CLI（Gemini Command Line Interface: Google Gemini模型的一个命令行接口，允许用户通过文本命令与AI进行交互和控制电脑）等方面的布局，预示着AI时代可能“干掉UI（用户界面: User Interface的缩写，指用户与软件或硬件交互的操作界面）”，许多网页可能只剩下代码，交互将由Agent与数据库和代码完成。

因此，AI时代的浏览器可能不再是给人使用的，其份额将被AI工作、Chatbot（聊天机器人: 一种通过文本或语音模拟人类对话的计算机程序）和系统端应用所消融。OpenAI和谷歌重回AI浏览器赛道，某种程度上像是“马拉火车”，其必要性存疑。

中美科技巨头的AI入口战略：抄作业与基因决定论

不同巨头对“入口”的定义各不相同。苹果将OS（操作系统: Operating System的缩写，管理计算机硬件与软件资源的系统软件）视为入口，因此稳如泰山。谷歌曾将Chrome和安卓视为入口，如今已站稳脚跟。而OpenAI作为一个应用，则需要被动地从App Store到浏览器，再到其他生态去抢占入口。

强烈建议硅谷大厂组团来华考察，学习中国大厂在抢占入口方面的经验。

1. 字节跳动：时长与生态的困境

字节跳动将豆包视为其AI入口，希望其成为一个AI版的抖音，以时长作为核心指标。目前，豆包在国内AI应用领域位居前列，其DAU和时长表现突出。这得益于抖音对人性的深刻洞察，通过短视频解决了用户体验和内容供给问题，从而成为巨大的广告平台。然而，豆包在内容消费和供给端尚未达到抖音的成就，其供给和需求创造仍面临挑战。

最近，豆包的海外版Cici在东南亚等地增长迅猛，甚至霸榜。但Cici使用的是Gemini和OpenAI的模型，而非国内模型，这使其在海外市场与创业团队处于同一起跑线，缺乏国内开源模型的生态优势。Sora的发布也让TikTok的团队深感担忧，因为AI视频直接冲击了其核心内容供给模式。

2. 腾讯：关系链与微信的犹豫

腾讯目前认知的AI入口似乎是DeepSeek，并积极蹭其流量。元宝作为AI搜索功能，已集成到微信内部，在用户搜索时提供AI答案，这让用户倾向于留在微信生态内。然而，元宝作为微信联系人，并未如预期般引发“化学反应”，用户并未形成主动艾特元宝的习惯。这可能是因为腾讯在AI与微信核心关系链的打通上仍有犹豫，龙哥（张小龙）尚未想好如何平衡AI的介入与微信“不主动唤醒”的用户体验。腾讯在AI领域的投入仍在持续，其混元模型及开源动作值得关注。

3. 阿里巴巴：夸克的崛起与场景堆叠

阿里巴巴对流量入口的理解正在发生变化，重心从淘宝转向夸克。夸克PC端在引入AI搜索后，DAU一年内增长了10倍，主要用户是00后。这表明，年轻一代对AI驱动的搜索和应用有强烈需求。

夸克最初以“干净搜索”为用户心智，如今已集成数百个应用入口，如AI小说、夸克网盘、P证件照等，功能堆叠丰富，如同当年的360或好123。夸克团队源自UC浏览器，继承了其在移动端产品设计的经验。OpenAI如今在补谷歌和夸克在生态、应用和刚需入口方面的课。当进入生态和用户粘性决战时，OpenAI和字节跳动因缺乏刚需应用而显得被动，不得不不断创造新产品。

夸克在AI搜索方面的表现尤为突出，其Deep Research（深度研究: 指通过AI技术对特定领域的海量信息进行深入挖掘、分析和总结的过程）功能甚至超越了Google Gemini。这得益于其不依赖搜索盈利的商业模式，敢于整合高质量信源，如知网（知网: 中国知名的学术文献数据库），并打通商业化链路。夸克背后的Qwen3 Max（通义千问3 Max: 阿里巴巴开发的一个大型语言模型，属于其千问系列中的顶级版本）模型，在专业领域经过结构化和标准化训练，使其在推理和专业输出方面表现出色，与Gemini和Claude Opus（Claude Opus: Anthropic公司开发的Claude系列大型语言模型中的高级版本）处于同一级别。

AI时代巨头梯队与未来展望

模型决定下限，生态决定上限。谷歌和阿里凭借其完整的生态系统，在AI时代显得从容不迫，可被视为第一梯队。腾讯和苹果则凭借其牢固的关系链和操作系统，作为第二梯队，可淡定观望。而最先开枪的OpenAI和势头最猛的字节跳动，虽然估值高企，但因缺乏强OS和生态，只能通过“APP工厂”（App Factory: 指通过快速开发和迭代，大量推出各种应用程序的策略或模式）战略，不断推出新应用来抢占市场，被视为第三梯队，离降级仅一步之遥。

从赚钱角度看，这六家公司中，目前只有谷歌和阿里能勉强通过AI实现第二曲线增长。谷歌通过AI驱动的云服务增长，而阿里则通过夸克等应用探索新的ToC入口。国内大厂在AI入口的争夺，是真刀真枪的生死战，这与国外巨头有所不同。因此，Altman组团访华，学习中国企业如何卡位入口，或许能为OpenAI带来新的启发。

然而，AI时代是否会出现一个像微信一样的超级APP或超级入口？从互联网到移动互联网，趋势是越来越去中心化。AI可能会融入到每一个产品、功能和点击中，但用户可能感知不到。未来两三年内，用户界面不会有快速的蜕变，但AI的入口形式将更加多样化，可能包括眼镜、穿戴设备等，不再那么依赖视觉。好的AI交互应该是直觉的，像婴儿般容易操作，通过自然语言、触觉甚至眼动来完成交互。

最终，AI将融入到每一个产品和功能中，实现“先帮我想到了，然后帮我做了AI优化，我直接用就好了”的理想状态。这种“五星级酒店”般的AI服务体验，或许只有中国公司才能率先实现。中美在AI领域的探索，看似殊途同归，但路径不同。中国企业在豆包、元宝、夸克等产品上的创新，为AI时代的ToC新入口提供了独特的中国答卷。

结语

期待未来能有更多关于国内AI产品的分享，也希望更多中国企业能出海，让这些优秀的AI应用走向世界。
